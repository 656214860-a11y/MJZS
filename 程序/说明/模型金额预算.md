# 模型金额预算与逐次费用

当前接入助手、剧本、界面中的 Seedream 资产/首帧及项目配音（逐句、整段、预演临时音频）及云端视频提交。本地 ComfyUI、其他图片代理、连接探测等入口尚未接入同一金额上限，不能把此配置视为全部制作费用的硬上限；它们已有的次数/秒数限制继续生效。

在项目根目录既有 `cost_profile.json` 增加 `budget_amount`，并在 `price_table` 中填写 `currency`、`version` 和 `model_rates`。model_rates 以实际模型 ID 为键，每个模型包含 `prompt_tokens` 与 `completion_tokens` 两个十进制费率，单位都是“每一个 Token”，建议用字符串存储。供应商按百万 Token 报价时须先除以一百万。按未命中缓存输入价格做保守估算，不把未知缓存优惠提前当作折扣。此文档不提供未经确认的真实价格。

结构示意（尖括号须替换成真实数值/标识，不可原样使用）：

```json
{
  "budget_amount": "<项目模型金额上限>",
  "price_table": {
    "currency": "<币种>",
    "version": "<费率版本>",
    "model_rates": {
      "<实际模型ID>": {
        "prompt_tokens": "<每输入Token价格>",
        "completion_tokens": "<每输出Token价格>"
      }
    }
  }
}
```

保留原配置中的实际成片秒数、其他单位费率及人工/存储等字段，不覆盖已有配置。没有配置金额上限的项目仍记录逐次用量，但不声称已受金额控制。

提交前按消息UTF-8体积加协议余量估计输入量，并预留完整输出上限。预留、额度检查和保存共享跨进程锁；超额请求不发送，也不自动降级绕过拦截。修改 budget_amount 是明确提高额度的操作，既有支出和未知预留不会清零。缺少模型费率、输出上限、币种、价格版本，或既有台账包含未计价费用时，启用金额预算后会停止发送，须先核对配置与历史账目。

响应同时返回输入和输出用量时，按请求开始时冻结的费率估算已用金额；改价不追改历史请求。失败响应有实报用量也记费用。超时、断连、进程退出或未报齐用量保留预留，重启不释放，不自动假定退款。实际用量超过估算时如实入账，后续请求会按新余额停止；估算不保证供应商绝不超收，真实账单仍需核对。

请求台账位于项目 `工作流任务/宠物/请求台账.json`，保存请求ID、模型、阶段、估计输入、输出上限、费率版本和币种。费用总览显示冻结费率下的估算支出、预留及未知笔数；每分钟成本采用同一冻结费率，不与通用Token费率重复计价。台账损坏时停止写入，不能通过自动清空来恢复额度。

缓存计费档位、供应商额外收费、多模态输入价格、账单自动对账、全入口预算和批量前可视化预估仍待补齐。项目金额配置不代替模型服务商的账单。

Seedream 单张计费：在实际图片模型的 model_rates 条目填写 `images`（每张价格）。资产和首帧与文本调用共享同一项目总额度；成功返回单张图片按冻结单价记估算支出，不能视为供应商实报账单。不同尺寸/质量单价不同时应配置本批次最高适用单价，当前不自动识别价格档位。未发送的预算拒绝记 failed/not_submitted，纠正配置后可重试；发送后超时仍记 uncertain 并保留金额。生成任务记录的 request_id 可关联请求台账；已成功图片的本地导入失败不退费。

配音按实际 TTS 模型的 `characters` 费率预留（每个输入字符价格；当前按 Python 字符长度估算）。请求台账仍记请求次数，`quantities.characters` 保存计费字符量，避免旧成功回调重复记账。按 Token/时长等其他口径收费的供应商不应冒用字符单价，需补对应计价适配。逐句发送前持久化请求编号；未知句子续跑不重发，成功句子沿用。整段配音冻结设置并使用稳定请求号；预演持久工作区按声音指纹缓存临时音频，后续渲染失败重跑可复用，未知请求不重发。账目核对与解除未知状态的界面尚待完善，可先人工导入音频。无项目参数的兼容API不使用项目预算。

云端视频：实际模型条目的 `seconds` 为每生成秒的估算单价。不同云端会话统一使用所属项目根目录cost_profile和请求台账，原秒数额度仍单独生效。网络提交前预留；任务内money_request_id关联费用，云端成功即按冻结单价结算估算费用，下载/质检失败不退费、不重复计费。提交异常、云端失败保留未知费用；即使原秒数额度因明确拒绝被释放，金额也不擅自假定退款。供应商原始usage留在任务记录，不能把Token用量直接当秒数。不同分辨率/音频配置应填写适用单价，自动价格档位与账单核对待补齐。旧云端会话曾把费用记在会话目录，本次不自动迁移历史账目；历史会话与无账目的旧任务须在启用完整项目成本核算前归并核对。

启用金额上限时，旧视频会话台账或任务若尚未纳入项目总账，将在发送前提示核账。明确未发送的请求不占用额度；远端拒绝不等于账单已确认退款。历史账目不会自动迁移或删除，暂缺核账入口，不应靠删除旧记录绕过检查。
