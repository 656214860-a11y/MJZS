# 模型金额预算与逐次费用

当前接入助手、剧本、界面中的 Seedream 资产/首帧及项目配音（逐句、整段、预演临时音频）及云端视频提交。内置Comfy云图片已接入；本地ComfyUI计算、自定义云节点、其他图片代理、连接探测等入口尚未接入同一金额上限，不能把此配置视为全部制作费用的硬上限；它们已有的次数/秒数限制继续生效。

在项目根目录既有 `cost_profile.json` 增加 `budget_amount`，并在 `price_table` 中填写 `currency`、`version` 和 `model_rates`。model_rates 以实际模型 ID 为键，每个模型包含 `prompt_tokens` 与 `completion_tokens` 两个十进制费率，单位都是“每一个 Token”，建议用字符串存储。供应商按百万 Token 报价时须先除以一百万。按未命中缓存输入价格做保守估算，不把未知缓存优惠提前当作折扣。此文档不提供未经确认的真实价格。

结构示意（尖括号须替换成真实数值/标识，不可原样使用）：

```json
{
  "budget_amount": "<项目模型金额上限>",
  "price_table": {
    "currency": "<币种>",
    "version": "<费率版本>",
    "model_rates": {
      "<实际模型ID>": {
        "prompt_tokens": "<每输入Token价格>",
        "completion_tokens": "<每输出Token价格>"
      }
    }
  }
}
```

保留原配置中的实际成片秒数、其他单位费率及人工/存储等字段，不覆盖已有配置。没有配置金额上限的项目仍记录逐次用量，但不声称已受金额控制。

提交前按消息UTF-8体积加协议余量估计输入量，并预留完整输出上限。预留、额度检查和保存共享跨进程锁；超额请求不发送，也不自动降级绕过拦截。修改 budget_amount 是明确提高额度的操作，既有支出和未知预留不会清零。缺少模型费率、输出上限、币种、价格版本，或既有台账包含未计价费用时，启用金额预算后会停止发送，须先核对配置与历史账目。

响应同时返回输入和输出用量时，按请求开始时冻结的费率估算已用金额；改价不追改历史请求。失败响应有实报用量也记费用。超时、断连、进程退出或未报齐用量保留预留，重启不释放，不自动假定退款。实际用量超过估算时如实入账，后续请求会按新余额停止；估算不保证供应商绝不超收，真实账单仍需核对。

请求台账位于项目 `工作流任务/宠物/请求台账.json`，保存请求ID、模型、阶段、估计输入、输出上限、费率版本和币种。费用总览显示冻结费率下的估算支出、预留及未知笔数；每分钟成本采用同一冻结费率，不与通用Token费率重复计价。台账损坏时停止写入，不能通过自动清空来恢复额度。

缓存计费档位、供应商额外收费、多模态输入价格、账单自动对账、全入口预算和批量前可视化预估仍待补齐。项目金额配置不代替模型服务商的账单。

Seedream 单张计费：在实际图片模型的 model_rates 条目填写 `images`（每张价格）。资产和首帧与文本调用共享同一项目总额度；成功返回单张图片按冻结单价记估算支出，不能视为供应商实报账单。不同尺寸/质量单价不同时应配置本批次最高适用单价，当前不自动识别价格档位。未发送的预算拒绝记 failed/not_submitted，纠正配置后可重试；发送后超时仍记 uncertain 并保留金额。生成任务记录的 request_id 可关联请求台账；已成功图片的本地导入失败不退费。

配音按实际 TTS 模型的 `characters` 费率预留（每个输入字符价格；当前按 Python 字符长度估算）。请求台账仍记请求次数，`quantities.characters` 保存计费字符量，避免旧成功回调重复记账。按 Token/时长等其他口径收费的供应商不应冒用字符单价，需补对应计价适配。逐句发送前持久化请求编号；未知句子续跑不重发，成功句子沿用。整段配音冻结设置并使用稳定请求号；预演持久工作区按声音指纹缓存临时音频，后续渲染失败重跑可复用，未知请求不重发。账目核对与解除未知状态的界面尚待完善，可先人工导入音频。无项目参数的兼容API不使用项目预算。

云端视频：实际模型条目的 `seconds` 为每生成秒的估算单价。不同云端会话统一使用所属项目根目录cost_profile和请求台账，原秒数额度仍单独生效。网络提交前预留；任务内money_request_id关联费用，云端成功即按冻结单价结算估算费用，下载/质检失败不退费、不重复计费。提交异常、云端失败保留未知费用；即使原秒数额度因明确拒绝被释放，金额也不擅自假定退款。供应商原始usage留在任务记录，不能把Token用量直接当秒数。不同分辨率/音频配置应填写适用单价，自动价格档位与账单核对待补齐。旧云端会话曾把费用记在会话目录，本次不自动迁移历史账目；历史会话与无账目的旧任务须在启用完整项目成本核算前归并核对。

启用金额上限时，旧视频会话台账或任务若尚未纳入项目总账，将在发送前提示核账。明确未发送的请求不占用额度；远端拒绝不等于账单已确认退款。历史账目不会自动迁移或删除，可使用下述显式导入和核对入口，不应靠删除旧记录绕过检查。

## 人工费用核对

设置→预算→费用核对中，选择已结算、未知或已取消的请求，填写最终账单金额、币种、核对人并选择非空本地凭据。金额0仅用于确认无费用；进行中的请求先查询最终结果。保存后按账单金额占用预算，允许记录超预算实际费用，但下一笔请求会受预算限制。

凭据不会上传或复制，台账保存本地路径、SHA256与每次修改前的金额/状态；请保留原文件。重复相同保存不增加审计记录。核对并不证明远端任务完成，也不会解除制作任务的未知状态或重发请求。后续模型/视频回执不覆盖已核对金额。用量总览分别显示估算金额与人工已核对金额。跨币种不能直接覆盖，不自动换汇。

点击「导入旧视频账目」可扫描项目根目录和 cloud_video 会话，将同会话同视频版本的条数、秒数和任务记录合为一笔待核对费用。不同会话的相同编号分别保留；没有足够关联信息的历史条目不推测合并。原会话文件不改动，项目原用量记录只增加费用组关联，避免金额重复计算。费用组不是新的模型调用，旧子会话用量不会因此伪装为新增调用。

导入后金额仍为未知，需逐笔凭账单核对；进行中任务应先查询最终状态，再重新导入。相同来源重复导入无新增费用组；来源变化会使旧金额失效，保留原金额和核对审计，并要求重新确认。每次核对绑定来源摘要。导入失败不会部分保存。尚未实现跨会话重复远端任务的自动合并，不能将此入口视为供应商账单真实性验证或完整历史用量迁移。

## 视频批次金额预览

云端视频手动提交与批量提交确认中，按当前配置模型和所选待提交镜头总秒数展示预计金额、费率版本、项目已占用金额（含预留）、金额上限及剩余金额。已完成或未知任务沿用既有筛选规则，不因预览重发。自动批量提交同样检查，并写入界面日志。整批超过金额上限时，在第一镜发送前拒绝。

预览不创建或修改台账、不冻结额度；确认到执行期间费率或其他请求可能变化，每次实际发送仍重新原子检查。并发消耗可能使后续镜头停止，预览不保证整批全部完成。没有金额上限时沿用兼容行为，缺费率明确显示未知；启用上限后缺费率/未计价历史会阻断。该入口尚未覆盖图片/TTS批量预览。


### R1544 图片批次预估

Seedream资产与首帧提供“预估费用”入口，按当前真实模型的图片单价显示最多新增图片数、报价及项目额度。预览不创建目录或请求台账，不冻结额度；执行前再次预检，逐请求仍原子预留。排除已完成、待核实及可恢复输出；损坏恢复文件需要人工核实，不能自动重新收费生成。报价为上界，后续输入校验可能减少实际请求数。TTS、其他代理以及跨批整单原子预留尚未覆盖。


### R1545 逐句TTS批次报价

确认框按实际冻结模型和待合成文本字符数显示金额、价格版本、项目占用及剩余额度。已有音频与身份相同的sending/uncertain句子排除，未知项提示人工核对。执行器在建目录或写清单前再次预检；超额整批零发送。报价不锁额度，逐请求仍原子预留；并发花费可能使批次部分完成。其他代理入口及跨批整单预留仍待完善。


### R1547 内置Comfy云图片

DramaCloudImage节点按模型、质量、比例组合计价，避免不同规格误套价格。例如费率表model_rates键为 `comfy:["Seedream 5.0 Pro","medium","1:1"]`，值含 `images` 每张费用；此标识也显示在批次报价中。一个工作流限一个内置云图片节点。提交前原子预留，远端输出出现后按冻结价格估算结算，随后才下载；失败或未知不自动视为免费。修改当前价格不追改历史费用。

批量资产入口先检查整批新增图片报价，排除可恢复和待核实任务。逐请求仍重验，因此报价后其他并发支出可能使批次部分完成；尚无整单额度锁。已有旧Comfy任务未自动补录费用，本地GPU与任意自定义云节点仍不在此覆盖范围，项目金额上限不能视为全部历史与全部工作流成本上限。
