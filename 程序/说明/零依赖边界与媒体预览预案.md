# 零依赖边界与媒体预览预案

> 状态：**已完成**（M0–M8 全部落地，M8 收尾轮更新本文；完成凭据见 `tasks_round/任务完成/零依赖边界与媒体预览·任务完成.md`）。对应任务书 `tasks_round/零依赖边界与媒体预览任务书.md`（M0–M8）。
> 本文只登记已确认决策与边界，不改代码；各轮实现进度以 `tasks_round/tasks_round_<N>_result.md` 为准。

## 1. 目标

用户安装应用后，登录，配置模型（或按引导填写 key），无需再安装任何依赖即可跑通默认流程。视频、音频在应用内有流畅的封面预览，用户能在「项目文件」面板里清楚地查找、打开、保存对应文件。

## 2. 「零依赖」的定义（D1/D2/D15）

- **主运行时零 pip 依赖**：`运行环境\Python` 是裁剪过的 Python 3.15 基解释器，`Lib\site-packages` 不存在。标准库裁剪清单见 `runbook.md` §9 与 `tests/test_stdlib_closure.py` 的 `PRUNED`。
- 媒体能力只走三个已有出口，**不新增第四种**：
  1. **外部进程**：ffmpeg／ffprobe（随包 LGPL 构建，见 §3）。
  2. **隔离 venv**：离线 ASR（`data/voice_asr_venv`＋`data/voice_models`，约 1.6 GB，不随安装包，见 §5）。
  3. **浏览器页**：白模监视页等既有本机页面。
- **破例加 pip 包的触发线（D15，四条全满足才可）**：①用户可见缺口且三个出口都试过不行；②纯 Python 或有稳定 Windows wheel，许可证允许分发；③wheel 随包带、运行时不联网安装；④同轮更新 `requirements.txt`、分发清单与 `test_import_error_boundaries.py` 等相关门禁。D14/D15 只作建议写在本文，不构成 `AGENTS.md` §2.3 硬约束。

## 3. ffmpeg 随包（D3，M1）

- 用 **LGPL 构建**的 `ffmpeg.exe`、`ffprobe.exe`，放 `运行环境\ffmpeg\bin\`，附 `LICENSE`/`NOTICE` 与构建来源、版本号；用户可在设置里指定自己的 ffmpeg（满足 LGPL 可替换义务）。
- 取路径优先级（解析发生在**读取时**，不只改默认值——已创建项目的 `config.json` 里已复制过旧路径）：
  **用户显式指定且文件真实存在的路径 ＞ 随包版本 ＞ 系统 PATH ＞ 调用方兜底原文**。
- 统一入口：`contract/platform_tools.tool_path`；绕过入口直读 `cfg['ffmpeg']`/`cfg['ffprobe']` 的消费方（`orchestrator/engine.py`、`local_video.py`、`agent/media.py`、`domain/animatic_service.py`、`environment_check.check_ffmpeg`）改为经 `tool_path` 解析；代码里写死的 `D:/Tools/ffmpeg/bin/...` 兜底（`domain/keyframe_evidence.py`、`infra/native_asset_codec.py`、`orchestrator/previs_automation.py`）删除。
- 程序目录 `config.json` 的 `ffmpeg`/`ffprobe` 默认值清空；`domain/projects.py` 新建项目时不再把这两项复制进项目配置。老项目配置不改写（保护用户数据）。
- `environment_check` 的 ffmpeg 行显示「当前使用：随包版本」或实际路径；缺失仍是警告，文案可操作。

## 4. 默认后端改云端（D7/D8，M2/M7）

- **新建项目**默认 `video_backend='cloud'`；已有项目的显式取值一律不动；`local_video_settings_service` 里用户主动保存本地设置写 `comfy` 属显式选择，保持。
- 本地 ComfyUI 与 Blender 变为**可选高级项**：未安装时白模预演页显示「需要 Blender · 去设置」，ComfyUI 同理给引导，不报错；`environment_check` 归为「可选」。
- 云端未配置（供应商／模型／key 任一缺失）时 `ui/cloud_video.py` 显示「尚未配置」并给出打开配置的入口。
- 字段 `video_backend` 必须保留（历史冒烟锚点只验字段存在）。
- **默认模型（A7，依赖 A4 中转站，未授权实现）**：过渡方案＝M7 登录闸通过后模型池为空则打开已有模型管理，由用户自填 key。客户端不得内置或明文落盘任何 key（`AGENTS.md` §2.1 第 1 条）；令牌将来由服务端按账号签发、经 `model_pool.env_file` 通道进入。登记见 `维护记录/优化待办队列.md` A7。

## 5. 离线语音识别默认云端（D6，M6）

- 离线包（约 1.1 GB）**不随安装包**。设置里提供「下载离线语音包」，带进度、校验和、断点续传、可取消；下载目标沿用 `data/voice_asr_venv`、`data/voice_models` 与 `voice_engine/bootstrap.py` 引导逻辑。
- 默认后端现状 `speech_api` 为 `offline`；离线缺失且已配云端密钥时会话层已自动降级。只补「离线缺失且无云端密钥」一格：提示改为引导「配置云端语音密钥，或在设置里下载离线语音包」。
- **不把全局默认直接改 `cloud`**：仅当离线环境缺失时新用户按云端处理；已装离线包的老用户（未显式设 `backend`）行为不变。

## 6. 项目文件面板：图标、预览与文件操作（D9–D13，M3–M5）

- **载体**：挂现有「项目文件」停靠面板，复用 `ui/desktop_files_panel.py`、`ui/desktop_files_panel_filters.py`、`infra/file_index`、`contract/file_naming`；原 `project_files` 图标保留。阶段图标是打开停靠面板后右侧的二级图标列（R3139 已合入，当前 emoji 占位）。
- **阶段图标视觉（D10）**：以侧栏阶段图标为底、右下角叠小「文件」角标；13 个阶段图标顺序同 `pet_bus.STAGES`；素材由开发期 `scripts/build_nav_icons.py` 生成 PNG（`assets/nav/<stage>_files.png`），运行时只读 PNG，缺 PNG 退回 emoji。
- **面板行为（D11，已实现于 R3191）**：阶段面板切换工作页时保持打开，只在切换项目或进入隐藏入口页（账户/参考站等）时收起。原 REQ-S01-90「切换页面…自动收起」的冲突句已由 REQ-S01-94（✅ R3191）取代：工作页间切换不收起。
- **查找与筛选（D12）**：首发保留「阶段／类型／状态／文件名关键字」四条件；镜头号与版本只作排序列显示，不做独立筛选器。
- **打开与保存（D13）**：「打开」调系统默认播放器；「在文件夹中显示」；「另存为」复制到用户选定位置（不移动），对话框预填 `项目名_阶段名_原文件名`，目标已存在先询问，不静默覆盖。
- **媒体预览（D4/D5）**：视频、音频只做封面＋系统播放器，不做应用内播放器。封面和波形由 ffmpeg 预生成为 PNG，Tk `PhotoImage` 显示；复用 `asset_thumbs.py` 磁盘缓存与后台子进程，缓存键含文件 mtime 与大小，命中不碰文件；启动路径零递归扫描（规则 33）。
- **判定口径**：媒体类型按文件后缀判断（`infra/file_index` 的 `IMAGE_SUFFIXES`/`AUDIO_SUFFIXES`/`VIDEO_SUFFIXES`），不按 `kind`（图片归「资产」）；时长与分辨率写封面缓存旁路记录，不改 `FileRow`（L0 契约不动）。
- **不新增代码模块（D14）**：全部改动落在现有模块；新增的只有二进制资源（ffmpeg、PNG）与文档。撞复杂度棘轮须拆分时停下请用户授权。
