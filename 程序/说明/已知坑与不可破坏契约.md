版本：1.1，2026-11-20。C1–C15、P1–P12、F1–F9 只从三个现成来源定向提炼，不回溯全仓：来源 A `维护记录/缺陷台账_20261001.md`（R744 只读普查）、来源 B `维护记录/优化待办队列.md`（当前待办索引）、来源 C `维护记录/架构变更记录.md`（architecture.md 迁出的轮次变更记录）。C16–C20 与 F10 的证据是已接受的 `docs/adr/0015-lane-flow-does-not-block-sessions.md`，不回写上述历史台账。每条格式：`一句话结论｜证据（来源文件＋行号/轮次）｜若破坏的后果`。取不到证据的条目一律不写；权威规则原文仍以 `AGENTS.md` §2.2/§2.3 为准，本文是「为什么这些边界存在」的证据索引，不是第二权威源。操作细则在 `runbook.md` §12。

## §2 已知坑

| # | 一句话结论 | 证据 | 若破坏的后果 |
| --- | --- | --- | --- |
| P1 | 启动饿死链：首帧完成后自动续开延后 40ms 建页若遇切页守卫返回，tick 保持暂停、简报队列不再消费；R765 已修代码但实机复验挂账 | A L9 | 用户机器上启动卡死，自动化环境复现不了 |
| P2 | 改名认领：`_live_path_writes()` 重写项目 `config.json` 的 `episode_dir`/`episode_file` 并由 `claim_reconciled()` 调用，改名路径待实机复验 | A L10 | 项目改名后路径认领错乱 |
| P3 | 右键删除不存在目录走 `clear_missing_registration()` 分流，主界面右键路径未证实同分流 | A L11 | 幽灵条目残留或误删提示缺失 |
| P4 | skip 登记位≠实际跳过：历史 203 条登记位中仅平台/依赖类合法 gate，余下「待核验证债务」不得以全量变绿为由保留 | A L41–L48 | 把登记位读成已跳过，覆盖造假 |

| P7 | 自然剧本正文在「剧本准备」页与「剧本结构」页各有一套独立阅读/编辑实现（`desktop_writing_page.py` 与 `desktop_script_pages.py` 的 `_ContentBox`） | B L41 | 改一处漏另一处，行为漂移 |
| P8 | R1068 副本删除对照证明≠生产删除：三个候选副本删除通过但真实生产删除量 0，仍 REVIEW | B L45–L46 | 把隔离证明勾选当生产清理完成 |

## §3 试过但失败的方案

| # | 一句话结论 | 证据 | 若破坏的后果 |
| --- | --- | --- | --- |
| F1 | 不用白名单/豁免压过测试违规（R2443 收口反向依赖时的明令） | C L7（R2443） | 违规被登记成「合法」，门禁失去意义 |
| F2 | 不把所有 `except Exception` 自动判为缺陷——须按吞没类别与影响面分类 | A L15 | 误报淹没真缺陷，或漏判静默失败 |
| F3 | 不为清零棘轮数字改层或重构资产批处理簇 | A L68 | 无设计判据的结构性回归 |
| F4 | 不删台账、不扩大白名单来伪造归零 | A L72–L74 | 欠账消失于记录而非代码 |
| F5 | SKILL 在线市场/付费分发：不做（单机无账户体系与支付通道） | B L92（S1） | 引入无服务端基础的空壳功能 |
| F6 | 项目级 SKILL 云同步：不做（项目数据属用户本地资产，依赖账户体系） | B L93（S2） | 未授权的数据出境与冲突合并风险 |
| F7 | Skill vs Plugin 代码插件二分：不引入（SKILL 只提供说明不执行代码） | B L94（S3） | 破坏「用户勾选制、只读说明」安全模型 |
| F8 | `.agents/skills` 回读挂载：不做（第三方包 frontmatter 不满足 17 字段契约，挂载会破坏层语义、职责反转） | B L95（S4） | SKILL 层被污染，单向导出变双向 |
| F9 | 多版本灰度并存与远端埋点：不做（单机成本高于收益） | B L75 | 为不存在的多租户场景付工程成本 |
| F10 | 不用「每工作树一把全量锁」或「每次提交改跑分层全量」来避免阻塞 | ADR-0015 选项 A、B | 多套全量抢同一 GUI，或每轮提交重新被全量挡住 |
