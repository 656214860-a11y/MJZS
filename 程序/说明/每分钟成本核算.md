# 每分钟成本核算

项目用量总览会读取项目根目录可选的 cost_profile.json。没有配置时保持原有用量统计，不猜费率。配置示例仅表示结构，数值须替换为本项目真实口径，不能据此认为有真实账单：

```json
{"duration_seconds":60,"price_table":{"currency":"CNY","version":"供应商价目版本","at":"适用日期","rates":{"seconds":0.1}},"overheads":{"gpu":null,"storage":null,"bandwidth":null,"human":null}}
```

duration_seconds 填实际交付片长，不能把失败或重试生成时长当分母。rates 键匹配请求台账 kind，每单位价格按同一币种录入；不支持自动换汇或按不同模型自动分价。已结算、预留、未知用量分别呈现。仅记账项的费用可以算已知部分，不代表真实全部成本。估计用量、未知量、缺费率或预留使总额保持不完整。

overheads 是本次交付额外GPU、存储、带宽、人工金额；null 表示未知，明确确认未发生才填0。已经包含在供应商费用中的资源不要重复加算。界面显示已录入部分每分钟成本、缺项和估算依据，不能冒称供应商对账通过。

仍待完善：按模型和费率版本冻结每笔费率、失败和重试全量记账、图片请求覆盖、账单导入对账、多币种以及用量自动采集。本轮不承诺生产链费用已覆盖100%。
