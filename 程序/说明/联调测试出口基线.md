## 5. 不适用项与真实网络面

| 传统安全项 | 适用性 | 依据 |
| --- | --- | --- |
| 越权（横向／纵向） | **不适用** | 本地单进程 Tkinter 桌面应用；无账户体系、无多租户、无远端访问 |
| 支付漏洞 | **不适用** | 无支付通道；金额是外部 API 花费与本地资源，走 `usage_overview`／`RequestLedger`，有 `tests/test_money_invariants.py`、`tests/test_request_ledger.py` 守护 |

**网络面不是零（R1627 更正）**：`previs_monitor.py:130` 会起一个本地回环 HTTP 只读预览页（`ThreadingHTTPServer(('127.0.0.1', 0), ...)`，随机端口）。已核验：只答 GET、只渲染固定页、**忽略请求路径、不服务文件**（无路径穿越面），仍无鉴权。适用风险＝同机其他进程／其他本机用户可以读到该预览页内容（含项目状态摘要）。登记为 T13，是否接受（本地单用户假设）由用户裁决。

**随附资产内的第二个监听面（R1636 补全）**：`skills/09白模预演SKILL/create-blender-story-video/assets/render-monitor-dashboard/server.py:849` 自带一个独立监控面板 `ThreadingHTTPServer`。已核验：`--host` 默认且只接受 127.0.0.1／localhost（非回环在启动前直接拒绝）；只答 GET 且仅固定只读端点（/、/index.html、/render-monitor-demo/、/render-monitor-demo/index.html、/healthz、/api/status、/api/latest-frame）；POST 与 HEAD 返回 405；只读白名单内的 index.html 与已校验预览帧，不做任意路径文件服务（无路径穿越面）；并设 nosniff／no-referrer／X-Frame-Options DENY 与 CSP 头。产品代码不启动它（全仓仅自引用），属随附工具资产，归入供应链面而非产品监听面；本轮只登记，不改其代码。

仍适用且未覆盖的安全面：模型输出注入（T10）、出站素材白名单（T11）、回环预览页暴露面（T13）、供应链（随附解释器 3.15.0a2 alpha＋`skills/**` 内第三方库）。

- 修复缺陷台账里的 A 级挂账 → 同步 §4 状态列；“实机已验证”之前必须有实机证据。
