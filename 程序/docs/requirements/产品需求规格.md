## 1. 产品目标与范围

目标用户：可编辑中文剧本和审核画面，但不编写代码的独立漫剧创作者。核心价值：在一个项目中，从创意形成可继续编辑、可追溯、人工确认的漫剧成片，减少重复提交和手工搬运素材。

首个验收规格：中文、**120 秒、30 镜**、每镜标称 6 秒、最多 2 个主要角色、最多 2 个场景、固定二次元插画风格；竖屏 1080×1920、25fps、MP4（H.264/AAC），SRT 与分轨素材清单，并输出已有 EDL/FCPXML。最终时长允许 119–121 秒；实际对白与动作应服从 120 秒时间预算。

**规模基线**（设计侧细化见 `docs/specs/README.md` §5）：产品支持「一部剧」为单项目，主力形态为红果短剧约 80 集／约 3000 镜，以及单集 90–120 分钟的电影（约 1200–1800 镜）。首个验收用 30 镜（覆盖红果典型单集上限），**满负载验收为 3000 镜**（只测性能与稳定性，不测质量可用率）。分页机制须在首个验收即被验证：分镜表每页 ≤100 行，30 镜首验收配合规模验收共同覆盖翻页路径。

人工编辑是正式路径：可以改剧本、分镜字段、替换角色／首帧、导入自己的配音、调整时间线或导出到外部剪辑软件。采用新版本必须更新来源关系，旧版保留以便回退，不允许静默把旧确认沿用到新版本。

验收预算：供应商与模型由用户指定，总付费上限待用户提供；未知预算时可执行本地技术检查，不自动启动收费样例。成本阈值在首批实测后由产品负责人确认，禁止先写未经依据的"几元一分钟"。一次批量启动必须展示最大任务数、重试上限和费用未知项。

历史用户要求及其阶段／领域设计落点见[对话需求追溯](../records/对话需求追溯.md)。该索引保留原始意图和变更依据；产品目标与优先级以本文为准。

**REQ-APP-01 · 制作操作入口**（2026-11-19，会话《梳理应用架构并编写任务书》，Q7 澄清后的选项 1）。创作者在助手自身界面查看项目、启动、暂停或取消制作。助手按既有配置主动访问云模型、账号、会员及计量服务。设计见 [ADR-0001](../adr/0001-layered-architecture.md)。验收时从界面启动受控任务并观察终态，分别核对本地执行和云端出站；新增集成方案须复核调用方向。

### 1.1 市场定位与竞品分析

**定位**：本地优先的全自动漫剧流水线。项目文件、剧本、分镜、首帧、配音和生成媒体全部留在用户本地目录；软件不强制云端保存，也不代管模型调用链。用户可自带 API Key，也可用官方中转站 API 按量自费。

**对标竞品与差异**：

| 竞品 | 形态 | 强项 | 本产品的差异点 |
|---|---|---|---|
| 剪映智能创作 | 云端一体化剪辑 | 模板生态、剪辑成熟、免费获客强 | 本产品不自建剪辑器，输出成片与 EDL/FCPXML 交给它精修；差异在**前置的 13 阶段结构化生产链**：分镜、资产正典、连贯性、可追溯采用关系 |
| 即创 | 云端投放素材生产 | 电商素材批量、模板多 | 本产品做**长叙事**（60 秒以上、多镜多角色一致性），不做素材快消 |
| 即梦 | 云端生成模型 | 模型质量与出图效果强 | 本产品**不绑死单一模型**：供应商与模型由用户指定，可换、可比、可降级到本地 ComfyUI |
| libtv | 短剧成片平台 | 成片分发与短剧内容 | 本产品停在**制作环节**，不做分发与播放平台 |
| 小云雀 | 云端 AI 视频工具 | 上手快、门槛低 | 本产品以**本地资产安全 + 可追溯 + 人工确认门禁**换取更高可控性，接受更高的上手成本 |

**差异化价值（可量化目标，未实测不宣称达成）**：
1. **数据不外流**：项目与素材零上传；仅出站 JSON 请求（提示词、参考图）经 `http_client`，用户可见。
2. **可追溯**：每个采用版本绑定相对路径 + 内容摘要，改稿使下游确认失效，不允许静默沿用。
3. **可选供应商**：至少 2 家线上供应商 + 本地 ComfyUI 降级，供应商失败不阻断出片。
4. **成本可见**：批量前展示最大任务数、重试上限与费用未知项；未知费用不显示为 0。

**市场切入**：
- 主战场：**独立短视频创作者**（日更、红果短剧、小说改编试水）。
- 次战场：**教育与培训市场**（课件、教学短片；学员侧提供教学场景与练习项目）。
- 非目标市场：需要多人协作、云端素材库、企业级权限与审计的团队客户（本设计为单机单用户）。

### 1.2 用户画像与典型场景

| 画像 | 背景与技能 | 目标 | 痛点 | 付费能力 | 使用频次／规模 |
|---|---|---|---|---|---|
| **P1 短视频日更创作者** | 会用 AI 工具、会配 API Key、会用 SKILL；不写代码 | 稳定日更 1 条竖屏短剧 | 重复提交、素材搬运、角色不一致 | 月付 19 元会员 + API 自费，月 API 预算约 50–300 元 | 日更；单条 60 秒、10 镜 |
| **P2 红果／短剧批量制作** | 有短剧制作经验，懂分镜术语 | 按平台要求批量出集 | 一致性差、返工多、成本不可控 | 月付 19 元 + API 自费，单集预算 10–50 元 | 月更长剧；单集 60–120 秒、10–30 镜 |
| **P3 小说改编试水者** | 有文本能力、缺视觉能力 | 把小说片段做成可看片段验证 | 不会写分镜、不会配提示词 | 月付 19 元 + 小额 API | 不定期；先做 1 集试水 |
| **P4 教育机构／学员** | 教师会做课件、学员零基础 | 教学短片、课件、练习作业 | 学习成本、操作步骤多 | 机构采购会员；学员用 3 天试用 | 课程周期内集中使用 |

**共同约束**：可编辑中文剧本、可审核画面；不编写代码；不安装 Python 环境（使用随附解释器）。

### 1.3 商业模式与计费规则

**REQ-APP-02 · 模型使用与费用**（11-18 会话 01a1ee62）。规划平台预置模型按量计费、自带 API 时只收会员费两种路径，项目文件留在本地。供应商、费率和代配方式待定。分别验收调用来源、凭据归属、会员费与使用费，见[云端设计](../specs/07_业务域规格.md)及 P1-1、P1-2。

来源：R1508；原件归档于 `tasks_round/归档/2026-10/tasks_round_1508_result.md` L25–L37，本表为唯一权威。

**收入结构**：

| 项 | 内容 | 价格 |
|---|---|---|
| 月度会员 | 软件使用权：解锁 13 阶段完整流程、无人值守、导出交付包 | **19 元／月** |
| 季度会员 | 同上，按季付费 | **49 元／季**（约 16.3 元／月） |
| 年度会员 | 同上，按年付费 | **189 元／年**（约 15.75 元／月） |
| 免费试用 | 应用使用权 3 天，**不含 API 额度** | 0 元 |
| 中转站 API | 用户选择使用官方默认中转站时按用量计费 | 按中转站价目表（`console.supergpt.dev/models`）计费 |
| 自建 API | 用户自带 Key 直连供应商 | **软件不收费**，费用由用户与供应商直接结算 |

**计费规则**：
1. **会员费与 API 费分离**。19 元只是软件使用权，不含任何模型调用额度；使用量的钱一律由用户自付。
2. **自建 API 不上报**：走用户自有 Key 的调用，软件只做本地台账（项目内逐笔记录），**不上传用量给服务端**，不参与额度扣减。
3. **默认中转站 API 计量目标（未实现）**：未来走官方中转站的调用，客户端应上报计费用量（项目哈希、阶段、模型、供应商请求 ID、计费单位、状态），由服务端按已确认结算契约扣减额度；上报内容只含计量字段，**不含提示词正文、剧本正文与素材**。截至本次源码核对，客户端与服务端均无 `/v1/metering`，不得标记为已上线或已扣减。
4. **失败与未知用量**：失败重试的费用按中转站实际计费口径结算；**未知用量不显示为 0**，标为"未知"并单列。迟到账单在下次对账时补记。
5. **额度不足**：余额或额度不足时拦截**新的付费阶段提交**，已勾选的素材与已成功的产物保留；免费阶段（剧本准备、结构、初步分镜、项目管理、查看与导出已成功产物）不受影响。
6. **试用边界**：3 天内应用全功能可用（含无人值守），但不含 API 额度；用户可自建 Key 在试用期内跑通全流程。试用到期后付费阶段锁定，免费阶段与本地文件读取仍可用。
7. **预算由用户填写**：项目级预算不是产品预设值。用户在项目设置里填写本集预算上限，软件据此展示预估、预留与实际，超额需明确操作才继续。产品**不发布"几元一分钟"这类无依据单价**；首批实测后再登记参考区间。

**成本可视化要求**：一次批量启动前必须展示：最大任务数、单任务计费单位、重试上限、预估区间、未知项清单；结束后展示实报用量、失败重试次数、实际时长。

### 1.4 数据安全与隐私保护

**数据分类与边界**：

| 数据 | 存放位置 | 是否上传 | 说明 |
|---|---|---|---|
| 项目、剧本、分镜、结构剧本 | 用户选定项目目录 | **否** | 只在本机读写 |
| 参考图、生成图、首帧、视频、音频 | 用户选定项目目录 | **否**（除作为模型输入外） | 作为请求体发送时用户可见，明文不落第三方存储 |
| 用户 API Key | `private/密钥/*.dpapi`（DPAPI 加密） | **否** | 首次读 `.env` 后迁入加密存储，之后不再读明文，日志与任务 JSON 不存明文 |
| 计量用量（默认中转站，待实现） | 服务端（目标） | **尚未接入** | 实现后仅含计量字段，不含正文 |
| 会员与授权状态 | 服务端 | **是** | 账号、设备、租约；不含项目内容 |

**密钥管理**：
- 全程只按变量名取密钥；日志、任务 JSON、异常栈、界面显示一律脱敏。
- 用户输入 Key 时提示不得共享或提交到公开仓库；密钥不写入任何记录文件。
- 出站请求统一经 `http_client`（超时必填、错误码、有界重试、响应上限、脱敏），`urlopen`／`build_opener` 只许 `http_client` 与登记白名单，由 `test_http_boundary` 守卫。

**隐私协议要点**（对外发布前须有正式文本，本文只列必须覆盖的点）：
1. 明确"项目与素材不上云"，列出唯一例外：模型输入（提示词、参考图）会发送给用户选定的供应商。
2. 默认中转站如未来接入，应明确它会收到的模型输入与最小计量数据、保留期和用途；当前无计量上报端点，不能声称已经收到或扣减；应提供只用自建 Key 的选择以跳过中转站。
3. 用户注销有 7 天冷静期；账号资料及后增数据依实际服务端表结构与隐私政策逐项清理，防重复试用哈希台账的保留须披露；未来计量记录的清理需单独定义。本地项目不受影响（本就不在服务端）。
4. 未成年不得注册（年龄声明）。

**素材溯源与授权**：
- 参考图、生成图、视频、音乐、字体、声音、外部导入**均记录来源、许可、必要授权与内容审核状态**。
- **缺失授权只警告不阻断**（用户自担商用风险），但该素材**不得标记为"商用审核通过"**；交付报告中单列风险项。
- 不自动填"原创"或"可商用"；检测失败显示"未知"并转人工。

### 1.5 不做什么

分三类裁决，避免"先不承诺"含糊：

| 类别 | 条目 | 原因 | 影响与替代方案 |
|---|---|---|---|
| **明确不做** | 口型精准同步 | 现有供应商无稳定 phoneme 对齐输出，自研成本超出单机产品边界 | 影响观感；替代：字幕对齐 + 用户外部精修（EDL/FCPXML） |
| **明确不做** | 无人监督商用 | 版权与内容责任无法由软件承担 | 影响商用效率；替代：商用审核清单 + 人工确认门禁 + 交付报告风险项 |
| **明确不做** | 云端项目同步／多人协作 | 与"数据不外流"定位冲突，需账户体系与冲突合并（已在 `优化待办队列` S1–S4 登记不做） | 影响团队场景；替代：本地项目目录 + 用户自行网盘备份 |
| **暂不优先** | 剪映原生草稿（`draft_content.json`） | 需逆向私有格式，版本一变即失效 | 影响剪映接力体验；替代：MP4 + SRT + 分轨清单 + EDL/FCPXML（已作为首个验收规格交付） |

**依赖关系（阶段放行门禁）**：
- `assets ← animatic`（SG-B：Animatic 可播放，节奏、时长、对白同步已确认）
- `keyframe ← storyboard`（SG-02：定稿已采用）
- `video ← keyframe`（数据依赖）+ SG-05（复杂镜头须有可播放白模预演）
- `audio ← storyboard`（对白以采用分镜为准）
- `edit ← video`、`edit ← audio`
- `delivery ← edit`（SG-04：成片可完整播放）

**并行与重试**：以 `stage_parallel.CONFIG` 为唯一权威。当前口径：应用进程共享最大在途 8；视频阶段串行、批 2–3 镜、同时最多 3 个、失败重试 2 次后转人工；视频是唯一处理供应商限流的阶段（降速排队）。该限制不提供跨进程机器总额度。

### 2.2 阶段确认模式（用户可选，逐阶段生效）

产品提供两种确认模式，**用户自己决定每个阶段用哪种**，默认按业界常见的"付费即确认、免费可自动"配置：

| 模式 | 说明 | 适用阶段默认 |
|---|---|---|
| **人工逐阶段确认** | 阶段产出后暂停，等用户查看并点采用才进入下一阶段；采用记录绑定内容摘要 | 付费阶段（S05、S08、S10、S11）、S01、S07、S13 |
| **三虎自动全流程** | 从指定阶段起无人值守连续跑到目标阶段；每阶段沿用既有确认策略，失败按重试上限转人工 | 免费阶段（S02、S03、S04、S06、S09、S12）可开自动 |

**强制不可自动化的门禁**（业界标准与合规要求，不接受自动放行）：
1. 付费阶段启动前必须有一次明确的费用确认（展示最大任务数、重试上限、未知项）。
2. `delivery` 的"商用审核通过"不能由模型自称完成，必须有人工确认或明确标为"未审核"。
3. 采用关系（剧本采用、分镜定稿采用、资产采用、首帧采用、视频验收）必须由用户操作产生；模型文字与 UI 提示不算完成证据（`stage_completion_service` 以产物核验）。
4. 自动流程中任一阶段失败超过重试上限即停止并转人工，不允许"跳过该阶段继续"。

### 2.3 页面与入口清单

13 个阶段页 + 工具页（参考网站、模型管理、设置、任务中心、日志）。每页必须提供：当前阶段状态、输入与产物清单、可用操作（生成／暂停／重试／采用／导出）、失败原因与下一步、费用与用量（适用时）。所有用户可见删除统一经回收站（`storage_maintenance.recycle_paths`）。

## 6. 质量基准与阈值

### 6.1 分阶段可用率阈值

原则：成本递增、可用率要求递增。**全部为待实测目标**，首批实测后由产品负责人确认或调整，不预先宣称达成。

| 阶段 | 首轮人工可用率目标 | 理由 |
|---|---|---|
| S01 剧本准备 | ≥ 50% | 用户预期会大幅编辑剧本 |
| S02–S03 结构与初步分镜 | ≥ 60% | 结构性工作，中等要求 |
| S04 分镜预演 | ≥ 70% | 用于节奏判断，容许微调 |
| S05 资产管理 | ≥ 70% | 重生成成本中等 |
| S07 分镜定稿 | ≥ 70% | 直接驱动首帧与视频 |
| S08 首帧管理 | ≥ 75% | 直接进入视频生成 |
| S10 视频生成 | ≥ 80% | 重生成成本最高 |
| S11 配音与字幕 | ≥ 70% | 音频可后期调整 |

### 6.2 评分与"可用"定义

5 分制：5＝完美无需修改；4＝优秀，小改 1–2 处即用；3＝可用，需改 3–5 处；2＝需大改，保留框架重做 30%–50%；1＝不可用，需重新生成。**≥3 分计为可用**。

### 6.3 技术指标目标值

| 指标 | 目标 | 说明 |
|---|---|---|
| 音画偏差 | ≤ 100 ms | 以字幕起点与对应音频起点对比；需实测记录测量方法 |
| 成片时长 | 119–121 秒（标称 120 秒，首验收）；59–61 秒（60 秒规格） | 以 FFprobe 探测为准 |
| 缺镜／黑帧 | 0 | 全片逐镜核对，无意外黑帧 |
| 对白覆盖 | 100% 非空对白有音轨或明确人工处理 | 逐句核对表 |
| 文件校验 | 导出包内每个文件可通过完整性校验 | 哈希清单 |

### 6.4 评测方法

至少 3 个故事 × 每故事 10 镜，独立留出故事验证泛化，双人独立评审并记录分歧；不得只展示最佳样片。工具为 `维护记录/基准脚本/business_quality_baseline.py`（当前空表返回 `pending`，无金标准样本）。
