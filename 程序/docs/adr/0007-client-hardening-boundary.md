# ADR-0007 客户端采用门槛型加固

- 状态：已接受
- 日期：2026-11-19
- 层级 / 阶段：L1/L2/L3 / 全局
- 取代／被取代：—

## 背景与问题

桌面端需要离线可用，部署在用户控制的 Python 环境。[技术选型对比表](../../说明/技术选型对比表_20261119.md) §1.1–1.2 记录三个可低成本修正的缺口。

## 考虑过的选项

- 只守服务端。改动少，但会保留会话完整性和设备绑定缺口。
- 门槛型加固。可保留离线能力，同时补齐已证实的缺口。
- 加壳、反调试或强制联网。投入高，强制联网违背离线承诺。

## 决定

采用门槛型加固。独立保存设备回退种子，校验会话文件，依据验签租约判定收费阶段。

## 后果（含不可破坏的约束）

这些措施提高绕过成本，不构成安全边界。签发与服务端资源由服务端控制。无可用租约时前两阶段仍可访问，收费阶段保持拦截。
