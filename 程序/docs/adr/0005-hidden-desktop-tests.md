# ADR-0005 测试隐藏桌面强制执行

- 状态：已接受
- 日期：2026-11-16
- 层级 / 阶段：L1,L5 / 全局
- 取代／被取代：—

## 背景与问题

「含 Tk 的测试一律在隐藏桌面运行、不弹到用户屏幕」此前只是文档约定：执法依赖仓库外钩子 `~/.claude/hooks/gui_test_guard.py`（R1837）与未跟踪 helper `工作流任务/gui_hidden.py`（`.gitignore` 排除）；R1838 起后台补跑带「helper 缺失则直跑」静默降级。R3000 起开发转入并行工作树车道后，工作树里没有这些外部件，规则实际失效——含 Tk 测试在用户可见桌面弹窗。决策出处：`tasks_round/测试隐藏桌面强制执行任务书.md` 已确认决策清单（R3039，用户拍板 15 条）。

## 考虑过的选项

- **A. 维持文档约定＋仓库外钩子/未跟踪 helper**：载体不入库、静默降级、工作树不可见，已实测失效。
- **B. 入库 `scripts/gui_hidden.py`＋唯一咽喉点自包装**（现行方案）：`run_selftests.py` 检测本轮范围含 Tk 测试即用入库模块把自己重新拉起到隐藏桌面；`smoke_test.py` 默认进程内 widget 检查同样接入；自动检测（扫 `import tkinter`/`tk.Tk()`）不维护人工登记表。
- **C. 逐测试入口人工包装**：入口多（run_selftests 各模式、smoke 各门禁、dev.py、local_ci、三虎），易漏且口径不一，被唯一咽喉点方案取代。

## 决定

按任务书 15 条已确认决策执行：隐藏桌面创建失败→中止并告警，绝不降级直跑；`auto_full_safe.py` 删「helper 缺失则直跑」fallback，缺失/失败记 BLOCKED；生效范围 agent 会话与用户手动一视同仁，唯一逃生舱 `--visible`（默认关、打印醒目警告、后台补跑禁止）；每轮 smoke 带 `--probe` 秒级自检；新增架构门禁守护回潮；`sink_test_windows()` 恢复为最后一道缓解；仓库外钩子废弃不再维护。

## 后果（含不可破坏的约束）

- 任何含 Tk 测试的入口最终都经 `run_selftests.py` 自包装，绕过即架构门禁红。
- 隐藏桌面不可用＝环境阻塞（BLOCKED），不得冒充测试红、不得静默直跑。
- `--visible` 仅人工调试，后台补跑禁用；新增测试放 `tests/` 并遵守同一咽喉点。
