# ADR-0010 兑换码优先与人工退款

- 状态：已接受
- 日期：2026-11-19
- 层级 / 阶段：L2 / 全局
- 取代／被取代：—

## 背景与问题

现有渠道通过发卡售卖会员。[技术选型对比表](../../说明/技术选型对比表_20261119.md) §1.4 对比兑换码与接入官方商户后的订阅模式。

## 考虑过的选项

- 只支持兑换码。成本最低，后续接订阅要补数据契约。
- 立即实现完整订阅。支付、发票与对账前置条件尚未具备。
- 兑换码先行并预留字段。能处理当前作废与退款登记。

## 决定

当前以兑换码开通和续期。未兑换码可作废，已兑换码可登记人工退款。预留自动续费与支付渠道字段，接入支付后再启用。

## 后果（含不可破坏的约束）

当前不自动扣费，不自动退款，不按比例退。同一码至多一份申请，用户只能查询本账号记录。
