# ADR-0011 以五维探针表达模型可用性

- 状态：已接受
- 日期：2026-11-19
- 层级 / 阶段：L1/L2 / 全局
- 取代／被取代：—

## 背景与问题

模型池已有探针和移除机制。[技术选型对比表](../../docs/records/文档迁移台账.md) §4.1 记录了增加启用开关与额度查询的评估。

## 考虑过的选项

- 单独增加启用开关。各下游都要过滤，遗漏会让停用模型继续被选中。
- 再增加额度查询。供应商接口不同，项目还需维护额外账本。
- 沿用五维探针，移除模型采用删除。沿用已登记的可用性与停用机制。

## 决定

使用连通性、协议兼容、模型标识、能力声明、完整任务五维探针。暂不引入启用开关或供应商额度查询。

## 后果（含不可破坏的约束）

停用通过删除完成。额度错误与用量继续由现有错误码、用量视图和请求台账承接。
