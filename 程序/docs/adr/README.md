# 架构决策记录（ADR）

本目录用 MADR 精简格式记录「为什么这么定」的架构与工程决策。规则：

- **状态枚举**：`提议`／`已接受`／`已废弃`／`已被替代`（四选一，不自造状态）。
- **编号规则**：4 位递增（0001、0002…），**一经分配不复用、不跳号**；新 ADR 从当前最大编号 +1 起。无证据可考的历史编号在索引标 `未立项`，**不为其建空壳文件**。
- **格式**：一律按 `TEMPLATE.md` 五段（背景与问题／考虑过的选项／决定／后果）；`考虑过的选项` 为必填段，查不到历史就写「历史未记录」，不得编造。
- **层级字段**：层级取值引用 `tests/architecture/_layers.py` 的 `LAYER_NAMES` 短名；阶段取 `S01`–`S13` 或 `全局`。
- **权威关系**：ADR 记录决策与理由；决策的**现行口径**仍以 `AGENTS.md` §2.2 权威源表、`architecture.md`、`pet_bus.STAGES` 等唯一权威为准，冲突时以权威源为准并回改 ADR。
