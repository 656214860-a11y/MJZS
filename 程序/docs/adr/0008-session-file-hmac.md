# ADR-0008 会话文件使用 HMAC 校验

- 状态：已接受
- 日期：2026-11-19
- 层级 / 阶段：L1 / 全局
- 取代／被取代：—

## 背景与问题

本地会话需要检测文件改动，并保留换机重新登录能力。[技术选型对比表](../../docs/records/文档迁移台账.md) §1.2、§2.3 与账户设计 D10 提供依据。

## 考虑过的选项

- 保持现有纯文本存储。无法检测字段被改动。
- 文件级 HMAC。用本机密钥认证会话内容，保存格式可维持既有 JSON。
- 对订阅凭据直接做机器绑定。D10 认为这会增加换机负担。

## 决定

使用 HMAC-SHA256 校验规范化会话内容。DPAPI 保护本机 MAC 密钥。验签失败、密钥丢失或遇到旧版无签名会话时重新登录。

## 后果（含不可破坏的约束）

HMAC 用于完整性。授权与服务端吊销仍依据租约和会话。换机可重新登录。密钥与会话不进入日志。
