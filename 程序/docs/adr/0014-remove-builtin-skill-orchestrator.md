# ADR-0014 移除应用内建 SKILL 总控

- 状态：已接受
- 日期：2026-11-19
- 层级 / 阶段：全局 / 全局
- 取代／被取代：—

## 背景与问题

用户已决定不再由应用内建专用总控管理 SKILL。总控界面移除后，专用资源、脚本桥、五个工具和路径分支仍存，阶段说明也依赖这些资源。执行依据是[内建总控退役任务书](../../tasks_round/总控机制删除任务书.md)；R3811 是任务标签，实际执行轮次为 R3818。

## 考虑过的选项

历史未记录其他正式选项。任务书已裁决直接删除专用机制，不迁入 legacy，不重写替代工具；通用阶段编排与第三方技能不属于退役范围。

## 决定

删除内建总控目录、专用机检桥、包差异维护脚本及五个工具 `feed.validate`、`feed.gateCheck`、`feed.auditContract`、`style.lockRecommend`、`style.lockLadder`。同步删除其专用测试与登记，其他测试保留有效语义。

保留命令的 `engine` 类别，从调用方提供的统一注册器快照投影用户／项目包入口；扁平技能仍走 `/skill名`。候选投影无文件扫描，发送解析复用注册器对象，项目＞用户＞内置优先级不变。同步器沿用通用引用解析，不再拼装特定包路径。

13 阶段 SKILL 在原文件内保留所需职责与可独立执行的方法定义，取消对被删资源的链接。外部 SKILL 仅在用户安装选择后参与，不视为已存在的内建资源。

## 后果（含不可破坏的约束）

应用不再暴露五个专用工具，也不再分发内建总控资源。通用 `skill_registry`、`skill_orchestrator`、阶段执行、制作锁、其他第三方 SKILL、模板与锁文件均保留；用户数据与历史报告不重写。

退役验证覆盖空候选、非法路径、注册包、命令发送、三层引用回退、阶段职责、工具列表和分发摘要。默认冒烟、完整架构门禁与安全全量通过后才能合入 master。覆盖率登记仅删已不存在的实体，其他阈值不降低。
