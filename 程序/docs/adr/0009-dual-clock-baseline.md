# ADR-0009 授权时钟基线双处保存

- 状态：已接受
- 日期：2026-11-19
- 层级 / 阶段：L1/L2 / 全局
- 取代／被取代：—

## 背景与问题

离线授权需要可靠的最近服务端时钟。[技术选型对比表](../../docs/records/文档迁移台账.md) §1.3 记录响应时钟未签名与单点状态丢失的问题。

## 考虑过的选项

- 只签服务端时钟。可认证签发时刻，历史最高时钟仍可能只保存在单处。
- 签名加双处单调保存。会话和当前用户注册表各保留可信基线。
- 每次启动联网。违背离线使用承诺。

## 决定

服务端签入 `iat_server`，客户端对签名时间和两份本机基线取高值。保持 300 秒回拨容差，运行期间用单调钟推进过期判断。

## 后果（含不可破坏的约束）

注册表不可用时按会话和签名租约降级，并显示状态。进程重启从持久化基线重新判定。
