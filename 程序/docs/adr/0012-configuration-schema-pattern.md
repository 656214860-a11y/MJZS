# ADR-0012 配置校验复用产物规格模式

- 状态：已接受
- 日期：2026-11-19
- 层级 / 阶段：L0/L1 / 全局
- 取代／被取代：—

## 背景与问题

配置需要可校验、兼容旧版本且满足运行时依赖准入。[技术选型对比表](../../说明/技术选型对比表_20261119.md) §3.4 比较了三种方案。

## 考虑过的选项

- 引入 jsonschema。具备成熟标准，但需要依赖准入，新增运行时依赖。
- 沿用 artifact_schema 的注册和版本模式。复用已有工程约定。
- 只写 schema_version。无法识别字段类型错误。

## 决定

后续配置校验沿用 artifact_schema 的注册和版本化模式，新写入带 schema_version，读取兼容缺版本的数据。

## 后果（含不可破坏的约束）

本决策只确定机制。具体配置字段约束由对应规格收口，依赖白名单保持有效。
