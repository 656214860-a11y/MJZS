# 06 安全设计

本册覆盖凭据存储、通信加密、完整性校验、会话防篡改、威胁模型与对抗清单。

## 1. 威胁模型

**前提假设**：单机单用户桌面应用，攻击者模型为「本机可执行代码的非特权用户」（能读文件、能改文件、能抓包），**不是**远程服务器入侵。

| # | 威胁 | 影响 | 现有防护 | 缺口 |
|---|---|---|---|---|
| T1 | API Key 泄露（明文落盘、日志、Git） | 盗刷用户额度 | DPAPI 加密；日志脱敏；提交期密钥扫描 | — |
| T2 | 中间人攻击（伪装服务端） | 窃取会话、伪造授权 | 证书钉扎（`PINNED_CERT`）；不关闭校验 | 测试服 IP 证书；生产域名待换 |
| T3 | 会话文件篡改（改过期时间） | 绕过会员闸门 | 会话文件 HMAC（`session_integrity`） | — |
| T4 | 时钟回拨（冻结本地钟续用过期租约） | 绕过会员闸门 | 双时钟基线（`session.json` + 注册表） | 见 §4.2 |
| T5 | 更新包投毒 | 植入恶意代码 | `分发清单.json` 逐文件 sha256 | **更新流程不校验** |
| T6 | 模型输出注入路径 | 越权读写文件 | 注入用例覆盖（`../`、绝对路径、非法字符、控制字符、超长截断） | — |
| T7 | 素材版权风险 | 法务纠纷 | 溯源清单 + 商用门禁 | 用户可填假信息 |
| T8 | 项目数据外流 | 隐私泄露 | 项目目录不上传（模型输入经选定供应商除外）；未来计量仅允许最小字段 | 中转站线路可见模型输入，当前 `/v1/metering` 尚未实现 |

## 2. 凭据存储

### 2.1 唯一实现

`infra/model_secrets.py` 是**唯一**凭据存储实现：

| 项 | 值 |
|---|---|
| 加密方式 | Windows DPAPI（`crypt32.CryptProtectData`／`CryptUnprotectData`） |
| 存储路径 | `程序/private/密钥/<名字>.dpapi` |
| 迁移 | `.env`／`private/.env` 首次读取时迁入，记 `private/env_imported.json`，**之后不再读 .env、文件不删** |
| 读取判据 | `infra/pet_llm.credential` |

### 2.2 取钥链（唯一）

```
infra/model_pool（唯一取钥链）
  → 本机 DPAPI（private/密钥/*.dpapi）
  → .env（首次迁移用，之后不读）
  → 环境变量
```

### 2.3 硬约束

| 约束 | 说明 |
|---|---|
| 只按变量名取钥 | 不读整份文件到内存 |
| 不写入任何记录文件 | 包括任务 JSON、结果文件、提交信息 |
| 不进日志 | `app.log` 落盘脱敏（`test_log_sink_boundary` 守卫） |
| 不进 Git | 提交前 `round_evidence.SECRET_PATTERNS` 扫描 |
| 界面脱敏 | 显示为 `sk-****`，不提供「显示明文」 |
| 导出脱敏 | 诊断导出不含密钥 |

`contract/model_protocol.py` 只声明边界，不放实现。

## 3. 通信加密

### 3.1 客户端 → 服务端

| 项 | 方案 |
|---|---|
| 协议 | HTTPS（TLS 1.2+） |
| 证书校验 | `ssl.create_default_context(cadata=PINNED_CERT)` — **钉扎，不关闭校验** |
| 当前证书 | `8.138.223.126` 测试服自签证书，内置在 `domain/account_client.py` |
| 变更条件 | 生产域名上线时必须换证书并重新钉扎；**不得用 `CERT_NONE` 过渡** |
| 主机名校验 | `wrap_socket(server_hostname=...)` 必须传 |

### 3.2 客户端 → 模型供应商

| 项 | 方案 |
|---|---|
| 传输层 | `contract/platform_tools` 统一 `ssl.create_default_context` |
| 出站唯一入口 | `http_client.request_json()`（[02 §1.7](02_接口与详细设计.md)） |
| 白名单 | `urlopen`／`build_opener` 只许 `http_client` 与登记白名单（棘轮只减不增） |

### 3.3 已知边界

- 使用官方中转站时，**模型输入（提示词、参考图）对中转站可见**。这是产品定位的一部分（PRD §1.4），须在隐私协议明示。
- 用户可切换「只用自建 Key」模式完全跳过中转站。

## 4. 会话与授权完整性

### 4.1 会话文件 HMAC（ADR-0008）

| 项 | 实现 |
|---|---|
| 模块 | `infra/session_integrity.py` |
| MAC 算法 | HMAC-SHA256 |
| 密钥 | `.mac_key.dpapi`（DPAPI 保护，机器绑定） |
| 校验 | `hmac.compare_digest`（防时序侧信道） |
| 覆盖 | `infra/account_store.py` 的会话文件 |

### 4.2 时钟基线（ADR-0009）

| 项 | 实现 |
|---|---|
| 基线 | `floor = max(last_server_time, issued_at)` |
| 判定 | `now + 300 < floor` → `CLOCK_SUSPECT` |
| 存放 | **两处独立**：`session.json` + 注册表 |
| 目的 | 单点改文件无法重置基线 |

**已知缺口**：`server_time` 当前来自未签名响应体。攻击者可改 `session.json` 的 `server_time` 为 0 降回 `issued_at`，再冻结时钟使过期租约长期判 `GRACE`。**待修**：服务端把 `server_time` 纳入签名租约 payload（ADR-0009 方案 B 的完整落地）。

### 4.3 授权状态机

| 状态 | 条件 | 可用范围 |
|---|---|---|
| `valid` | `now < expires_at` 且 `state ∈ {trial, active}` | 全部功能 |
| `grace` | `expires_at ≤ now < grace_until` | 可用 + 横幅提示续签 |
| `locked` | `now ≥ grace_until` 或 `state=expired` | 禁付费阶段新生成与导出；免费阶段、打开项目、读本地文件仍可用 |
| `signed_out` | 无租约／验签失败／`did` 不匹配 | 提示登录；免费阶段仍可用 |
| `clock_suspect` | 本地时间早于已知服务器时间（容差 5 分钟） | 视为过期，须联网续签 |

最长离线 10 天（7 + 3）。续签在启动时与每 12 小时进行，失败静默重试不弹窗。

### 4.4 会员闸门

前置在 `stage_handler_registry.start()` 入口（C6）。宿主未挂 account 时不设闸（避免开发与测试被阻断）。

**已知缺陷**：`GATE_ENFORCED` 是明文模块常量（`domain/entitlement_service.py:29`），改一行可废掉全部收费阶段。**待修**：从租约派生 `enforce = payload.get('state') in PAID_STATES`。修法需同步调整 3 处测试的 patch 目标（改为 patch 租约 payload 的 `state`）。

## 5. 完整性校验

### 5.1 发布包（已有）

| 层 | 实现 | 状态 |
|---|---|---|
| 逐文件哈希 | `distribution_build.py` 写 `分发清单.json`，`verify()` 比对 mismatch/extra | **已实现** |
| 清单签名 | minisign／GPG detached 签名 `SHA256SUMS` | **待实现** |
| SBOM | CycloneDX 1.5 | **待实现** |

### 5.2 更新包（缺口）

**当前**：`infra/update_notice.py` 只比版本号，**不校验包完整性**。

**要求**：更新流程必须
1. 下载后读内嵌 `分发清单.json`；
2. 逐文件比对 sha256（调 `distribution_build.verify()`）；
3. 用公钥验 `SHA256SUMS.sig`；
4. 指纹比对通过才安装；
5. 校验失败**拒绝安装**并明确提示，不得「警告后继续」。

### 5.3 外部工具与技能包

| 对象 | 锁定方式 |
|---|---|
| FFmpeg／FFprobe | `external_tools.lock.json`（版本 + 哈希） |
| 外部技能包 | `维护记录/外部技能包哈希.json`（来源、固定提交、内容树哈希） |

漂移即红（`skill_package_pins --check`）。

## 6. 故障处置与恢复

| 场景 | 处置 |
|---|---|
| 密钥读取失败 | 明确提示重新配置；不静默使用空 Key |
| 证书校验失败 | 拒绝连接并提示；不降级 |
| 会话验签失败 | 清本机会话，提示重新登录 |
| 磁盘满 | 发布前 `resources.ensure_free` 闸门拦截 |
| 索引损坏 | `rebuild` 重建（派生数据） |
| 更新包校验失败 | 拒绝安装，保留旧版 |

## 8. 合规与隐私

| 项 | 要求 |
|---|---|
| 数据最小化 | 会员服务只接收账号与授权所需字段；官方中转站计量上报尚未接入，未来不得上传提示词／剧本／项目路径原文；模型输入经用户选定供应商或第三方线路，不能称为绝对零上传 |
| 未成年 | 不得注册（年龄声明） |
| 注销 | 7 天冷静期后按已核实表清理账号资料，试用防滥用哈希台账的例外及保留期须在隐私政策披露；未来计量数据清理另设计并验证；本地项目不受影响 |
| 隐私协议 | 须覆盖 [PRD §1.4](../requirements/产品需求规格.md) 四点 |
| 免责 | 不保证法律合规、不替用户做授权判断 |
| 主体与资质 | 暂无；支付未开通（首期用兑换码） |
