# 设计规格索引（Design Spec）

版本：1.0，2026-11-19，R3785。本目录是「AI 漫剧助手」的实现设计层规格，覆盖架构与技术选型、接口与详细设计、安装签名与分发、数据与本地存储、UI/UX、安全设计、业务域规格七部分。

## 1. 本目录与其他文档的权威关系

**这不是需求文档，也不是流程规范。** 层级如下（上层是下层的前提，下层不得反向覆盖上层）：

| 层 | 文档 | 权威范围 |
|---|---|---|
| 需求 | [`说明/产品需求规格.md`](../说明/产品需求规格.md) | 产品目标、用户故事、优先级、验收标准、非功能指标 |
| 阶段需求 | [`docs/stages/S01–S13`](../stages/) | 13 个阶段的 `REQ-`／`DES-` 条目与测试锚点 |
| 架构（唯一权威） | [`architecture.md`](../../architecture.md) | L0–L5 分层表、目录树、门禁清单 |
| **实现设计（本目录）** | `docs/specs/*.md` | **怎么实现**：技术选型理由、接口契约、存储设计、安装分发、UI 规范、安全机制 |
| 决策记录 | [`docs/adr/`](../adr/) | 单个决策的「为什么」 |
| 运维 | [`runbook.md`](../../runbook.md) | 部署、升级、回滚、故障处置 |

**冲突处理**：本目录与 `architecture.md` 冲突时以 `architecture.md` 为准并回改本目录；与 PRD 冲突时以 PRD 为准；与代码冲突时以代码为准并回改本目录。本目录**不重新定义**分层、阶段顺序、路径、事件前缀等已有唯一权威 —— 那些只引用不复述。

## 5. 规模与形态基线

用户确认的产品形态（覆盖 PRD §5.6 的规模上限，本节为设计侧细化）：

| 形态 | 集数 | 单片长 | 总镜数 | 估算媒体文件数 | 说明 |
|---|---|---|---|---|---|
| 红果短剧 | 约 80 集 | 1–2 分钟／集 | 约 3000 | 约 21000 | 主力商业形态 |
| 电影 | 1 集 | 90–120 分钟 | 约 1200–1800 | 约 12000 | 单集长片 |

**项目 = 一部剧**，一集 = 一个 episode。资产为**项目级共享**（角色正典跨集复用）。

规模实测与瓶颈见 [04 §7](04_数据与本地存储.md) 与 [05 §4](05_UIUX与交互规范.md)。
