# 07 业务域规格

本册覆盖会员订阅、登录认证、设置、模型管理四个业务域的详细设计。

**账户与会员的完整设计权威是 [`说明/账户会员云端设计.md`](../说明/账户会员云端设计.md)**（250 行，含数据表、接口表、状态机、服务端字段）。本册写**域边界与实现约束**，不复制那份文档的正文，避免双份失真。

## 7.1 域划分

| 域 | 职责 | 权威文档 |
|---|---|---|
| 会员订阅 | 试用、付费、租约、额度、兑换码 | `说明/账户会员云端设计.md` + 本册 §7.2 |
| 登录认证 | 邮箱验证码、会话、设备绑定 | `说明/账户会员云端设计.md` + 本册 §7.3 |
| 设置 | 全局配置、桌面偏好 | 本册 §7.4 |
| 模型管理 | 模型池、密钥、可用性探针 | 本册 §7.5 + ADR-0011 |

## 7.2 会员订阅

### 7.2.1 产品形态

| 档 | 价格 | 内容 |
|---|---|---|
| 免费试用 | 0 元 3 天 | 应用使用权，**不含 API 额度** |
| 月度 | 19 元／月 | 应用使用权（约 19 元／月） |
| 季度 | 49 元／季 | 同上（约 16.3 元／月） |
| 年度 | 189 元／年 | 同上（约 15.75 元／月） |
| API | 按量 | 走官方中转站时按 `console.supergpt.dev/models` 计费；自建 API 不收费 |

### 7.2.2 会员费与 API 费分离

**19 元只是软件使用权，不含任何模型调用额度。**

| 调用方式 | 计费 | 上报 |
|---|---|---|
| 用户自建 API Key | 软件不收费，用户与供应商直接结算 | **不上报**，只入本地台账 |
| 官方默认中转站 | 按中转站价目表 | **上报计量字段** |

上报内容：项目哈希、阶段、模型、供应商请求 ID、计费单位、状态、时间戳。
**不含**：提示词正文、剧本正文、素材、路径原文、API Key。

### 7.2.3 状态与闸门

状态机见 [06 §4.3](06_安全设计.md)。闸门位置：`stage_handler_registry.start()` 前置（C6）。

**额度不足时**：拦截**新的付费阶段提交**；已勾选素材与已成功产物保留；免费阶段（剧本准备、结构、初步分镜、项目管理、查看与导出已成功产物）不受影响。

### 7.2.4 兑换码（首期收款方式）

| 项 | 方案 |
|---|---|
| 发放 | 服务端 `scripts/gen_redeem.py` 批量生成 |
| 购买渠道 | 爱发电／淘宝发卡（第三方发卡，不碰卡号） |
| 客户端入口 | 账号页「输入兑换码」 |
| 端点 | `POST /v1/redeem` |

**首期不做在线支付**（无经营主体与资质）。

### 7.2.5 退款

ADR-0010：**兑换码优先 + 人工退款**。无自动退款流程；退款由人工处理并留记录。

### 7.2.6 待修缺陷

| # | 缺陷 | 影响 |
|---|---|---|
| M-1 | `GATE_ENFORCED` 明文常量可一行废除 | 付费墙可绕过（**P0**） |
| M-2 | 时钟基线单点可改 | 过期租约可长期用（**P0**） |
| M-3 | 退款无据 | 退款争议无从核对（P1） |

## 7.3 登录认证

### 7.3.1 首期范围

| 项 | 首期 | 预留不实现 |
|---|---|---|
| 登录方式 | **邮箱验证码** | 短信、微信扫码 |
| 设备绑定 | 每账号 3 台 | — |
| 试用判定 | **服务器时间权威**（防改本地钟） | — |
| 支付 | 不做 | 自动续费代扣 |

### 7.3.2 会话与租约

| 项 | 方案 |
|---|---|
| 租约验签 | RSA（`infra/lease_verifier.py`），`hmac.compare_digest` 比对 |
| 离线可用 | 最长 10 天（租约 7 天 + 宽限 3 天） |
| 续签 | 启动时 + 每 12 小时；失败静默重试不弹窗 |
| 并发续签 | 设备级锁 + 服务端替换窗口（`MJ_REPLAY_GRACE_SECONDS`，默认 10 秒） |
| 登出 | 先请求服务端吊销轮换链，再清本机会话；无法确认时仍清本机并提示远端到期失效 |

### 7.3.3 设备与账号

| 项 | 方案 |
|---|---|
| 设备标识 | 本机生成，存 `session.json` |
| 解绑 | 自助解绑 |
| 注销 | 7 天冷静期后删除账号与服务端记录；本地项目不受影响 |
| 年龄 | 未成年不得注册 |
| 数据导出 | 支持 |

### 7.3.4 隐私边界

- 云端**只做鉴权 + 订阅**，不碰模型调用链。
- 素材不上云。
- 服务端代码为独立仓库 `D:\漫剧服务端`，分支 `main`，不推远端。

## 7.4 设置

### 7.4.1 配置分层

| 层 | 文件 | 内容 | 升级 |
|---|---|---|---|
| 全局配置 | `程序/配置/客户端档案.json`、`配置/SKILL/预设.json`、`配置/宠物/配置.json` | 客户端档案、SKILL 预设、宠物偏好 | 保留 |
| 程序状态 | `程序/config.json`、`projects.json`、`desktop_settings.json` | 项目索引、FFmpeg 路径、ComfyUI 地址、上次项目 | **保留不覆盖** |
| 项目配置 | `<项目>/skill_config.json` | 阶段模型、SKILL 勾选、制作锁、`reasoning` | 保留 |

**升级安装只覆盖程序文件**，上述一律保留。

### 7.4.2 校验模式

配置校验**复用 `artifact_schema` 模式**（ADR-0012），不引入 pydantic：

- 写入侧 `stamp()` 落版本
- 读取侧 `validate()` 返回问题清单不抛异常
- 历史配置 `migrate()` 只加键

### 7.4.3 桌面偏好

| 项 | 字段 | 说明 |
|---|---|---|
| 上次项目 | `project_choice_path` / `project_choice_day` | 记住上次打开 |
| 本机 ComfyUI | `comfy_url` | 本地白模预演 |
| 剪映路径 | `jianying` | 导出接力 |
| 外观 | 见 `design_tokens` | 深色模式不在本期 |

发布该文件经 `desktop_settings_service.publish_desktop_settings()`（原子发布）。

### 7.4.4 存储与日志设置

| 项 | 位置 | 默认 |
|---|---|---|
| 保留天数 | `<项目>/storage_policy.json` 的 `retention_days` | 按策略 |
| 日志保留 | `infra/log_maintenance.py` 常量 | 轮转 + 容量帽 |
| 成本配置 | `<项目>/cost_profile.json` | 缺失则只显示已落盘用量，不猜费率 |

## 7.5 素材授权与溯源

### 7.5.1 溯源要求

参考图、生成图、视频、音乐、字体、声音、外部导入**均记录**：来源、许可、必要授权、内容审核状态。

### 7.5.2 许可判定（P0-1）

| 规则 | 要求 |
|---|---|
| 许可 ID | 用**规范 ID**，禁止子串放行 |
| CC BY-NC | 商用请求**必须拦截** |
| ND | 改编用途**必须拦截** |
| BY-SA | 明示义务 |
| 缺来源信息 | 不可静默放行 |
| 两处过滤路径 | 必须一致 |

### 7.5.3 缺失授权的处置

**警告不阻断**（用户自担商用风险），但：
- 该素材**不得标记为「商用审核通过」**
- 交付报告中**单列风险项**
- 不自动填「原创」或「可商用」
- 检测失败显示「未知」并转人工

### 7.5.4 商用门控（P0-5）

交付素材 **100% 可追溯**才可标「商用通过」。必要授权缺失或高风险内容未处置时**不得标记通过**。检测失败转人工，不能视为通过。

## 7.6 模型管理

### 7.6.1 模型池

| 项 | 方案 |
|---|---|
| 权威 | 模型管理保存的模型池 |
| 取钥链 | DPAPI → `.env`（首次） → 环境变量 |
| 按阶段选模型 | `<项目>/skill_config.json` 阶段项 + `reasoning` 字段 |
| 推理等级 | auto / low / medium / high，按模型协议映射（`reasoning_effort`／`reasoning.effort`／`thinking.budget_tokens`） |

### 7.6.2 可用性探针（ADR-0011）

以**五维探针**表达模型可用性，不是单一布尔值。探针结果只做提示，不自动禁用模型。

### 7.6.3 失败切换

`ModelRouter` 按 SKILL 的 `fallbackModels` **有限次**切换（`说明/生成服务失败处理契约.md`）。切换失败分类由 `test_adapter_failure_conformance` 钉在真实适配器上。

### 7.6.4 三处模型设置的区别

| 设置 | 位置 | 作用 |
|---|---|---|
| 模型池 | 模型管理 | 可用模型全集 |
| 阶段模型 | `skill_config.json` 阶段项 | 本阶段用哪个 |
| 推理等级 | `skill_config.json` 的 `reasoning` | 本阶段档位 |

**约束**：CLI／桌面引擎与生产模型不受 `reasoning` 影响。

### 7.6.1 SKILL 管理边界

应用不再内建专用总控包；安装的 SKILL 可自带创作说明，应用仍通过统一注册表管理项目、用户和内置三层 SKILL，优先级为项目＞用户＞内置。通用阶段编排与 `production_locks` 制作锁保持独立。

退役五个专用工具：`feed.validate`、`feed.gateCheck`、`feed.auditContract`、`style.lockRecommend`、`style.lockLadder`，不提供替代实现。保留 `engine` 命令类别，其候选复用已注册的用户／项目包入口；扁平技能仍使用 `/skill名`，不扫描任意 README 或执行包内脚本。空候选和未知命令返回空结果。

任务与验收边界见[内建总控退役任务书](../../tasks_round/总控机制删除任务书.md)。

## 7.7 域间依赖

```
登录认证 ──→ 会员订阅（租约是会员状态的载体）
     │
     └──→ 模型管理（闸门通过后才允许配模型／生成）
设置 ──→ 全部域（配置是所有域的前提条件）
素材授权 ──→ 交付（商用门控依赖溯源）
```
