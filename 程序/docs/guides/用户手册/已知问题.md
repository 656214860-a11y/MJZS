# 已知问题

只列您能感知到的问题，每条写现象、影响与临时办法；修复或不再适用时从本页移除。发布说明引用本页。

## 界面写「剪映」，其他剪辑软件未验证

- 现象：剪辑页的导出叫「整理剪映素材交接包」。
- 影响：实际用其他剪辑软件时，工程兼容性未经验证。
- 临时办法：按交接包里的素材清单，在您的剪辑软件里手工导入素材组装。

## 升级与回滚只演练过模拟构建

- 现象：覆盖式升级前后的自动校验，尚未在真实安装目录上完整跑过一次。
- 影响：升级万一中断，可能留下新旧混合的程序文件。
- 临时办法：升级前先手动备份安装目录和项目目录；出现异常时整目录还原。

## 源码副本不携带随包工具与开源清单

- 现象：「关于与开源许可」提示「本副本未携带 THIRD_PARTY_NOTICES.txt」，FFmpeg 也可能缺失。
- 影响：从源码直接运行的副本，合成类功能不可用。
- 临时办法：使用完整发布包；或按《环境类错误指引 · FFmpeg 缺失》补齐工具。

## 取消任务不保证远端已停止

- 现象：点「取消」后本地不再继续，但已提交的远端任务可能仍在运行并计费。
- 影响：取消后仍可能产生费用，或收到意料之外的结果。
- 临时办法：远端任务结果未知时先查询任务状态，别把关闭窗口当成取消成功。
