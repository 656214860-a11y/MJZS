# 环境类错误指引

制作或登录时遇到下面的环境类提示，按对应条目自查；解决不了再按「联系方式」求助。错误提示末尾的「查看帮助：环境类错误指引 · <页名>」对应本页小节。

## FFmpeg 缺失

- 现象：剪辑、合成或试听步骤报「缺少外部工具」「ffmpeg 不存在」一类提示，视频无法合成。
- 原因：随包 FFmpeg 不在、被安全软件删除，或运行的是没有随包工具的源码副本。
- 怎么办：确认使用的是完整发布包而不是源码副本；被杀毒软件删除时在安全软件里恢复并把 `运行环境/ffmpeg/` 加入白名单，然后重启应用；都没有再重新解压一份发布包。
- 联系方式：联系客服：[待用户提供联系渠道]；附上诊断包（「00 会员账户」页可导出）和提示原文截图。

## 磁盘满

- 现象：生成或导出报「写入文件失败」「磁盘空间不足」，或文件写了一半就失败。
- 原因：项目所在磁盘或系统临时目录所在盘的剩余空间不够。
- 怎么办：清理磁盘腾出空间后重试；长期不够可把项目目录迁到剩余空间充足的磁盘，再在应用里重新打开项目。
- 联系方式：联系客服：[待用户提供联系渠道]；附上诊断包和提示原文截图。

## 模型 Key 无效

- 现象：生成任务报「缺少凭据」「凭据被服务拒绝」「余额或配额不足」。
- 原因：模型管理里没配对应服务的密钥、密钥填错或已过期、服务商账户额度用完。
- 怎么办：在模型管理里核对对应服务的密钥是否填写、是否复制完整；到服务商后台确认密钥仍然有效并重新复制粘贴；额度不足先充值再重试。
- 联系方式：联系客服：[待用户提供联系渠道]；密钥本身不要发给任何人，只附报错截图。

## 网络不可达

- 现象：生成、探测或下载报「网络请求超时」「无法连接到服务」。
- 原因：本机断网、代理或防火墙拦截了请求、服务地址暂时不通。
- 怎么办：先确认本机能正常上网再重试；使用代理的在系统代理设置里核对；公司或校园网络请网管放行对应服务地址；恢复后重试原任务。
- 联系方式：联系客服：[待用户提供联系渠道]；附上诊断包和提示原文截图。

## 账号服务不可达

- 现象：登录、续签或兑换报「连不上账号服务器」「账号服务响应超时」「账号服务证书校验失败」。
- 原因：本机网络不通、账号服务暂时故障、本机系统时间偏差过大导致证书校验失败。
- 怎么办：先检查本机网络连接和系统时间是否准确，再重试；持续失败导出诊断包（「00 会员账户」页）连同提示原文一并发给客服。
- 联系方式：联系客服：[待用户提供联系渠道]；附上诊断包和提示原文截图。
