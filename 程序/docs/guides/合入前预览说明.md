# 合入前预览说明

某条车道（并行开发分支）改了界面、还没合入正式版时，可以亲眼打开一扇预览窗口看效果，不用等合入。

## 在哪里运行

在**车道工作树**的 `程序` 目录里运行。车道工作树是仓库根目录下 `.agents\worktrees\<车道名>` 那份独立副本，里面有该车道的全部代码。

不要在主工作区（正式应用所在目录）的 `程序` 目录里跑：那里同时放着正式应用的数据，预览会被拒绝，提示「预览只能在车道工作树里开」。要看主干（正式版）效果，请直接开正式应用。

## 命令

在车道工作树的 `程序` 目录下：

```
python.exe -B scripts\dev.py preview
```

可选参数：

| 参数 | 什么时候用 |
| --- | --- |
| `--print-only` | 只建预览数据、打印路径，不打开窗口。核对命令是否可用时用它。 |
| `--reset` | 删除本工具建的预览数据目录。预览数据指到了数据目录之外、启动被拒时，先跑它再重开。 |
| `--data <目录>` | 指定预览数据目录。缺省是系统临时目录 `manju-preview\<分支名>`，不同车道各用各的，互不影响。 |

## 能看到什么、看不到什么

能看到：用当前车道代码打开的真实窗口，界面和交互都能点；窗口标题带「预览 · <分支名> · 」字样，可与正式应用同时开着。

看不到、也没有：

- 预览里装的是隔离的示例数据：临时目录下只有一个空的示例项目，不是你的真实项目。
- 没有登录、没有任何模型密钥，不能真跑模型——凡是要调模型的功能在预览里都不会真的执行。
- 不读写正式应用的设置和项目库，预览里改的东西不会影响正式应用。

## 被拒绝时怎么办

| 提示 | 原因 | 做法 |
| --- | --- | --- |
| 预览只能在车道工作树里开 | 在主工作区的 `程序` 目录跑了 | 到该车道工作树的 `程序` 目录重跑 |
| 预览数据指到了数据目录之外 | 预览数据里的项目库位置或登记项目跑到了数据目录外 | 先跑 `python.exe -B scripts\dev.py preview --reset`，再重开预览 |
| 预览数据目录不能放在代码仓库里 | `--data` 指到了仓库里面 | 换一个仓库外的目录，或不写 `--data` 用缺省目录 |
| 不是预览工具建的目录 | `--data` 指向了一个已有内容的目录 | 换一个空目录；确认里面没有要留的东西后也可手动清空 |

## 现在做不到的事

- **不能拿真实项目预览。** 真实项目的配置里记着指向原项目的绝对路径，直接复制会顺着这些路径读写原项目；等路径改写和残留检查做好后才开放。在预览里只能看示例项目下的界面。

## 看到问题怎么反馈

一句话告诉开发窗口：**哪条车道、哪一页、期望什么、实际什么**。例如：「codex/xxx 车道的项目选择页，期望列出全部项目，实际只显示一个」。
