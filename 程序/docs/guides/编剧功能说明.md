# V0.2.1 剧本准备与镜头JSON导入

双击“启动制作助手”快捷方式，顶部新增两个按钮。

## 剧本准备

填写创意，选择编剧技能阶段和目标秒数，点击“生成编剧任务书”。文件夹内包含任务书、技能原文、已有资产表、镜头JSON模板。
将任务书交给Codex执行即可。此按钮不调用语言模型，不自动写剧本，也不消耗任何视频额度。
编剧技能来自Coconah/AI-Short-Drama-Agent-Skill，原文随包存放在skills/screenplay/SKILL.md。LobeHub Marketplace配置未完成。

## 导入镜头JSON

选择JSON，程序检查编号、2–15秒镜头时长、总时长、对白时间与说话者、资产ID、PNG首帧路径。
同目录提供assets.json时使用该表，否则使用当前项目资产表。新增角色必须先在资产表登记。
首帧缺失会提示，但允许导入，之后可以在界面逐镜“替换首帧”。真实生成仍要求首帧存在。

通过校验后，界面列出镜头数、合计秒数和缺失首帧。确认后在projects目录建立独立项目。
新项目自带程序及已找到的素材。双击新项目的启动文件进入，不会覆盖原任务记录。
新项目默认离线、预算0秒：本地新建项目不意味着云端免费额度重置。

## 文件约定

JSON中的frame相对于JSON所在目录，例如frames/SH001.png；禁止绝对路径和上级目录路径。
资产表中的image同样使用表所在目录内的相对路径。导入时参考资产复制至新项目assets目录，避免覆盖镜头首帧。
已有的生成历史不自动迁入新剧本。第3镜不查询、不补交、不清除预算占用。

## 制作顺序

创意→任务书→Codex按技能编剧→人工确认→镜头JSON→导入独立项目→补齐首帧→确认实际额度→按镜生成→验收→剪辑。
本次更新只接通前面的离线交接步骤；没有实现自动写剧本API或自动首帧生成。
