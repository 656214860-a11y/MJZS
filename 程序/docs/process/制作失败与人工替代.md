# 制作失败与人工替代

各阶段手动制作窗口第四行显示人工／失败处理路径。自动操作产生的是候选结果；剧情、角色一致性、表演、授权及发布始终需要人工判断。没有已登记付费步骤不代表免费。

|用户任务|自动能力|人工确认与失败替代|继续前检查|
|---|---|---|---|
|写剧本|候选文本与结构整理|人工改稿并保存自然剧本|故事、对白和原稿版本确认|
|拆分镜|镜头初稿及提示词|人工修正镜头、时长和资产引用|初稿→预演→连续性→定稿采用|
|生成角色|资产候选生成|导入有授权素材，手工选定角色锚点|形象、服装和授权完整|
|批量出图|任务排队、技术检查与失败重试|导入／替换失败首帧|成功采用项保留，未知请求先查询|
|配音|TTS及字幕时间草稿|导入录音／授权音频，逐句听校|对白、角色声线、授权及时间同步|
|剪辑|已有素材粗剪|在剪辑软件人工剪辑；静帧运镜作为明确的替代方案|不得冒充AI动态视频成功，人工确认观感|
|导出|技术格式与清单输出|外部软件输出后导入最终成片|实际播放、完整性、商用资料分开验收|

网络或超时：先查询原任务；429等确定拒绝可在限流恢复后重试；结果未知不能自动重发。取消只停止本地后续操作，不能保证远端取消或退款。分镜、素材或成片更换后必须重新核验受影响结果。

静帧替代当前是外部人工剪辑路径，应用不会自动将预演或静帧标为正式动态视频，也不会替用户采用。人工替代的成片走质检交付页“导入剪映最终成片”及“校验并确认本阶段成果”；商用资料另行核验。尚未证明普通用户能在无指导下完成这些操作，需真实可用性验收。

## 从失败处继续操作

先进入原项目和当前集，查看失败原因；输入或采用版本已改变时，先核对当前采用分镜。未知远端任务先查询，不能把关闭窗口当成取消成功。

|遇到的问题|实际操作入口|如何判断这一步完成|
|---|---|---|
|某镜首帧无法生成|首帧管理选择该镜，点击“导入 / 替换选中首帧”，选择有使用权的图片|核对该镜预览和引用；替换后重新核验依赖它的视频，不沿用旧审核|
|TTS不可用或声音不合适|配音页点击“导入配音 / 音乐”，选择 WAV、MP3、M4A 或 AAC；用“打开音频目录”找到导入文件|完整试听、核对当前集；再点“校验并确认本阶段成果”，选择导入后的文件并人工确认|
|字幕与配音不一致|配音页“导出对白字幕 SRT”，在剪辑软件逐句听校|核对对白起止时间；导入音频不会自动完成字幕对齐，估算时间仍是草稿|
|自动剪辑或动态镜头不可用|剪辑页“整理剪映素材交接包”；在外部剪辑软件手工组装，必要时明确使用静帧运镜|完整观看实际预览，确认静帧替代效果；不得把缺失的视频任务标成生成成功|
|外部软件已经输出成片|质检交付页“导入剪映最终成片”，选择 MP4 或 MOV；再点“校验并确认本阶段成果”选择项目内导入文件|技术检查后，在“确认本集成果”中核对文件和集数，确实已完整观看才确认；导入成功本身不等于阶段已完成|

按钮名称中的“剪映”是当前界面用语；实际剪辑软件的工程兼容性需另行验证。前置条件不满足时按页面提示补齐，人工导入不会绕过门禁。商用交付另走“生成商用待填资料”及“核验商用交付资料”，不能用播放成功替代授权审核。

首次练习可从[雨夜修伞指南](../../resources/examples/rainy_umbrella/开始练习.md)开始。遇到无法继续的步骤，记下页面、按钮、提示原文及最后成功步骤，保留原素材，便于恢复。

## 环境类故障

FFmpeg 缺失、磁盘满、模型 Key 无效、网络不可达、账号服务不可达等环境类问题，见《环境类错误指引》（应用内「00 会员账户」页 · 帮助）。当前版本仍存在的用户可见问题见《已知问题》清单。
