## 一、我们收集和保存什么

「漫剧助手」是本地桌面应用。以下数据只保存在你的本机，不上传：

- 项目、剧本、分镜、结构剧本：保存在你自己选定的项目目录，只在本机读写。
- 参考图、生成图、首帧、视频、音频：保存在项目目录内，不上传（作为模型输入发出时除外，见下表）。
- 你填写的各家模型与服务密钥：以 Windows DPAPI 加密存放在程序目录 `private/密钥/` 下，不以明文保存；密钥不写入任何记录文件。
- 程序运行日志：保存在程序目录 `logs/` 下，按既定政策保留 30 天后自动清理。
- 程序配置与运行数据：保存在程序目录 `配置/`、`data/` 下。

唯一的例外：当你主动使用需要联网的功能时，对应内容会作为请求发送给你所选的服务提供方，逐项见下表。

## 二、哪些操作会外发什么

下表逐项对应 `docs/process/外发内容清单.md` 的登记节；只有在你使用对应功能时才发生，本程序没有后台遥测上报。

| 操作 | 发向哪里 | 发出的内容 | 清单对应节 |
| --- | --- | --- | --- |
| 联网采风 | 你配置的 tools 服务地址 | 搜索查询词、条数等查询参数；要抓取的页面网址；密钥只出现在请求头 | 联网采风 |
| 文字模型请求 | 你在模型管理里选择的模型地址 | 模型名、对话消息/提示词与参数；密钥只出现在请求头（Authorization 或 x-api-key）；对模型地址的可用性探测不带业务负载 | 模型请求（文字模型） |
| 图像/视频生成与云端任务 | 你选用的生成服务端点 | 提示词、参考图、任务参数；密钥只出现在请求头；生成结果按任务返回的地址下载回本机 | 图像/视频生成与云端任务 |
| 本机 ComfyUI | 本机回环地址上你自己运行的 ComfyUI 服务 | 工作流、任务查询、参考图上传；Comfy 相关密钥只随请求体发给本机服务 | 本机 ComfyUI（localhost）、密钥流说明 |
| 账号注册/登录/兑换/登出 | 账号服务地址 | 邮箱、验证码、密码、设备标识（编号、名称、系统）、刷新令牌、兑换码、协议版本；登录态经 Authorization 租约头携带 | 账号服务 |
| 更新检查 | 账号服务 | 客户端版本号（X-Client-Version），已登录时附租约头；更新发布页地址只在你点击后交给本机浏览器打开 | 更新检查 |
| 实时语音识别 | 你配置的语音识别服务（wss） | 会话配置（采样率、格式、热词等）与麦克风 PCM 音频块；密钥只出现在请求头 | 语音识别（实时 ASR） |
| 语音合成 | 你配置的 TTS 端点 | 合成文本与音色/语速等参数；密钥只出现在请求头 | 语音合成（TTS） |
| SKILL 包下载 | 你自己提供的远程 ZIP 地址 | 仅 GET 下载请求，无请求体 | SKILL 包下载 |
| 离线语音识别模型下载 | modelscope 仓库 | 模型名与修订号；本地已缓存时不联网 | 离线语音识别模型下载 |
| 连通性探测 | 你设置的 ComfyUI 地址端口 | 仅探测端口能否连通，不带业务数据 | 本机连通性探测（不带业务负载） |
| 打开外部页面 | 你点击的链接地址 | 程序只把地址交给本机浏览器打开；浏览器与目标站点之间的通信不经本程序 | 浏览器与系统打开（用户主动） |

## 三、密钥与日志如何处理

- 密钥只出现在发往对应服务的请求头里（Authorization / x-api-key），不写入日志、任务 JSON、异常栈与界面显示。
- 日志与诊断导出统一经 `infra/app_logging.redact` 脱敏：凭据字段替换为 `[已脱敏]`、邮箱替换为 `[邮箱]`、本机用户目录前缀替换为 `~`、本机用户名替换为 `[用户]`。
- 发给本机 ComfyUI 的密钥只存在于内存中的请求体，本程序不把密钥持久化到磁盘；ComfyUI 服务端自身是否在其队列或历史中留存，不在本程序可证范围。

## 四、你可以怎样关闭或删除

- 上表中的外发全部由你的操作触发，不使用对应功能即不发送；本地保存的数据无需关闭。
- 删除本机数据：删除你选定的项目目录即删除该项目与素材；删除程序目录下 `logs/`、`data/`、`private/` 即删除日志、运行数据与已存密钥。
- 账号数据的删除见下节。

## 五、账号、注销与年龄声明

- 注册账号需声明已成年；未成年不得注册。
- 注销账号有 7 天冷静期；冷静期后账号资料及后续新增数据按服务端实际表结构与隐私政策逐项清理。为防止重复试用而保留的哈希台账（不含明文身份信息）将按其保留期如实披露；未来如接入计量记录，其清理规则将单独定义。你本机的项目与素材不在服务端，不受注销影响。

## 六、默认中转站说明

- 当前版本没有任何计量上报端点：中转站不会收到你的用量记录，也不存在因此扣减的计量。
- 如未来接入，中转站将收到：作为模型输入的提示词、参考图，以及最小计量字段；其保留期与用途将在接入前以更新后的隐私文本说明。
- 你可以始终选择只使用自己的密钥（自建 Key）直连模型供应商，不经过中转站。
