# 外发内容清单

本清单登记生产代码里所有把数据送离本进程、连接远端服务或打开外部页面的出站点，
由 `tests/architecture/test_http_boundary.py` 的 `test_outbound_registry_*` 用例核对：
下表每个「文件:行号」必须对应一个真实出站点；代码里新增未登记的出站点即测试变红，
清单里登记了已不存在的出站点同样变红。

## 密钥流说明

- Comfy 提交 payload 的 `api_key_comfy_org`（orchestrator/asset_batch_execution.py 的 `extra_data`）与 `native_assets.py` 的 dispatch `api_key`：只在内存随 `/prompt`、`/drama/assets/dispatch` 请求发给本机 ComfyUI 服务。
- 只读核验：`native_assets.py` 的批次落盘记录序列化字段为 request/options/items，不含密钥；`infra/cloud_assets.py` 的工作流构建不含密钥字段——未见密钥被持久化到本仓磁盘（外部 ComfyUI 自身是否留存在其队列/历史中不在本仓可证范围，与 `维护记录/密钥流审计_20261002.md` 的存疑结论一致）。
- 模型请求密钥只进请求头（Authorization / x-api-key），不写入日志：日志与诊断导出走 `infra/app_logging.redact` 统一脱敏。
