# 生成服务失败处理契约

## 范围与权威
模型和能力仍来自模型池/ModelAdapter；不是另建模型列表。ModelRouter.chat 使用 SKILL fallbackModels 实施有限次切换，显式指定模型不自动替换。仅候选能力覆盖原请求的全部声明时才尝试；每个模型最多调用一次。切换前重新检查现有 Budget 配额及执行期限；该配额不是供应商实付金额或价格保证。

## 统一失败事实
failure_policy 接受 status、accepted（true/false/未知）、provider_task_id/task_id、response_meta.response_id，输出 acceptance、reason_code、retryable、provider_task_id。供应商编号或已受理证据优先于错误码；不能仅凭5xx判定未受理。只有供应商适配器能够证明未受理时才可传 accepted=false。

| 场景 | 分类 | 自动动作 |
|---|---|---|
| 429且无受理证据 | rate_limit/not_accepted | 可尝试已配置且能力兼容的下一个备用模型，无同模型循环重试 |
| 5xx无受理证据 | server_error/unknown | 停止，核对供应商，不重提 |
| 5xx且明确未受理 | server_error/not_accepted | 可切换，重查配额/期限 |
| 401/403 | authentication | 停止并修正凭据，不向另一供应商传播请求 |
| 400/404/422 | unsupported_request | 停止，检查能力/请求协议 |
| 超时、网络中断、流式响应残缺 | receipt_unknown | 停止并核对，流式不能透明再次发送普通请求 |
| 有远端编号但本地失败 | accepted | 保留编号、查询/恢复，禁止自动重提 |
| 执行取消/过期 | 本地停止 | 不开始下一次调用；不声称远端停止 |

## 多模态执行边界
| 类型 | 能力/请求配置权威 | 期限与恢复 |
|---|---|---|
| 文本/图像理解 | 模型池与ModelAdapter，SKILL能力声明 | chat/stream服从ExecutionControl剩余期限；失败切换使用上述契约 |
| 图像生成 | Comfy工作流/资产批次冻结请求 | 资产批台账与Comfy回执保存编号；取消/超时继续核对，不跨模型猜测恢复 |
| 视频生成 | 云/本地Studio冻结版本请求 | 视频版本台账保留task_id/local_request/execution；未知状态先查询，禁止以备用模型覆盖原尝试 |
| 音频生成 | TTS服务与语音配置 | 仍按既有服务返回结果和发布门禁验收；未提供受理证明的失败不得自动切换付费请求 |

本轮运行失败切换的产品入口为ModelRouter.chat。媒体路径不会因此新增跨供应商提交；若未来增加媒体备用，必须先适配上述受理事实、能力和预算检查，并保留原尝试。取消是本地控制，不证明供应商停止或退款。真实供应商行为、计价和账单沿用实际使用阶段验收，不发起付费测试。
