# 配置说明

这三类 JSON 不合并：它们分别服务于安装级、项目运行级与项目界面级生命周期。应优先通过应用界面或下列统一入口修改，避免手工覆盖未知字段。

| 文件 | 归属与用途 | 主要读写入口 |
| --- | --- | --- |
| `desktop_settings.json` | 程序目录；保存本机桌面偏好，例如 ComfyUI 地址、剪映路径与当天项目选择。不是项目数据，换项目时不复制。 | `desktop.py`、`comfy_runtime.py` |
| `<项目>/config.json` | 项目运行参数，例如视频后端、媒体工具路径、分辨率、时长与本地秒数预算。新建或打开项目时由项目服务管理。 | `engine.py`、`projects.py`、`app.py` |
| `<项目>/ui_settings.json` | 项目界面与助手行为偏好，例如当前分镜指针、自动制作开关及页面选择。只保存助手行为类设置，不承载阶段模型/SKILL。 | `project_settings.py`、`storyboard_selection.py` |

阶段模型和 SKILL 另存于 `<项目>/skill_config.json`，不属于上述三类配置。密钥也不写入这些 JSON：仅按变量名从 `.env`、`private/.env` 或 DPAPI 密钥文件读取。

若配置文件被手工改坏，应停止编辑并从项目备份恢复；`project_settings.read()` 对 `ui_settings.json` 会给出可操作的损坏提示，其他配置应通过对应页面重新保存。
