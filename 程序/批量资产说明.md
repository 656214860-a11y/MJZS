# 批量资产生成

ComfyUI 工作流基于官方 Z-Image-Turbo 模板：
https://docs.comfy.org/tutorials/image/z-image/z-image-turbo
https://github.com/Comfy-Org/workflow_templates/blob/main/templates/image_z_image_turbo.json

原始画布：z_image_official.json；批量API版本：z_image_assets_api.json。
适配：768×768、每资产1张、8步、文本编码器CPU；不保证8GB显卡的速度与显存表现。
服务地址默认 http://127.0.0.1:8189。使用已安装的 z_image_turbo_bf16、qwen_3_4b 和 ae 模型。

选择类别，点击开始批量制作。已导入资产跳过，生成图片按资产编号和名称保存并登记。
如提交状态不明，不自动重发；请检查 ComfyUI 队列与项目 workflows/资产批量记录.json。
自定义工作流必须使用API格式、指定正向提示词节点，并且每个资产仅输出一张PNG。

Imagen SKILL 制作使用资产制作的引擎和 Skill 设置。首次进入 Codex 后需发送任务，之后由 Skill 批量制作。
助手打开时自动监测批次输出并登记；若助手关闭，重新进入资产管理后继续监测。
没有图像生成工具的引擎不能凭 Skill 文件获得生图能力。
