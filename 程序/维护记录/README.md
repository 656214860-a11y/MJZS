# 维护记录索引

`程序/维护记录/` 是工程治理资料库。本文把顶层文件按 Diátaxis 近似四格分区（不改名、不移动）：**一类·当前有效基线**（门禁/工具实际读取的 JSON、政策与口径文档）、**二类·审计快照**（一次性审计，只作历史证据）、**三类·路线图与待办**（当前有效计划）、**四类·归档**（历史记录，不作当前验收）。每条格式：`文件名 — 一句话用途｜是否当前有效（是/否）｜谁读`。
