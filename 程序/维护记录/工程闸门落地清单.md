# 工程闸门落地清单

目标：把“好代码”的标准从依赖自觉变成系统里不可绕过的约束。按 约束层 → 闸门层 → 观测层 → 演进层 递进，每个批次是一轮（可独立回滚的变更集）。

- 来源：2026-11-15 对「漫剧助手」按四层逐项核查的结论；证据与取舍见同日会话。
- 执行方：SWE-2（用户 2026-11-15 授权）。按 `程序/AGENTS.md` §4，执行方即领号、测试、提交方。
- 状态记法：`[ ]` 未开始　`[~]` 进行中　`[x]` 完成（须附结果文件轮次与 commit hash）　`[!]` 阻塞（须写证据）。

## 授权范围

| 事项 | 状态 |
| --- | --- |
| 批次 1、2、3 | 已授权，按顺序直接执行 |
| 批次 1.3：合入前强制 `exit` 档（约 4 分钟）＋pre-commit 增加快速静态门禁 | 用户已接受 |
| 批次 4（G2、G5、G6、G7、G8、E1–E3） | 每项开工前先向用户确认；G2、G5 须先有批次 3 的基线数据 |
| §2.3“暂无守卫”规则的降级或删除 | 只有用户能决定；SWE-2 只列清单 |
| 服务器（`backup` 远端）操作 | 不授权；只产出脚本与说明，由用户部署 |
| `git push`、改 `程序/data`、`程序/private`、`程序/logs`、用户项目目录 | 不授权 |

## 统一规则（每个任务都适用）

**开工前**
- 读 `程序/AGENTS.md` §0、§2.5、§2.6、§5、§8 与 `程序/runbook.md` §12–§13。
- 工作目录 `程序/`；解释器 `运行环境\Python\python.exe`（工作树里没有就用 `D:\漫剧制作助手\运行环境\Python\python.exe`）。测试带 `PYTHONPATH=tests;.`；含 Tk 的测试经 `工作流任务\gui_hidden.py`。
- 先 `git status`，只暂存本任务文件，不混入他人的未提交改动。
- 新开 `codex/<任务名>` 工作树，不在 master 上改 `程序/` 源码（规则 34a）；用 `维护记录/基准脚本/round_claim.py next` 领号。

**完成标准**
- 新增规则同轮带自动化测试（规则 26）；先红后绿，红的输出贴进结果文件。
- 已有测试的断言不改、不弱化、不跳过（§2.4）。
- 结果文件 `程序/tasks_round/tasks_round_N_result.md` 开头回答三问，并写明 commit hash。
- 提交用 `scripts\dev.py commit -m "R<N>: 说明" <文件...>`；`project_status.md` 只在 master 提交。
- 失败按 §8 闭环；回滚用 `git revert`，不用 `reset --hard`。
