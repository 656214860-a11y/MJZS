# UI 内联设计值审计（C4）

## 口径

- 扫描 UI Python 源中的内联 `#RGB` / `#RRGGBB`：205 行命中。
- 扫描布局、尺寸和字体参数中的数字字面量：422 行候选。
- 数字不等于违规：窗口尺寸、表格列宽、动画节奏和画布绘制须逐项分类，不能机械替换为 `SPACING`。

## 优先级

1. `ui_theme.py`、`pet_ui.py`、`desktop.py`、`asset_detail.py` 的页面级颜色先归入 `ui_tokens.COLORS`。
2. 业务页的 `padx` / `pady` 只允许 `SPACING`；列宽、内容最大长度保留为领域参数。
3. 新增 `ui_tokens.py` 的 token 定义、`ui_icons.py` 像素绘制、`ui_theme.py` ttk 原生绘制可作为初始白名单；每一项须标出用途与所有者。

## 棘轮建议

首轮不要冻结“全文件豁免”。基线应按 `(文件, 行, 属性类别)` 登记；除白名单外，内联 hex 与间距数字只能减少。先迁移高频页面，再把已迁移位置从白名单移除。

## 验收

- 新增业务页不引入内联 hex 或 `padx` / `pady` 数字字面量。
- 现有基线计数非递增；任一新增项必须有 token 化或白名单理由。
- 视觉回归覆盖主题、资产表、弹窗与滚动条。
