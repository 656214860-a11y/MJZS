# 自动协作使用说明

任务队列的唯一可写权威是 Git common-dir 的 `maintenance-queue.json`；工作树内
`任务队列.json` 仅是自动导出的只读快照，不替代 `tasks_round` 或项目台账，禁止手工编辑。

认领前先查看：`python 维护记录/基准脚本/round_claim.py show`。认领使用
`python 维护记录/基准脚本/round_claim.py claim M1-remaining --owner <工作区或操作者>`。
旧命令 `python 维护记录/claim_queue.py ...` 仅作兼容转发，完全等价于上述权威入口，不能再写工作树快照。
认领、释放与收口使用 common-dir 锁和原子替换；`show` / `validate` 为只读操作。

提交轮次前运行：`python 维护记录/基准脚本/round_gate.py <branch> <round>`。
它只做机械复核：当前分支、8 项冒烟声明、架构测试数量、73 条 SKILL 注册、状态轮次、结果报告的定向/凭据证据，以及已暂存文件不得包含 `tasks_round`。任何红项均返回非零；基础设施分支没有结果报告时出现红项是预期的，不应伪造结果报告来通过它。
