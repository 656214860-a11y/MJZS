## 二、逐条「改前 → 改后」

### 1. 聊天框右上角那两颗「放大／缩小」撤掉

- `程序\ui_theme.py`：新增 `bare_window(win)`。

  ```
  改前：弹窗那两颗「最小化／最大化」由 install_window_placement 的 hidden_init 给每个
        tk.Toplevel 长出来（接线只有这一处），三虎的云朵框也照长。
  改后：bare_window(win) 把已经长出来的按钮条 place_forget() ＋ destroy()，留下
        win._drama_buttons=None 与 win._drama_buttons_ready=True 两个记号；
        window_buttons() 开头就认 _drama_buttons_ready，之后再问也不长回来。
  ```

- `程序\pet_cloud.py`：`build()` 里建完 Toplevel 就调 `ui_theme.bare_window(win)`（包在 try 里记账，
  拿不到 `ui_theme` 也不影响云朵框本身）。云朵自带的那颗红底白 × 不受影响。

### 2. 初步分镜：按钮行与说明行先占位

- `程序\storyboard_files.py`：

  ```
  改前：labels[kind] 那行说明与 actions 那一排按钮排在表格之后，表格一长高就被挤成 0 像素；
        整页高度又刚好不需要滚动，按钮既看不见也滚不出来。
  改后：分镜那一支 actions.pack_configure(side='bottom', before=tree.master)、
        label_row.pack_configure(side='bottom', before=tree.master)；
        剧本那一支 note.pack(side='bottom', anchor='w', pady=(4,0), before=tree.master)。
        位置不够时该缩的是表格，不再是按钮。
  ```

### 3. 悬停放大尺寸缩一半

- `程序\cell_hover.py`：`ZOOM_SIZE = 480`（原 960）。各页的悬停放大都读这一个常量——
  `app.py`（资产页两处、首帧页一处）、`asset_reference_images.py`（参考图）、`desktop.py`
  （资产／首帧两处）——改一处全部跟着变。`asset_detail.ZOOM_SIZE = 900` **未动**：那是「点一下
  看原分辨率」，与悬停放大是两件事。

### 4. 开机一律回到「只提醒」档

- `程序\pet_ui.py`：

  ```
  改前（第 44 期）：用户选的档写进全局配置，下一次开机照它来。
  改后：新增 Pet.start_level()：agent.set_level(pet_agent.DEFAULT_LEVEL)、
        auto.armed = False、auto.paused = False，返回当前档。
        配置里那把键照旧留着（用户下次切档时会重写），开机那一下不冒云、不报错。
  ```

- `程序\pet_ui.py` 模块级 `start()`：先 `pet.start_level()`，再 `reset_cloud()`，再 `schedule_greet()`。

### 5. 自动档自动开始每个阶段

- `程序\stage_flow.py`：新增 `DONE_STATES = ('success', 'skipped')`、`PAID_STAGES = ('assets',
  'video', 'audio')` 与 `Auto.arm_from(level, states)`——先走 `script_done(level)`，武装后按项目
  现状把已经收场的那几步跳过，队长从第一个没做完的阶段接手；`states` 给不出来就退回老规矩（从头走）。

- `程序\desktop.py`：新增 `UNATTENDED_SWITCH`（轮询名 → `project_settings.set_auto_*` 开关）与
  `Desktop.pet_start(stage)`——先把这一步的无人值守开关替他打开，再 `pet_advance()` 叫醒一轮；
  没有无人值守的那几步给空串。

- `程序\pet_ui.py`：新增 `Pet.stage_states()`、`Pet.arm_auto()`、`Pet.start_stage(stage)`。
  `start_stage` 分镜／首帧走免费的准备链（`storyboard_batch`／`firstframe_batch`），其余走
  `pet_start`；放行不了的退成「只叫醒」；**只提醒档一开头就返回空串**，一个阶段都不开。
  `tune_advance()` 那一拍改调 `start_stage()`；`Pet.set_level()` 切到 semi／auto 时调 `arm_auto()`、
  切回 hint 时 `auto.armed = False`。

- 一处返工：`arm_auto()` 起初放在 `auto_stage()` 里，每拍抢在状态机前面吃掉一格，
  `test_pet_ui.AdvanceTests` 三条立刻变红。改到「用户切档」那一下，两边的口径才对上。

## 三、顺带修掉的真 bug：弹窗还原之后掉线

- `程序\ui_theme.py`：`window_buttons()` 的 `put_owner_back()` → `back()`。

  ```
  改前：<Map> 之后隔 150 毫秒 win.transient(owner)。实测在刚还原那一拍，Tk 会把窗口重新
        压成 withdrawn——窗口看不见、任务栏也点不回来（第 65 期「最小化后不可见」的另一半）。
  改后：back(attempts=0)：状态还是 iconic／withdrawn 就隔一拍重试（最多 8 次，不硬拽窗口）；
        挂完 owner 若当场变 withdrawn，立刻再 deiconify() 一次把窗口救回来。
  ```

  探针抓到的时序：`transient(None) → '' / normal`，紧接着 `transient(<win>) → 'withdrawn'`。
  修前 test_ui_theme 连跑 8 次 **8 红**，修后连跑 8 次 **0 红**。
