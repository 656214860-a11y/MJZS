# 路线图 2026-10-14：功能与工程缺口

来源：R1425 前对 10 个制作阶段与模块清单的缺口盘点（按文件清单与状态页判断，非逐模块代码审计；每项开工前先核验现状，避免重复实现）。每项为一个独立轮次，按优先级顺序执行，各自领号、各自验收。

| 编号 | 缺口 | 目标 | 前置/依赖 | 验收口径 |
|---|---|---|---|---|
| A | CLI 失败无明显提示；CLI 条目可指向 Claude Desktop 图形程序 | 失败给弹窗；保存与调用前识别图形程序并给出改法 | 无 | 定向用例 + 受影响 UI 用例 |
| B | 外部依赖无统一自检 | 一页检查 ffmpeg／ComfyUI／Blender／桌面 Claude／Codex／模型密钥，给"下一步" | 复用 `white_model_service.diagnose`、`find_program`、`engine_probe` | 只读检查，不写用户数据；每项状态与建议用例化 |
| C | 无项目级成本总览 | 按项目／集／阶段汇总 `RequestLedger` 用量，token、秒、次数不跨量纲相加 | 依赖 R1354 账本；先核验账本是否落盘 | 汇总数与账本逐项对账 |
| D | 无剪辑软件交付出口 | 导出 EDL／FCPXML 与分轨素材清单；剪映草稿先评估格式稳定性再定 | `engine.output_spec`、`subtitle_timing` | 导出文件结构校验；不调用外部软件 |
| E | 镜头多候选无并排对比与回退 | 同镜头候选并排、一键回退到旧版本（沿用显式采用语义） | `artifact_lineage`、`video_lifecycle_service` | 回退不删原稿，来源账本一致 |
| F | 音频只有对白 TTS 与导入 | 分轨（对白／旁白／BGM／音效）清单与混音参数；BGM／音效生成先做接口与匹配，不绑定供应商 | `tts_api.AUDIO_KINDS`、`audio_import_service` | 分轨清单与混音滤镜可测，不调用真实服务 |
| G | 无持续集成；hooks CRLF；Linux/Windows 用例分歧 | hooks 换行修复；平台相关用例显式标注；CI 配置草案 | 用户确认 CI 平台（GitHub Actions 或本地） | 随附解释器在 Windows 全量通过 |

## 约束

- 沿用 AGENTS.md 轮次、分层、状态页与五轮全量规则；每轮单独提交（`R<N>:`）。
- 涉及付费或真实模型调用的验收一律不自动执行。
- 外部软件格式（剪映草稿等）无稳定公开规范时只做评估报告，不臆造格式。
- G 中的 CI 平台与仓库托管需用户决定，其余可自行推进。
