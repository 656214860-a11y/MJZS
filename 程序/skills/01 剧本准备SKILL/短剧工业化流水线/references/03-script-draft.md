## 一、岗位职责与边界

### 1.2 岗位边界

| 维度 | 本岗位做 | 本岗位不做 |

### 1.3 硬性前置条件

- ✅ Gate A已通过（岗位2大纲经用户确认）

## 二、五阶门控开发流水线（引用SD screenplay-dual-hook-engine.md）

> 方法论归属：短剧双层钩子创作法（扣子独立版已内化，无需外部文件） 第四部分

动笔写每集剧本前，必须依次通过五道门禁（Gate1→Gate1.5→Gate2→Gate3→Gate4→Gate5），严禁跳过结构直接写大段台词。

### 2.1 门禁总览

| 门禁 | 名称 | 核心任务 | 通过标准 |
|------|------|---------|---------|
| Gate 1 | 前提（Premise） | 30字前提公式 + 黄金钩子类型选择 + 视觉钩子设计 | 前提一句话能让人想知道后续 |
| Gate 1.5 | 钩子适配（Hook Adaptation） | 将大纲钩子适配为具体开场画面+叙事钩子 | 视觉钩子0-2秒+叙事钩子3-10秒双层到位 |
| Gate 2 | 前3秒（Opening 3s） | 单集三幕时间比例分配 + 结尾卡点设计 | 三幕比例30%/50%/20% + 卡点钩子明确 |
| Gate 3 | 中段双压（Mid Double Pressure） | 场景因果节拍表 + 每场戏因果链完整 | 承重戏完整五段，无废场 |
| Gate 4 | 三重反转（Triple Reversal） | 世界观与实体边界校验 + 反转逻辑自洽 | 反转有伏笔，无机械降神 |
| Gate 5 | 终局（Finale） | 语义化标准排版输出 | 完整剧本页结构，无心理描写 |

### 2.2 各门禁详解

#### Gate 1：前提（Premise）

**30字前提公式**：
```
[主角] + [核心欲望] + [不可抗力阻碍] + [失败的致命代价]
```

本岗位在写每集前，须确认该集的核心前提是否与大纲一致：
- ✅ "废柴少年想救被抓走的妹妹，但他只有三天时间，还被全江湖追杀"
- ❌ "一个剑客想要变强"（无阻碍、无代价）

**黄金钩子类型**（6种选其一）：

| # | 钩子类型 | 核心机制 | 适用场景 |
|---|---------|---------|---------|
| 1 | 极端悬念钩 | 生死悬于一瞬，观众想知道"能不能活" | 枪口抵头、刀架脖子、坠落中 |
| 2 | 认知反差钩 | 身份反转，最弱的人居然是最强的 | 外卖员是宗师、赘婿是隐世高手 |
| 3 | 情绪爆发钩 | 至亲受辱/背叛，怒气值瞬间拉满 | 未婚妻退婚、亲人被欺负 |
| 4 | 视觉奇观钩 | 超自然现象出现，震撼视觉 | 天雷裂空、法相降临、时空撕裂 |
| 5 | 关系/情感钩 | 亲密关系突然断裂，情感冲击 | 离婚、分手、久别重逢 |
| 6 | 喜剧反差/信息缺口钩 | 错位误会或悬念线索，好奇后续 | 穿错衣服、认错人、神秘线索 |

**视觉钩子设计**：开场前2秒须明确写出使用哪种钩子模式（细节拉出/光影冲击/慢动作冲击/视角代入/规模揭示/反射揭示/颜色爆发/遮挡揭示/运动冲击/微表情定格）。

#### Gate 1.5：钩子适配（Hook Adaptation）

将岗位2大纲中的钩子设计适配为本集的具体开场画面。须同时满足双层钩子铁律：

| 层面 | 作用时间 | 核心问题 | 观众反应 |
|------|---------|---------|---------|
| 视觉钩子 | 0-2秒 | "这画面好特别，停一下看看" | 停止划动 |
| 叙事钩子 | 3-10秒 | "发生了什么？接下来会怎样？" | 继续观看 |

**标准时间轴**：
```
0-0.5秒：[视觉冲击] + [打光特征]    → 抓住眼球
0.5-1秒：[揭示] + [情绪锚点]         → 建立情绪
1-2秒：  [摄像机运动] + [深度线索]   → 给出承诺
```

#### Gate 2：前3秒与三幕结构（Opening 3s & Three-Act）

**单集三幕时间比例**（按目标时长换算）：
```
铺垫建立 约30% → 核心冲突危机 约50% → 转折爆发与卡点 约20%
```

示例换算：
- 60秒 → 0~18s / 18~48s / 48~60s
- 90秒 → 0~27s / 27~72s / 72~90s

**结尾卡点钩子（Cliffhanger）**四种类型：
- 决策关头——"他会怎么选？"
- 身份暴露瞬间——"被发现了！"
- 援兵突现——"谁来了？"
- 攻击命中前一帧——"打中了吗？"

> 独立/完结算集可不强制挂钩，以情感余韵或主题落点收尾。

#### Gate 3：中段双压（Mid Double Pressure）

**场景因果节拍表**——每场戏必须通过"场次存在性法则"：

> 一场戏如果删掉后不影响后续剧情，立即删除。

**每场戏因果链**：
```
场景目标 → 遭遇阻碍 → 升级行动 → 意外转折 → 产生新局面
```

- 承重戏（高潮/反转/情感爆发）：必须完整五段因果链
- 过场戏（过渡/交代）：允许只承担一种功能（推进信息/铺垫情绪/建立关系）

#### Gate 4：三重反转（Triple Reversal）

**世界观与实体边界校验**：
- 时代法则：明确时代背景，锁定法律、战力天花板与技术极限
- 人际关系网络：明确上下级、仇恨、盟友关系，杜绝无动机叛变
- 战力体系：明确力量等级划分，避免"突然变强"的剧情崩坏

反转须有伏笔铺垫，严禁机械降神（天降救兵/突然觉醒新能力）。

#### Gate 5：终局·标准排版（Finale）

输出完整语义化标准剧本页（见第三部分标准格式）。

## 三、标准短剧剧本格式

### 3.1 场景标题格式

```
第X集
X-1 内 场景名 日/夜
```

字段说明：
- `第X集`：集数编号
- `X-1`：集内场次编号（如第3集第1场 = 3-1）
- `内/外`：内景或外景
- `场景名`：具体地点（如"林府正厅""城外破庙"）
- `日/夜`：日景或夜景

### 3.2 完整场景格式

```text
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
第3集
3-1 内 林府正厅 夜
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
出场人物：@林婉（表面平静·暗藏不安）、@赵管家（居高临下）
场景功能：推动剧情+制造悬念
情绪弧线：平静 → 压迫 → 暗涌
信息增量：林婉得知父亲死讯并非病故
前后衔接：
  ▶ 承接上一场：3-0结尾林婉踏入府门
  ▶ 引向下一场：林婉决定夜探灵堂

【景别/镜头指示】大全景→中景
林府正厅，烛火通明。赵管家立于堂中，手持一封信。
林婉推门而入，脚步微顿。

赵管家（居高临下）：大小姐回来了。老爷走了。

林婉（指尖微颤）：……什么时候的事。

赵管家：昨日亥时。大夫说是急症。

林婉（目光锐利）：急症？（停顿）我父亲从不生病。

【镜头停在林婉攥紧的拳头上｜本集钩子结束】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

### 3.3 格式要素速查

| 要素 | 格式 | 说明 |
|------|------|------|
| 场景标题 | `X-Y 内/外 场景名 日/夜` | 必须包含集数+场号+内外+地点+日夜 |
| 景别指示 | `【景别/镜头指示】动作描述` | 大全景/全景/中景/近景/特写 |
| 角色台词 | `角色名（情绪）：台词` | 括号内标注情绪状态 |
| 动作描写 | 纯行为描述 | 只写可拍摄的动作，禁心理描写 |
| 钩子结束 | `【镜头停在XX｜本集钩子结束】` | 每集结尾必须标注卡点画面 |
| 场景功能 | `场景功能：[类型]` | 推动剧情/建立关系/制造悬念/情绪爆发/过渡 |
| 情绪弧线 | `情绪弧线：[开场] → [峰值] → [结尾]` | 标注本场情绪变化轨迹 |
| 前后衔接 | `▶ 承接上一场 / ▶ 引向下一场` | 确保场景间因果连贯 |

### 3.4 景别术语对照

| 术语 | 含义 | 适用场景 |
|------|------|---------|
| 大全景 | 展示整体环境 | 场景建立、规模揭示 |
| 全景 | 人物全身+环境 | 人物入场、动作展开 |
| 中景 | 人物腰部以上 | 对话、日常互动 |
| 近景 | 胸部以上 | 情绪表达、关键对话 |
| 特写 | 面部或局部细节 | 微表情、关键道具、情绪爆发 |
| 极端特写 | 极小局部（瞳孔/手指） | 视觉钩子、关键细节 |

## 四、行业铁律：禁止小说式心理描写

### 4.1 核心法则

> **短剧剧本中的一切文字必须可视化——观众能在画面中看到，演员能用身体表演。**

短剧是视听媒介，不是文学。小说可以写"她心里一阵酸楚，想起了十年前那个雨夜"，剧本绝对不行。剧本只写观众能看到和听到的。

### 4.2 禁止清单

| 禁止类型 | ❌ 错误写法（小说式） | ✅ 正确写法（剧本式） |
|---------|---------------------|---------------------|
| 心理描写 | "她心里一阵酸楚" | "她垂下眼，嘴唇微抿，指尖无意识地搓着袖口" |
| 回忆插入 | "她想起了十年前那个雨夜" | 【闪回·雨夜】小女孩跪在泥水中，面前是一扇关上的门 |
| 感受陈述 | "他感到一阵前所未有的恐惧" | "他后退一步，撞上墙壁，瞳孔骤缩" |
| 旁白内心 | "如果当时我没有离开……" | 角色对着空房间说："如果当时我没有离开……" |
| 抽象状态 | "空气中弥漫着尴尬" | "两人沉默，只有茶杯碰桌面的声音" |
| 全知视角 | "她不知道的是，门外站着他" | 【切镜·门外】门缝外，一双靴子纹丝不动 |

### 4.3 可视化转化原则

1. **情绪→动作**：所有情绪必须转化为可拍摄的身体语言（微表情、手势、步态、姿态变化）
2. **回忆→闪回**：需要回忆时用闪回画面，标注`【闪回·时间】`，不用文字描述回忆内容
3. **内心→外化**：内心独白要么删掉（用行为暗示），要么转为角色自言自语
4. **氛围→感官**：抽象氛围用五感描写（声音、光影、温度、气味、视觉细节）
5. **信息→行为**：背景信息通过角色在冲突中的行为释放，不用旁白解说

## 五、麦基叙事法（三幕结构+人物弧光）

> 调用时机：本岗位写初稿时按需调用，作为叙事质量增强层
> 路径：`（扣子独立版已内化的技能模块）`

### 5.1 引擎一·故事结构（三幕）

来源：罗伯特·麦基《故事：材质、结构、风格和银幕剧作的原理》

| 模块 | 核心功能 | 在初稿中的应用 |
|------|---------|--------------|
| 1.2 故事五部分 | 激励事件→进展纠葛→危机→高潮→结局 | 每集结构骨架校验 |
| 1.5 幕设计 | 三幕递进，每幕高潮须比前一幕更强 | 单集三幕节奏校验 |
| 1.6 场景设计 | 每个场景须至少完成一个价值转换 | 场景存在性验证 |
| 1.9 场景分析 | 五步程序定位场景动力结构 | 节拍递进形态检查 |
| 1.10 布局谋篇 | 节奏与过渡设计 | 场景间过渡衔接 |

**三幕结构在单集中的映射**：

```
第一幕·建置（约30%）
  → 激励事件：打破平衡的事件
  → 建立冲突：主角面临不可回避的挑战

第二幕·对抗（约50%）
  → 进展纠葛：阻碍层层升级
  → 中点转折：局势发生质变
  → 危机：主角面临最大困境

第三幕·解决（约20%）
  → 高潮：主角做出关键选择
  → 结局（卡点）：新局面产生，留悬念
```

### 5.2 引擎二·人物弧光

来源：罗伯特·麦基《人物：文本、舞台、银幕角色与卡司设计的艺术》

| 模块 | 核心功能 | 在初稿中的应用 |
|------|---------|--------------|
| 2.1 塑造vs真相 | 表面特征可欺骗，压力下的选择才揭示真相 | 角色行为设计双字段 |
| 2.3 选择揭示人物 | 转折点必须是主动选择而非被动事件 | 关键场景选择设计 |
| 2.5 人物退化与成长 | 三轴弧光（道德/心智/人性） | 角色弧线一致性检查 |
| 2.8 人物内写作 | "如果我是这个角色"的正确问法 | 台词与行为动机校验 |

**人物弧光三段式**：
```
开篇状态 → 转折（压力下的选择） → 终局状态
```

每集剧本须确保角色行为与其弧光阶段一致：
- 开篇阶段：角色表现出初始状态的特征（弱小/隐忍/无知等）
- 转折阶段：角色在压力下做出关键选择，暴露真实面目
- 终局阶段：角色达到新的状态，与开篇形成对照

## 六、节拍表方法论

> 调用时机：本岗位规划场景内部节拍时引用其方法论
> 路径：`（扣子独立版已内化的技能模块）`

### 6.1 节拍表（Beat Sheet）方法论

节拍表编写法提供了精确的场景节拍设计方法，本岗位在场景内部结构设计时直接使用：

**节拍表结构**：

| 节拍 | 时间码 | 场景 | 事件 | 情绪 | 镜头类型 | 时长 | 角色内在状态 | 声音情绪 |
|------|--------|------|------|------|---------|------|------------|---------|

**节拍表编写规则**（适配短剧初稿）：
- 每个节拍时长 5-10 秒（防止内容过密导致角色漂移）
- 相邻节拍的情绪要有变化（平静→紧张→爆发），创造节奏感
- 每场戏拆分为 3-6 个节拍，确保因果递进
- 承重戏节拍更密（5-6个），过场戏节拍更疏（2-3个）

### 6.2 在初稿中的应用方式

本岗位不产出完整节拍表（那是分镜阶段的任务），但在写每场戏时参考节拍表思维：

```
场景内部节拍设计（初稿阶段）：

节拍1（0-5s）：人物入场/画面建立
  → 动作：[角色进入场景，建立空间关系]
  → 情绪：[初始情绪状态]

节拍2（5-15s）：冲突展开/信息交换
  → 动作：[核心互动开始，矛盾暴露]
  → 情绪：[情绪升级]

节拍3（15-XXs）：转折/升级
  → 动作：[意外发生或冲突升级]
  → 情绪：[情绪峰值或反转]

节拍4（最后3s）：收束/钩子
  → 动作：[本场结尾状态]
  → 情绪：[情绪落点或悬念残留]
```

## 七、BiFish SOP系统提示词模板

> 来源：行业短剧编剧SOP方法论（BiFish系统提示词范式）

### 7.1 标准系统提示词模板

以下模板可在本岗位启动时作为系统提示词框架使用，根据具体项目填充`[题材]`等变量：

```
你是一位有5年经验的短剧金牌编剧。请为我创作一个[题材]的短剧剧本。

节奏要求：
- 每集必须有钩子（开场前3秒抓住观众）
- 前3集必须埋下核心矛盾
- 每5集一个打脸反转
- 每集结尾必须有卡点（让观众追更）

台词要求：
- 台词简洁，不超过20字/句
- 角色说话风格区分明显
- 禁止心理描写，一切可视化

格式要求：
- 场景标题：X-Y 内/外 场景名 日/夜
- 动作描写：只写可拍摄的行为
- 台词格式：角色名（情绪）：台词
- 每集结尾标注：【镜头停在XX｜本集钩子结束】
```

### 7.2 节奏硬性要求

| 要求项 | 标准 | 说明 |
|--------|------|------|
| 每集钩子 | 必须有 | 开场前3秒设计视觉+叙事双层钩子 |
| 前3集核心矛盾 | 必须埋下 | 第1-3集建立全剧核心冲突线 |
| 每5集打脸反转 | 必须有 | 被轻视→展示实力→震惊全场的爽点循环 |
| 每集卡点 | 必须有 | 结尾留悬念让观众追更 |
| 单句台词 | ≤20字 | 保持紧凑节奏，超24字强制拆镜 |

### 7.3 题材适配指南

| 题材 | 节奏特征 | 钩子偏好 | 反转频率 |
|------|---------|---------|---------|
| 赘婿/逆袭 | 快节奏，每集打脸 | 认知反差钩 | 每2-3集一次 |
| 修仙/玄幻 | 中快，视觉奇观 | 视觉奇观钩+规模揭示 | 每3-5集一次 |
| 甜宠/情感 | 中速，情绪推拉 | 关系/情感钩 | 情绪反转每集 |
| 复仇/悬疑 | 中慢，悬念积累 | 极端悬念钩+遮挡揭示 | 每5集大反转 |
| 喜剧/爽文 | 快速，信息密集 | 喜剧反差钩 | 每1-2集一次 |

## 八、时长预算与场景规划

### 8.1 单集时长预算

| 指标 | 标准 | 说明 |
|------|------|------|
| 单集时长 | 60-90秒 | 根据知识库赛道定位确定 |
| 场景数 | 3-8场/集 | 承重戏少而精，过场戏快而简 |
| 台词占比 | ≤40%总时长 | 短剧以动作为主，台词辅助 |
| 动作/画面占比 | ≥60%总时长 | 确保视觉化叙事 |

### 8.2 场景数与时长分配参考

| 单集时长 | 场景数 | 开场钩子 | 核心冲突 | 结尾卡点 |
|---------|--------|---------|---------|---------|
| 60秒 | 3-5场 | 5-8秒 | 35-45秒 | 5-8秒 |
| 75秒 | 4-6场 | 6-10秒 | 50-60秒 | 6-10秒 |
| 90秒 | 5-8场 | 8-12秒 | 60-70秒 | 8-12秒 |

### 8.3 场景类型与五感密度

引用SD screenplay-dual-hook-engine.md 第五部分：

| 场景类型 | 五感密度 | 描写长度 | 功能 |
|---------|---------|---------|------|
| 承重戏 | 五感全开+情绪底色 | 详细，3-5行 | 高潮/反转/情感爆发 |
| 次承重戏 | 视觉+听觉+情绪底色 | 中等，2-3行 | 关键对话/信息揭示 |
| 过场戏 | 只有视觉一句话 | 极简，1行 | 过渡/交代/建立关系 |

## 十、与上下游岗位的衔接

### 10.1 上游衔接：岗位2（分集大纲+钩子编剧）

| 接收项 | 来源 | 用途 |
|--------|------|------|
| 分集大纲 | 岗位2产出 | 每集的结构骨架，按此逐集展开 |
| 钩子设计清单 | 岗位2产出 | 每集开场钩子+结尾卡点的类型和方向 |
| 角色出场清单 | 岗位2产出 | 每集哪些角色出场、什么状态 |
| Gate A确认 | 用户确认 | 大纲已锁定，不得擅自修改结构 |

**衔接规则**：
- 岗位2大纲中已确定的集间卡点必须保留，不得擅自修改
- 如发现大纲有结构性问题（如场景因果断裂），须暂停并反馈，不得自行修改大纲
- 大纲中的钩子类型可适配为具体画面，但钩子方向不得改变

### 10.2 下游衔接：岗位4（台词润色编剧）

| 交付项 | 格式 | 接收方用途 |
|--------|------|-----------|
| 标准剧本初稿 | 语义化排版 | 岗位4在此基础上润色台词 |
| 场景清单 | 表格 | 岗位4了解每场戏的语境 |
| 人物出场清单 | 表格 | 岗位4核对角色出场一致性 |
| 钩子标注 | 内嵌 | 岗位4保留钩子位置的台词不被压缩 |

**交付规则**：
- 台词写出初版即可，不必追求口语化——口语化是岗位4的核心任务
- 但台词必须推进剧情、传递信息，不得写无效台词
- 每条台词须标注角色情绪状态，供岗位4润色时参考

### 10.3 与知识库（00）的衔接

| 知识库要素 | 在初稿中的应用 |
|-----------|--------------|
| 人物档案·语言特征 | 每个角色台词须符合其语言特征（口头禅/用词偏好/语速） |
| 人物档案·不可变特征 | 角色外貌描写须与档案一致 |
| 人物档案·禁用设定 | 角色行为不得违反"绝不会做什么/绝不会说什么" |
| 世界观规则 | 场景描写须符合世界观（时代/技术/战力天花板） |
| 爽点清单 | 按清单安排爽点出现的集数和方式 |
| Logline | 每集内容须服务于全剧核心卖点 |

**OOC防护规则**：
1. 写每场戏前，先查阅知识库中该角色的语言特征和禁用设定
2. 角色行为须与其角色弧线阶段一致（开篇状态/转折/终局）
3. 如发现大纲要求与知识库冲突，以知识库为准，暂停并反馈
