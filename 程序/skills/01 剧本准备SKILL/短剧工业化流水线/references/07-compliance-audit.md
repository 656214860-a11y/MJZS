# 岗位7·合规审读（Compliance Reader）

> 定位：流水线第七岗位——平台红线筛查与违规桥段替换。对全剧剧本执行六大维度合规扫描，定位违规内容，输出风险等级评估和具体替换方案。
> 上游：岗位6（逻辑审查通过的剧本）
> 下游：岗位8（总编终审）
> 本岗位已内化平台合规指南（六大维度合规速查表+替代方案+风险三级标注），可直接执行。
> 核心方法论：ai-script-reviewer红线识别方法论（ModelScope开源工具）+ SD合规转译体系

## 一、模块定位

### 1.1 岗位定义

本岗位是短剧剧本生产流水线中的**合规审读者**，对标短剧行业标准SOP中"合规审读"一职。职责是对全剧剧本进行平台红线筛查——暴力血腥、伦理道德、政治敏感、性暗示裸露、未成年人保护、平台通用规则——六大维度逐集扫描，发现违规内容后提供具体替换方案，确保剧本在投喂平台时不触发审核拦截、限流或封号。

### 1.2 岗位边界

| 维度 | 本岗位做 | 本岗位不做 |
|------|---------|-----------|
| 红线筛查 | 逐集扫描违规内容模式，输出违规清单 | 不修改台词风格（岗位4负责） |
| 风险分级 | 对每处违规进行高/中/低风险分级 | 不做逻辑审查（岗位6负责） |
| 替换方案 | 为每处违规提供3+替换选项 | 不执行替换（交回岗位3/4执行） |
| 版权检查 | 经典IP改编的授权合规检查 | 不处理版权采购流程 |
| 平台适配 | 按目标平台规则调整合规标准 | 不修改分集大纲（岗位2负责） |
| 合规报告 | 输出逐集合规报告+全剧风险评估 | 不做最终定稿裁定（岗位8负责） |

### 1.3 硬性前置条件

- ✅ 岗位6逻辑审查已完成并通过（或问题已记录移交）
- ✅ 总编知识库（00）已锁定，禁用设定清单+平台规则可查
- ✅ 赛道定位已确定（目标平台+平台规则已在知识库中标注）
-  分集大纲中已标注每集场景清单（内外/日夜/内容摘要）

### 2.2 输出三级模式

本岗位在审查时需对照SD合规指南的三级输出模式，判定剧本内容属于哪一档：

| 模式 | 适用 | 默认用词 | 是否可直接投喂公开平台 |
|------|------|---------|----------------------|
| **① 安全默认（推荐）** | 直接投喂即梦/Seedance/可灵等公开平台 | 失衡、击退、擦伤、尘土、衣料受力 | ✅ 是 |
| **② 强动作非血腥** | 需要更猛的动作感但拒绝血腥 | 击退重击、受力凹陷、猛烈撞击 | ⚠️ 视平台政策，建议先审 |
| **③ 成人级创作草案** | 仅用于剧本文本，不直接投喂 | 保留强度描写，标注"仅供创作参考" | ❌ 否 |

### 2.3 引用原则

1. **只读引用**：本岗位引用SD合规指南的禁忌清单和替代方案作为审查基准，不修改原文件
2. **增量检查**：SD合规指南面向的是分镜/提示词生成阶段的词汇替换，本岗位增加剧本层面的桥段级合规审查（剧情设定/角色行为/场景设计是否违规，而非仅词汇层面）
3. **平台适配**：本岗位根据知识库中的目标平台信息，调整合规审查的严格程度（不同平台标准不同）

## 三、ai-script-reviewer红线识别方法论

> 来源：ModelScope开源工具·ai-script-reviewer方法论
> 核心原理：用结构化模式匹配对剧本进行红线扫描，替代人工逐行审读，提高审查效率和覆盖率。

### 3.1 红线识别流程

```
Step 1：违规模式扫描
  → 对全剧剧本逐集逐场景执行关键词+语义模式扫描
  → 匹配SD合规指南六大维度的禁忌清单
  → 记录命中位置（集号+场景+台词/动作/描写）

Step 2：上下文判定
  → 对每条命中执行上下文分析
  → 区分"正面教育意义"与"美化展示"
  → 区分"必要叙事"与"可替代描写"
  → 剔除误报（如角色名中包含敏感字）

Step 3：风险等级分类
  → 按下文3.2的风险等级矩阵分类
  → 高风险=必须替换，中风险=建议替换，低风险=可保留但标注

Step 4：替换方案生成
  → 对每处违规引用SD合规指南替代方案
  → 每处提供至少3个替换选项
  → 标注替换后的安全等级

Step 5：IP改编风险检查（如适用）
  → 检查经典IP改编的版权合规
  → 检查原著授权范围
  → 检查改编是否超出授权边界

Step 6：输出合规报告
  → 逐集违规清单+替换方案
  → 全剧风险评估
  → 逐集PASS/FAIL判定
```

### 3.2 风险等级分类矩阵

| 风险等级 | 标识 | 判定条件 | 处置原则 | 对应SD等级 |
|---------|------|---------|---------|-----------|
| **高风险** | 🔴 | 命中致命级或高危级禁忌，直接触发平台封号或拦截 | **必须替换**，不替换不得交付 | 🔴致命/🔴高危 |
| **中风险** | 🟡 | 命中中危级禁忌，可能被限流或人工审核打回 | **建议替换**，替换后通过率显著提升 | 🟡中危 |
| **低风险** | 🟢 | 接近红线但未直接命中，或上下文有正面导向 | **可保留**但标注提醒，供岗位8终审定夺 | 🟢低危 |

### 3.3 违规内容模式识别规则

本岗位对以下内容模式进行扫描识别：

**词汇级扫描**（对照SD合规指南禁忌清单）：

| 扫描类型 | 识别模式 | 命中维度 |
|---------|---------|---------|
| 血腥词汇 | 血/流血/血迹/血污/断骨/碎裂/内脏 | 维度一·暴力与血腥 |
| 死亡词汇 | 死/杀死/死亡/毙命/尸体/垂死/濒死 | 维度一·暴力与血腥 |
| 武器词汇 | 枪/刀/弹药/导弹/炮弹/枪口/枪管 | 维度一·暴力与血腥 |
| 性暗示词汇 | 全裸/半裸/露点/呻吟/娇喘/胸部/臀部特写 | 维度二·性暗示与裸露 |
| 未成年违规 | 小学生抽烟/初中生喝酒/校园霸凌/未成年恋爱 | 维度三·未成年人保护 |
| 恐怖词汇 | 丧尸/贞子/僵尸/鬼/灵异/尸体/断头 | 维度四·恐怖与惊悚 |
| 价值观违规 | 撒钱/赌场/吸毒/贩毒/出轨/小三/乱伦 | 维度五·价值观与公序良俗 |
| 政治敏感 | 领导人/国旗/国徽/政治事件/敏感历史 | 维度六·平台通用红线 |

**桥段级扫描**（本岗位新增，SD未覆盖）：

| 扫描类型 | 识别模式 | 命中维度 |
|---------|---------|---------|
| 暴力桥段 | 角色被酷刑/虐待/自残的完整叙事段落 | 维度一·暴力与血腥 |
| 性暗示桥段 | 完整的暧昧/性暗示场景设计 | 维度二·性暗示与裸露 |
| 不良导向桥段 | 犯罪过程被美化/不伦恋被正面描写 | 维度五·价值观与公序良俗 |
| 敏感设定 | 剧情设定涉及真实政治事件/宗教冲突 | 维度六·平台通用红线 |

### 3.4 经典IP改编风险检查

当本流水线从小说IP入口（入口A）启动时，本岗位需额外执行IP改编合规检查：

| 检查项 | 检查内容 | 通过标准 |
|--------|---------|---------|
| 版权合规 | 原著是否为公有领域/已获授权 | 有明确授权或属公有领域 |
| 改编范围 | 改编是否超出授权范围 | 在授权范围内进行改编 |
| 角色使用 | 是否使用了原著中的受保护角色 | 角色使用在授权范围内 |
| 情节使用 | 是否完整复制原著受保护情节 | 改编而非复制，有原创成分 |
| 商标规避 | 是否涉及原著中的受保护商标/专有名词 | 使用替代名称或获得授权 |

## 五、替换策略

### 5.1 暴力替换策略

对每处暴力违规，提供至少3个替换选项，按安全程度排序：

| 违规类型 | 选项1（最安全） | 选项2（中等力度） | 选项3（保留最大张力） |
|---------|----------------|------------------|---------------------|

## 七、8项自检清单

合规审读完成后，执行以下自检清单，全部通过才能输出报告：

```
□ 1. 六大维度全扫描：暴力/性暗示/未成年保护/恐怖/价值观/平台红线，逐集逐场景无遗漏
□ 2. 违规清单完整：每处违规有集号+场景+时间戳+维度+风险等级+违规摘要
□ 3. 替换方案可执行：每处高风险违规至少提供3个替换选项，标注推荐选项和安全等级
□ 4. 风险等级准确：高风险（必须替换）/中风险（建议替换）/低风险（可保留）分类无误
□ 5. 平台适配检查：已对照知识库中目标平台规则调整审查严格度
□ 6. IP改编合规检查：如为IP改编入口，已执行版权合规+授权范围+改编边界检查
□ 7. 全剧风险评估：已输出全剧风险评级+各维度违规分布统计+平台匹配度
□ 8. 逐集PASS/FAIL判定：每集有明确判定，FAIL集已标注必须替换的违规位置
```

## 八、与其他岗位的衔接

### 8.1 上游衔接：岗位6（逻辑编审）

| 衔接项 | 说明 |
|--------|------|
| **输入物** | 岗位6逻辑审查通过的剧本（或逻辑问题已记录移交的剧本） |
| **输入格式** | 标准短剧剧本格式（场景标题+动作描写+台词+钩子标注） |
| **依赖项** | 岗位6已确认剧情逻辑无致命漏洞（合规审查不在有逻辑硬伤的剧本上执行，避免替换违规桥段后又因逻辑问题返工） |
| **回退条件** | 若合规替换方案导致逻辑断裂（如替换暴力桥段后因果链断裂），标注后退回岗位6重新审查逻辑 |

### 8.2 下游衔接：岗位8（总编终审）

| 衔接项 | 说明 |
|--------|------|
| **输出物** | 合规审查报告（逐集违规清单+全剧风险评估+替换方案） |
| **输出格式** | 本模块第六部分定义的报告格式 |
| **传递信息** | 违规清单（供岗位8判断是否执行替换）+ 替换方案（供岗位8裁定采用哪个选项）+ 逐集PASS/FAIL判定（供岗位8终审参考） |
| **不阻断原则** | 合规审查中条件通过的集不阻断流程，报告传递给岗位8，由总编终审统一裁定是否执行替换。但FAIL集必须替换后复检才能进入终审 |

### 8.3 知识库（00）衔接

| 衔接方向 | 内容 |
|---------|------|
| **← 禁用设定清单** | 知识库中的禁用设定清单（人物禁用/剧情禁用/平台禁用/风格禁用）作为合规审查的基线 |
| **← 平台规则** | 知识库赛道定位中的目标平台规则，决定合规审查的严格程度 |
| **← 人物档案** | 人物档案中的"禁用设定"字段（角色绝不会做什么/说什么）作为角色行为合规的检查基准 |
| **→ 违规清单** | 合规审查中发现的违规桥段，如涉及知识库禁用设定，反馈至知识库标注"已触发" |
| **→ 替换词库** | 替换方案中积累的安全替代词，可反馈至知识库作为后续项目的合规参考词库 |
