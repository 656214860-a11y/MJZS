# ★岗位6·逻辑编审（Logic Auditor）

> 定位：流水线第六岗位——**新增模块**，填补SD体系中"逻辑编审"的行业空白。以知识库（00）为逻辑基线，对剧本执行全量逻辑审查：剧情穿帮、设定冲突、角色动机一致性、跨集逻辑闭环。
> 上游：岗位5（节奏编审通过稿）
> 下游：岗位7（合规审读）
> 本岗位已内化多集连贯性系统（跨集衔接三要素、Bible校准、变化追踪）与终检P0逻辑相关项，可直接执行。
> 配套方法：麦基叙事质检清单（M1-M120 + F1-F12，增强层非门禁，见第四节，可配合「麦基叙事引擎」技能）
> 理论来源：CML-Bench八维指标体系（arXiv:2510.06231）、DuoDrama多角色视角审查法（ACM 2025）

---

## 一、模块定位

### 1.1 为什么需要逻辑编审

SD原体系在台词（岗位4）、节奏（岗位5）、合规（岗位7）之间缺少一个专门的**逻辑自洽性审查层**。行业标准中，"逻辑编审"是独立于台词润色和节奏审查之外的核心岗位，专职解决以下问题：

| 问题类型 | 典型表现 | 不做逻辑编审的后果 |
|---------|---------|-------------------|
| 剧情穿帮 | 角色知道不该知道的信息 | 观众弹幕刷"这他怎么知道的？" |
| 设定冲突 | 世界观规则前后矛盾 | 观众质疑"说好的不能飞呢？" |
| 动机断裂 | 角色行为缺乏合理动机 | 观众觉得"这人突然就疯了" |
| 跨集逻辑漏洞 | 上一集的悬念下一集被遗忘 | 观众流失、追更意愿骤降 |
| 时间线矛盾 | 事件发生顺序不可能 | 观众出戏、口碑崩盘 |

### 1.2 核心职责

本岗位接手岗位5（节奏编审通过稿），对剧本执行五层逻辑审查：

1. **单集内逻辑自洽**——同一集内事件因果链是否闭合
2. **角色动机一致性**——角色行为是否符合其设定动机
3. **信息流合理性**——角色获取/使用信息的时间线是否正确
4. **跨集逻辑闭环**——集与集之间的逻辑衔接是否连贯
5. **世界观合规**——剧本是否违反知识库（00）中的世界观规则

### 1.3 岗位边界

| 维度 | 本岗位做 | 本岗位不做 |
|------|---------|-----------|
| 逻辑审查 | 剧情穿帮、设定冲突、动机一致性、跨集逻辑 | 不修改台词口语化（岗位4已做） |
| 信息流追踪 | 角色知识边界检查、信息获取时间线 | 不调整节奏/节拍（岗位5已做） |
| 世界观合规 | 对照知识库检查规则违反 | 不做平台合规审查（岗位7负责） |
| 角色行为检查 | 行为是否符合动机与弧光设计 | 不重新设计角色弧光（知识库已锁） |
| 跨集衔接 | 情绪/空间/时间三要素衔接检查 | 不做资产视觉一致性（由Bible机制负责） |
| 叙事增强 | 可选调用mckee 132项清单（增强层） | mckee结果为建议非门禁，不阻断推进 |

### 1.4 硬性前置条件

- ✅ 岗位5（节奏编审）已通过，剧本节奏无P0/P1级问题
- ✅ 总编知识库（00）已锁定，世界观规则·人物档案·禁用设定可查
- ✅ 多集项目须有Bible（由本岗位多集连贯性检查产出）
- ✅ 场景清单+人物出场清单+时间线已就绪

## 二、核心方法论1：CML-Bench八维指标体系

> 来源：arXiv:2510.06231（CML-Bench: A Comprehensive Benchmark for Chinese Movie and TV Drama Script Logic）
> 原理：将剧本逻辑质量拆解为三个维度（对话/角色/情节）共8项可量化指标，每项0-10分打分，加权计算逻辑总分。

### 2.1 八维全量评分矩阵

每集剧本须通过以下8项指标的逐一评分。本岗位作为逻辑审查执行方，须对每集独立打分。

#### 维度A：对话维度（Dialogue Consistency, DC）— 权重25%

| 指标 | 评分标准 | 0分（严重） | 5分（一般） | 10分（优秀） | 检查方法 |
|------|---------|------------|------------|-------------|---------|
| **DC1 对话语义相似度** | 检查同一场景内对话是否语义连贯 | 角色A说东、B答西，语义断裂明显 | 部分对话有跳跃但可理解 | 每轮对话语义自然衔接，无断裂 | 逐场景提取对话对，检查上下句语义关联度 |
| **DC2 话题集中度** | 检查对话是否围绕当前场景话题，不跑题 | 角色突然谈论无关话题，无过渡 | 偶有跑题但有回拉 | 对话始终围绕场景核心话题推进 | 标注每场景核心话题，检查每句对话的话题相关度 |
| **DC3 问答相关性** | 检查对话中回答是否匹配提问 | 问A答B，答非所问 | 部分回答间接但基本相关 | 每个回答直接或合理间接对应提问 | 提取所有问答对，检查回答与问题的匹配度 |

#### 维度B：角色维度（Character Consistency, CC）— 权重35%

| 指标 | 评分标准 | 0分（严重） | 5分（一般） | 10分（优秀） | 检查方法 |
|------|---------|------------|------------|-------------|---------|
| **CC1 角色情感稳定性** | 检查角色情感变化是否渐进而非突变 | 上一秒平静下一秒暴怒，无触发事件 | 情感变化有触发但过渡过快 | 情感变化有明确触发事件且过渡合理 | 逐场景标注角色情感状态，绘制情感变化曲线，检查梯度 |
| **CC2 语言风格一致性** | 检查角色说话风格是否跨集一致 | 角色A在第3集文绉绉、第5集满嘴粗话 | 偶有波动但基本可辨识 | 全剧语言风格稳定，听声辨人 | 对照知识库（00）语言特征卡，逐集校验词汇/句式/口头禅 |
| **CC3 意图-行为一致性** | 检查角色行为是否符合其声明的意图 | 角色说要报仇却主动帮助仇人（无解释） | 行为与意图有偏差但有理由 | 行为始终与声明的意图一致或在合理范围内转变 | 提取角色声明意图，逐场景检查行为是否匹配 |

#### 维度C：情节维度（Plot Reasoning, PR）— 权重40%

| 指标 | 评分标准 | 0分（严重） | 5分（一般） | 10分（优秀） | 检查方法 |
|------|---------|------------|------------|-------------|---------|
| **PR1 事件序列语义连贯性** | 检查事件序列是否逻辑连贯 | 事件A→事件B之间无任何逻辑桥梁 | 部分事件间有跳跃但有隐含逻辑 | 每个事件都有明确的前因后果链接 | 绘制事件因果链图，检查相邻事件的逻辑桥 |
| **PR2 因果关系密度** | 检查事件间是否有充足的因果连接 | 重大事件无任何前因（凭空发生） | 主要事件有1个原因但偏弱 | 每个重大事件有≥1个充足原因且逻辑严密 | 逐事件标注原因（cause），检查原因的充分性 |

### 2.3 评分阈值与判定规则

| 总分区间 | 判定 | 处理方式 |
|---------|------|---------|
| 8.0-10.0 | 优秀 | 直接通过，可进入岗位7 |
| 6.0-7.9 | 合格 | 通过，但须记录待优化项，进入岗位7 |
| 4.0-5.9 | 不合格 | 返回岗位3（初稿）修正后重新审查 |
| <4.0 | 严重不合格 | 返回岗位2（大纲）重新检视结构逻辑 |

**最低门槛铁律**：每个维度（DC/CC/PR）的小计分必须≥6.0/10，任一维度低于6.0即判定不通过，即使总分≥6.0。

### 2.4 八维评分实操示例

**示例：EP05 评分**

| 指标 | 分数 | 证据 | 问题 |
|------|------|------|------|
| DC1 | 8 | 场景3对话语义连贯 | 无 |
| DC2 | 7 | 场景5角色B突然谈论无关话题，但有回拉 | 记录待优化：场景5话题跑偏 |
| DC3 | 9 | 问答匹配度高 | 无 |
| CC1 | 6 | 角色A在场景4从平静到暴怒仅用2句台词过渡 | 记录P1：情感突变需增加触发铺垫 |
| CC2 | 9 | 跨集语言风格稳定 | 无 |
| CC3 | 5 | 角色B声明要保护C却在场景7主动暴露C位置（无解释） | P0级问题：意图-行为矛盾 |
| PR1 | 7 | 事件序列基本连贯，场景6→7过渡略跳跃 | 记录待优化 |
| PR2 | 6 | 事件4（角色A获得线索）无明确前因 | P1级问题：因果关系不足 |

```
DC小计 = (8+7+9)/3 × 0.25 = 2.00
CC小计 = (6+9+5)/3 × 0.35 = 2.33
PR小计 = (7+6)/2 × 0.40 = 2.60
逻辑总分 = 2.00 + 2.33 + 2.60 = 6.93 / 10
判定：合格（CC3=5<6，触发最低门槛铁律 → CC维度不通过 → 整体判定不通过）
```

> 注意：上例中虽然总分6.93≥6.0，但CC维度小计=(6+9+5)/3=6.67≥6.0通过，实际CC3单项=5但维度平均≥6。若CC维度平均<6则整体不通过。修正判定逻辑：维度平均分≥6.0即维度通过。上例CC维度6.67≥6通过，总分6.93≥6通过。但CC3=5仍标记为P0级问题须修复。

## 三、核心方法论2：DuoDrama多角色视角审查法

> 来源：ACM 2025（DuoDrama: Multi-Role Perspective Review for Script Consistency）
> 原理：为每个主要角色实例化一个"角色视角审查员"，以该角色的第一人称视角通读剧本，检查"我会这么做吗？我在这个时间点知道这个信息吗？我的动机连贯吗？"

### 3.1 双记忆模块机制

每个角色视角审查员维护两套记忆，模拟角色在剧本时间线中的认知状态：

```
┌──────────────────────────────────────────────────────────┐
│              双记忆模块（Dual Memory Module）            │
├──────────────────────────────────────────────────────────┤
│                                                          │
│  ┌─────────────────┐    ┌─────────────────────────┐     │
│  │  角色记忆         │    │  故事记忆                │     │
│  │  (Character      │    │  (Story Memory)         │     │
│  │   Memory)       │    │                         │     │
│  │                  │    │                         │     │
│  │  角色知道什么     │    │  实际发生了什么           │     │
│  │  角色经历过什么   │    │  （上帝视角）             │     │
│  │  角色的认知边界   │    │                         │     │
│  └────────┬────────┘    └───────────┬─────────────┘     │
│           │                         │                    │
│           └──────────┬──────────────┘                    │
│                      ▼                                   │
│            ┌─────────────────┐                           │
│            │  冲突检测器       │                           │
│            │  (Conflict       │                           │
│            │   Detector)     │                           │
│            │                 │                           │
│            │  角色记忆 vs     │                           │
│            │  故事记忆        │                           │
│            │  → 信息不对称    │                           │
│            │  → 行为不合理    │                           │
│            └────────┬────────┘                           │
│                     ▼                                    │
│            ┌─────────────────┐                           │
│            │  一致性报告      │                           │
│            │  (Consistency   │                           │
│            │   Report)      │                           │
│            └─────────────────┘                           │
└──────────────────────────────────────────────────────────┘
```

#### 角色记忆（Character Memory）

记录每个时间点该角色"应该知道什么"：

| 字段 | 内容 | 示例（角色：林默，EP05） |
|------|------|------------------------|
| 已知信息 | 截至当前场景，角色通过亲历/被告知/推理获得的信息 | 知道苏婉是间谍（EP03揭示）、不知道老陈是幕后黑手 |
| 已经历事件 | 角色亲历的所有事件 | EP01被抓、EP03识破苏婉、EP04被追杀 |
| 认知边界 | 角色不可能知道的信息 | 不知道老陈的计划（只有观众知道） |
| 情感状态 | 截至当前场景角色的情感积累 | 对苏婉从信任→愤怒→纠结 |

#### 故事记忆（Story Memory）

记录剧本中"实际发生了什么"（上帝视角）：

| 字段 | 内容 | 示例（EP05） |
|------|------|-------------|
| 事件全貌 | 所有角色的所有行为 | 老陈在EP03暗中介入、苏婉EP04未死的真相 |
| 信息分布 | 每条信息哪个角色知道、何时知道 | 老陈身份：观众EP02知道、林默EP05才知道 |
| 时间线 | 事件发生的客观顺序 | EP03夜→EP04晨→EP05午 |

### 3.2 角色视角审查员实例化

为每个A级角色（≤5个）实例化一个审查员。B级角色视情况可选实例化。

**实例化模板**：

```
角色视角审查员 · [角色名]
═══════════════════════════════════════════
身份设定：我是[角色名]，[角色定位]
认知基线：[从知识库00提取的角色档案]

审查任务：
  1. 逐场景阅读剧本
  2. 以我的视角回答三个核心问题：
     Q1: "我会这么做吗？"——检查我的行为是否符合我的性格和动机
     Q2: "我在这个时间点知道这个信息吗？"——检查信息认知边界
     Q3: "我的动机连贯吗？"——检查我的行为动机是否前后一致

审查输出：
  ┌────────────────────────────────────────┐
  │ 场景[编号]                             │
  │ 我的行为：[描述]                       │
  │ Q1回答：[是/否/存疑] + 理由             │
  │ Q2回答：[知道/不知道/不应知道] + 理由   │
  │ Q3回答：[连贯/断裂/突变] + 理由         │
  │ 问题标记：[P0/P1/P2/无]                │
  │ 问题描述：[详细]                       │
  │ 修复建议：[具体]                       │
  └────────────────────────────────────────┘
```

### 3.3 冲突检测机制

DuoDrama核心是检测"角色记忆"与"故事记忆"之间的信息不对称。以下是五类核心冲突检测规则：

| 冲突类型 | 检测规则 | 示例 | 严重级别 |
|---------|---------|------|---------|
| **信息越界** | 角色使用了其不应知道的信息 | 林默EP05精准说出老陈的计划，但该信息要到EP08才对他揭示 | P0 |
| **信息遗漏** | 角色未使用其应该知道的信息 | 林默EP03识破了苏婉，但EP05却完全信任苏婉无任何防备 | P0 |
| **行为越界** | 角色做了超出其能力/权限的事 | 普通学生角色突然展现出专业格斗技巧（无铺垫） | P1 |
| **动机断裂** | 角色行为动机前后矛盾 | 角色EP02声明要复仇，EP05却毫无理由地放弃 | P0 |
| **情感失忆** | 角色对重大事件的情感反应遗忘 | 角色EP03目睹好友死亡，EP05像没事人一样说笑 | P1 |

## 五、多集连贯性检查

> 来源：`（扣子独立版已内化的方法论模块）`

### 5.1 Bible基准跨集校准

本岗位在多集项目中，须使用Bible管理机制进行跨集逻辑审查：

| Bible要素 | 逻辑审查用途 |
|-----------|------------|
| 角色Bible档案 | 检查角色行为是否与档案中的核心欲望、禁用设定一致 |
| 场景Bible档案 | 检查场景描写是否与GEO块、固定陈设一致 |
| 时间线档案 | 检查事件发生时间是否与全剧时间线矛盾 |
| 版本变更记录 | 检查角色/场景变化是否有对应的剧情理由 |

### 5.2 变化追踪

SD系统的变化追踪机制与逻辑审查直接相关：

| 变更类型 | SD审批级别 | 逻辑审查检查点 |
|---------|-----------|--------------|
| 小变化（加配饰） | 导演决定 | 检查是否有剧情呼应 |
| 中变化（换服装） | 需确认剧情合理性 | 检查换装是否有剧情理由 |
| 大变化（毁容/发型大变） | 必须有剧情支撑 | 检查剧情支撑是否充分，前后集是否呼应 |

### 5.3 跨集衔接三要素检查

引用SD系统的衔接三要素，执行跨集逻辑审查：

| 要素 | SD定义 | 逻辑审查检查方法 |
|------|--------|----------------|
| **情绪衔接** | 上集结尾情绪→下集开头承接 | 逐集检查结尾情绪状态与开头情绪状态的连贯性。上集愤怒→下集不能突然开心 |
| **空间衔接** | 上集结尾空间位置→下集开头连续 | 逐集检查结尾空间与开头空间的一致性。上集在门口→下集不能已坐在室内 |
| **时间衔接** | 两集间时间跨度是否明确 | 逐集检查时间标注。紧接着？次日？三年后？必须明确且不矛盾 |

### 5.4 集尾卡点兑现检查

使用"集尾卡点设计"规则，检查上集承诺是否在下集兑现：

| 卡点类型 | 上集承诺 | 下集必须兑现 | 逻辑审查检测点 |
|---------|---------|------------|--------------|
| 危机型 | 刀架在脖子上 | 刀还在→解决危机 | 下集开头是否承接危机状态 |
| 悬念型 | 门正要打开 | 开门→看到门后 | 下集开头是否兑现开门 |
| 生死型 | 角色坠崖 | 坠崖结果 | 下集开头是否交代角色命运 |

> **铁律**：上一集结尾承诺了什么，下一集开头必须兑现什么。卡点不兑现 = 逻辑断裂 = P0级问题。

## 八、剧情穿帮检测指南

### 8.1 五类穿帮检测方法

#### 类型1：信息不对称（Information Asymmetry）

**定义**：角色使用了其不应知道的信息，或未使用其应该知道的信息。

**检测流程**：
```
Step 1：构建角色认知时间线
  → 逐场景记录角色在每个时间点应该知道什么

Step 2：提取角色使用的每条信息
  → 在台词/行为中标注信息来源

Step 3：比对
  → 角色使用的信息 vs 角色应知信息
  → 若使用>应知 → 信息越界（P0）
  → 若应知>使用且角色应做出反应但未反应 → 信息遗漏（P0）
```

**检测示例**：
| 场景 | 角色行为 | 角色应知 | 判定 |
|------|---------|---------|------|
| EP05·场景3 | 林默说出老陈的计划 | 林默到EP08才知道 | P0：信息越界 |
| EP05·场景7 | 林默完全信任苏婉 | 林默EP03已识破苏婉 | P0：信息遗漏 |

#### 类型2：时间线冲突（Timeline Conflicts）

**定义**：事件发生顺序在物理或逻辑上不可能。

**检测流程**：
```
Step 1：提取全剧事件时间标注
  → 每个场景标注：第几天/什么时间（早/午/晚/夜）

Step 2：绘制时间线
  → 按时间排列所有事件

Step 3：检查不可能序列
  → 事件A在事件B之后发生，但A的内容依赖B尚未发生
  → 例：角色A在"第三天"提到"第五天的会议" → 时间线矛盾
```

**常见时间线矛盾模式**：
| 模式 | 表现 | 示例 |
|------|------|------|
| 预知未来 | 角色提到了尚未发生的事件 | EP03角色提到EP05的会议 |
| 时间倒流 | 后发生的事件被描述为先发生 | EP05说"昨天"但指的是EP03的事（EP03是3天前） |
| 并行矛盾 | 两件不可能同时发生的事被描述为同时 | 角色A在城东开会，同时在城西打架 |

#### 类型3：动机空缺（Motivation Gaps）

**定义**：角色行为缺乏充分的动机支撑。

**检测流程**：
```
Step 1：提取角色行为
  → 逐场景标注角色的每个重大行为

Step 2：追溯动机
  → 该行为的动机是什么？动机是否在剧本中有铺垫？

Step 3：充分性检查
  → 动机强度是否匹配行为量级？
  → 微弱动机 + 重大行为 = 通俗剧化（P1）
  → 无动机 + 重大行为 = 动机空缺（P0）
```

**动机充分性评估表**：
| 行为量级 | 需要的动机铺垫 | 不充分的信号 |
|---------|--------------|------------|
| 日常行为 | 无需特别铺垫 | N/A |
| 重要决定 | ≥1个前置场景铺垫 | 无铺垫直接做决定 |
| 重大转折 | ≥2个前置场景铺垫+内心冲突外化 | 1句台词带过 |
| 生死抉择 | 完整弧光支撑+压力测试 | 无压力测试 |

#### 类型4：设定违反（Setting Violations）

**定义**：剧本中的事件违反了知识库（00）中的世界观规则或禁用设定。

**检测流程**：
```
Step 1：加载知识库世界观规则和禁用设定
  → 逐条提取规则和禁用项

Step 2：逐场景检查
  → 每个事件/行为是否违反了任何规则

Step 3：匹配违规
  → 事件X违反规则Y → P0级设定冲突
```

**检测示例**：
| 场景 | 剧本事件 | 知识库规则 | 判定 |
|------|---------|-----------|------|
| EP05·场景2 | 角色飞行 | 规则1：无超自然能力 | P0：设定违反 |
| EP05·场景5 | 角色说"这经济上不划算" | 禁用设定：古装戏禁用现代词汇 | P1：设定违反 |

#### 类型5：道具连续性（Object Continuity）

**定义**：关键道具在场景间无解释地出现或消失。

**检测流程**：
```
Step 1：提取关键道具清单（从Bible道具档案）
  → 每个有戏份的道具列出

Step 2：逐场景追踪道具位置
  → 道具在哪个角色手中/在什么位置

Step 3：检查无解释变化
  → 道具A在场景3在桌上，场景4突然消失 → 检查是否有交代
  → 道具A在场景3角色B手中，场景4突然在角色A手中 → 检查是否有交代
```

## 九、12项自检清单

逻辑编审完成后，须逐项执行以下自检清单：

```
□ 01. CML-Bench八维评分是否已逐项打分且每项都有证据？
□ 02. 每个维度（DC/CC/PR）的小计分是否≥6.0（最低门槛铁律）？
□ 03. A级角色是否全部实例化了DuoDrama角色视角审查员？
□ 04. 每个角色视角审查员是否输出了完整的一致性报告？
□ 05. 五类穿帮检测（信息不对称/时间线/动机/设定/道具）是否全部执行？
□ 06. 所有P0级问题是否已标记且给出了修复建议？
□ 07. 多集项目是否执行了跨集衔接三要素检查（情绪/空间/时间）？
□ 08. 多集项目是否检查了集尾卡点兑现？
□ 09. 设定冲突是否逐条比对了知识库（00）的世界观规则和禁用设定？
□ 10. mckee增强层（如执行）的发现是否已作为建议附入报告（非阻断）？
□ 11. 逻辑编审报告是否完整输出（含7个部分：评分卡/角色报告/穿帮/冲突/跨集/mckee/总评）？
□ 12. 通过/不通过判定是否基于总分+最低门槛+P0问题数三重条件？
```

### 9.1 判定三重条件

最终通过/不通过判定须同时满足三个条件：

| 条件 | 要求 | 不满足时 |
|------|------|---------|
| 条件1：逻辑总分 | ≥6.0/10 | 直接不通过 |
| 条件2：维度最低门槛 | DC/CC/PR每维度小计≥6.0 | 直接不通过 |
| 条件3：P0问题数 | P0级问题 = 0 | 直接不通过 |

> 三重条件为AND关系，任一不满足即判定不通过。全部满足方可判定通过，进入岗位7。

## 速查：逻辑编审核心速查卡

### 八维指标速查

```
对话维度（DC, 25%）：
  DC1 对话语义相似度 — 上下句语义是否连贯
  DC2 话题集中度     — 是否跑题
  DC3 问答相关性     — 答是否匹配问

角色维度（CC, 35%）：
  CC1 情感稳定性     — 情感变化是否渐进
  CC2 语言风格一致性 — 跨集说话风格是否统一
  CC3 意图-行为一致性 — 行为是否符合声明意图

情节维度（PR, 40%）：
  PR1 事件序列连贯性 — 事件间是否有逻辑桥
  PR2 因果关系密度   — 每个重大事件是否有≥1个充足原因

总分 = DC×0.25 + CC×0.35 + PR×0.40
通过线：总分≥6.0 且每维度≥6.0 且 P0=0
```

### 五类穿帮速查

```
1. 信息不对称 → 角色用了不该知道的信息 / 没用该知道的信息
2. 时间线冲突 → 事件顺序不可能
3. 动机空缺   → 行为无充分动机
4. 设定违反   → 违反知识库世界观规则
5. 道具连续性 → 道具无解释出现/消失
```

### DuoDrama三问速查

```
Q1: "我会这么做吗？"         → 行为是否符合性格和动机
Q2: "我在这个时间点知道吗？" → 信息认知边界
Q3: "我的动机连贯吗？"       → 动机前后一致
```

### 严重级别速查

```
P0 = 致命（穿帮/设定违反/动机矛盾）→ 必须修复，阻断推进
P1 = 严重（衔接断裂/因果不足）    → 应当修复，可带条件通过
P2 = 一般（情感过快/话题跑偏）    → 建议修复，不阻断
P3 = 优化（mckee增强建议）        → 可选，不影响判定
```
