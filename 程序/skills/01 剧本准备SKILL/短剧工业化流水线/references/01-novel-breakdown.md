# 岗位1·拆书编剧（Novel Breakdown Writer）

> 定位：剧本生产流水线第1岗——小说/原著/网文的故事核提取与情节节点表产出。
> 行业对标：短剧编剧团队中"拆书编剧"岗位，负责将IP原著拆解为可执行的情节骨架。
> 上游：阶段0·总编知识库（`00-chief-editor-knowledge-base.md`）已锁定的Logline、人物总档案、世界观规则。
> 下游：岗位2·分集大纲+钩子编剧（`02-outline-and-hooks.md`）接收情节节点表进行分集拆分。
> 六步管线（抽样快评→章节索引→核心提取→分集规划→剧本转化→改编契约）已内化为本岗位可直接执行的方法。

---

## 一、岗位职责边界

### 1.1 做什么

通读原著全文，提取故事核心，砍掉支线/内心独白/世界观灌水，输出一张**情节节点表**（Excel结构）供后续岗位使用。

### 1.2 不做什么

| 不做的事 | 归属岗位 |
|---------|---------|
| 分集拆分、集数规划 | 岗位2·大纲+钩子 |
| 写剧本（场景/动作/台词） | 岗位3·脚本初稿 |
| 台词润色 | 岗位4·台词润色 |
| 节奏/逻辑/合规审查 | 岗位5/6/7 |
| 提炼Logline、锁定人物档案 | 阶段0·总编知识库 |

### 1.3 输入与输出

```
输入：
  ✦ 总编知识库（00）中的 Logline + 人物总档案 + 世界观规则
  ✦ 小说/原著/网文全文（或分章文本）
  ✦ 用户附加指示（如"重点保留感情线""砍掉修仙体系设定"等）

输出：
  ✦ 情节节点表（Excel结构，核心交付物）
  ✦ 章节索引表（全书内容索引）
  ✦ 来源锚点标注（每个情节节点可追溯到原文）
  ✦ 角色合并方案（哪些角色合并/删除/降为路人）
  ✦ 核心五要素清单（核心欲望/角色/场景/爽点/设定）
```

## 二、六步管线（本岗位执行前三步）

> 本岗位引用 （已内化的方法论模块） 的六步管线，但只执行前3步（抽样快评→章节索引→核心提取），后3步（分集规划→剧本转化→改编契约）移交后续岗位。

### 管线总览

```
Step 1  抽样快评   → 值不值得改？（快评5问，≥60分才继续）
Step 2  章节索引   → 全书有什么？（8列索引表+标记系统）
Step 3  核心提取   → 哪些必须留？（核心五要素+角色合并+场景筛选）
─────── 以上为本岗位执行范围 ───────
Step 4  分集规划   → 移交岗位2（大纲+钩子）
Step 5  剧本转化   → 移交岗位3（脚本初稿）
Step 6  改编契约   → 移交岗位8（总编终审时追溯校验）
```

### Step 1 要点：抽样快评5问

| # | 问题 | 权重 | 判定标准 |
|---|------|------|---------|
| 1 | 有没有强钩子？ | 30% | 第1章末尾有没有"必须看下去"的悬念/反转/爽点 |
| 2 | 主角欲望清晰吗？ | 25% | 一句话能说清主角想要什么+阻碍是什么 |
| 3 | 视觉化程度高吗？ | 20% | 靠动作/场景推动，还是靠内心独白/叙述推动 |
| 4 | 角色数量可控吗？ | 15% | 核心角色能否压缩到≤5个 |
| 5 | 短剧适配度 | 10% | 题材是否属于短剧热门赛道 |

- **≥80分**：强烈推荐改编，直接进入Step 2
- **60-79分**：可以改，必须附补强计划（钩子强化/角色压缩/视觉化提升）
- **<60分**：不建议直接改，须告知用户风险并获得确认后才能继续

### Step 2 要点：章节索引8列

| 列名 | 说明 |
|------|------|
| 章节 | 原著章节号 |
| 主要事件 | 这一章发生了什么（一句话） |
| 出场角色 | 本章出现的角色名单 |
| 核心场景 | 事件发生地点 |
| 情绪基调 | 紧张/悲伤/热血/甜蜜/压抑等 |
| 关键信息 | 推动主线必须知道的信息 |
| 爽点/反转 | 打脸/逆袭/揭秘/甜宠等爽点标记 |
| 视觉化难度 | 高/中/低——能不能直接拍成画面 |

> **来源锚点**：每条索引标注原文出处（章X段Y），改编后全程可追溯。

### Step 3 要点：核心五要素

| 要素 | 标准 | 数量限制 |
|------|------|---------|
| 核心欲望 | 主角想要什么+为什么+阻碍——一句话 | 1句 |
| 核心角色 | A级角色清单 | ≤5个 |
| 核心场景 | A级场景清单 | ≤8个 |
| 核心爽点/反转 | 每集至少1个 | 全剧≥总集数 |
| 核心设定 | 观众必须知道才能看懂的世界规则 | 只保留必知 |

> 详细规则见后文第六至十章。

## 三、增强方法A：Toonflow章节分割法

> 来源：Toonflow的自动化章节分割与角色提取方法论。
> 用途：对长篇小说（50章以上）进行高效的章节分割与角色自动化梳理，避免人工逐章阅读的效率瓶颈。

### 3.1 自动章节分割流程

```
输入：小说全文
  ↓
Step A：章节边界识别
  → 按"第X章"/"Chapter X"/空行分隔符自动切分
  → 无明确章节标记的文本，按字数阈值（2000-3000字）强制分段
  → 输出：章节清单（章号 + 起始段落 + 字数）
  ↓
Step B：每章摘要生成
  → 对每章提取3-5句话摘要（人物+事件+结果）
  → 标记该章是否含核心剧情节点
  → 输出：章节摘要表
  ↓
Step C：AI角色提取
  → 逐章扫描，提取所有出场角色的名字
  → 记录每个角色的：首次出场章节、出场总次数、与主角的关系
  → 输出：角色出场频次表
  ↓
Step D：角色画像生成
  → 对出场频次Top 10的角色，自动生成角色画像草稿
  → 画像含：姓名、身份、性格关键词、与主角关系、功能定位
  → 输出：角色画像草稿表（供岗位0总编知识库参考）
```

### 3.2 角色出场频次表格式

| 角色名 | 首次出场 | 出场章数 | 总出场次数 | 与主角关系 | 功能定位 | 初步建议 |
|--------|---------|---------|-----------|-----------|---------|---------|
| 林晚 | 第1章 | 28/30 | 156次 | — | 主角 | A级保留 |
| 张浩 | 第1章 | 22/30 | 89次 | 前夫/反派 | 直接阻碍 | A级保留 |
| 苏瑶 | 第2章 | 15/30 | 42次 | 闺蜜/盟友 | 智囊助力 | A级保留 |
| 王律师 | 第5章 | 3/30 | 8次 | 苏瑶同事 | 提供证据 | 合并入苏瑶 |
| 李总 | 第8章 | 2/30 | 5次 | 投资人 | 龙套 | 降为路人/删除 |

### 3.3 与六步管线的衔接

- Toonflow Step A-B 产出 → 自动填入第2步章节索引表
- Toonflow Step C-D 产出 → 为第3步角色合并提供数据支撑
- Toonflow角色画像草稿 → 交岗位0总编知识库作为人物档案参考

> **效率提示**：50章以下的小说可跳过Toonflow自动分割，直接人工通读+六步管线。50章以上的长篇必须走Toonflow流程，否则章节索引质量不可控。

## 四、增强方法B：Versely导演式二读法

> 来源：Versely的导演模式阅读方法论。
> 用途：在章节索引完成后（第2步之后），进行第二轮"导演视角"阅读，为视觉化转化做前置标注。

### 4.1 为什么要二读

第一遍阅读（第1-2步）解决"有什么"的问题——把全书内容索引出来。
第二遍阅读（Versely导演式）解决"怎么拍"的问题——在原文上标注视觉化要素。

### 4.2 二读五类标注

对每个核心章节（标记为🔴必保留或⭐高爽点的章节），进行第二遍精读，在原文上标注以下五类信息：

| 标注类型 | 符号 | 含义 | 标注规则 |
|---------|------|------|---------|
| **位置变化** | 📍 | 角色空间位置的移动 | 标注角色从哪里到哪里、移动方式（走/跑/跌倒）、移动时的情绪状态 |
| **角色入场** | 👤 | 新角色进入当前场景 | 标注入场方式（推门/从暗处走出/被叫来）、入场时观众的感知焦点 |
| **不可删对白** | 💬 | 删了剧情就不成立的台词 | 标注原因（揭露关键信息/推动反转/定义角色关系） |
| **高视觉化画面** | 🎥 | 最适合拍成镜头的3个画面 | 每章选Top 3，标注画面要素（主体+动作+环境+光影） |
| **情绪转折点** | 🔄 | 角色情绪发生方向性变化的瞬间 | 标注转折前情绪→转折触发→转折后情绪 |

### 4.3 二读标注示例

以SD novel-adaptation-engine.md附录中原著第3章为例：

```
📍 [酒吧门口→酒吧内] 林晚推门进入，穿过舞池→后台方向
  └ 移动方式：低头快步走 | 情绪：紧张、不想被注意

👤 张浩入场：从吧台卡座站起来，主动走向林晚
  └ 感知焦点：他的声音先到（"哟，这不是林大设计师吗"），人后到

💬 不可删对白："你告我啊？有证据吗？你那些设计稿，现在署的都是我的名字，谁信你？"
  └ 原因：揭露核心冲突（知识产权被夺）+ 定义角色关系（施害者vs受害者）+ 铺设复仇主线

🎥 高视觉化画面 Top 3：
  1. 张浩端着威士忌走近林晚，嘴角嘲讽——中景，酒吧灯光打在酒杯上
  2. 林晚拳头攥紧，指甲嵌进掌心——特写，指节发白
  3. 林晚转身走出酒吧，背影消失在门口——全景，门内暖光门外冷光对比

🔄 情绪转折点：
  转折前：林晚"浑身一僵"（恐惧+屈辱）
  触发：张浩凑近耳边说"你告我啊？有证据吗？"
  转折后：林晚"猛地抬起头，盯着他的眼睛"（恐惧→愤怒→觉醒）
```

### 4.4 二读产出用途

| 产出 | 用途 |
|------|------|
| 📍位置变化标注 | 岗位3写脚本时设计场面调度（角色走位/镜头跟随） |
| 👤角色入场标注 | 岗位2设计每集角色出场节奏（谁先出场、怎么出场） |
| 💬不可删对白标注 | 岗位4台词润色时保护核心台词不被压缩 |
| 🎥高视觉化画面 | 岗位2设计钩子时的视觉参考 + 后续分镜素材 |
| 🔄情绪转折点 | 岗位5节奏编审时的节拍锚点 + 岗位3写戏时的弧光设计 |

## 五、情节节点表输出格式（Excel结构）

> 这是本岗位的核心交付物。结构对标Excel表格，后续岗位2直接基于此表进行分集拆分。

### 5.1 表头定义（9列）

| 列号 | 列名 | 类型 | 说明 |
|------|------|------|------|
| A | 序号 | 整数 | 节点流水号（P001, P002...） |
| B | 章节 | 文本 | 原著章节号（如"第3章"或"第3章§2"表示第3章第2节） |
| C | 主要事件 | 文本 | 一句话概括这个情节节点发生了什么 |
| D | 出场角色 | 文本 | 本节点涉及的角色名单（用顿号分隔） |
| E | 场景 | 文本 | 事件发生地点 |
| F | 情绪 | 文本 | 情绪基调（紧张/悲伤/热血/甜蜜/压抑/震惊等） |
| G | 钩子/反转 | 文本 | 本节点是否含钩子或反转，简述内容 |
| H | 视觉化难度 | 枚举 | 高/中/低——能否直接拍成画面 |
| I | 来源锚点 | 文本 | 原文出处（章X段Y，精确到段落） |

### 5.2 标记列（第10列，叠加标记）

| 标记 | 含义 | 使用规则 |
|------|------|---------|
| 🔴 必保留 | 核心剧情节点，删了故事就不成立 | 主线骨架事件，100%保留 |
| 🟡 可压缩 | 有价值但可以合并/简化 | 信息有用但篇幅可缩，后续岗位2决定如何压缩 |
| ⚪ 可删除 | 支线/灌水/心理描写/回忆杀 | 不影响主线理解，直接砍掉 |
| ⭐ 高爽点 | 打脸/反转/逆袭/揭秘——短剧核心卖点 | 100%保留且要强化，这是观众留下来的理由 |
| 🎬 高视觉化 | 动作戏/大场面/名场面 | 重点保留，优先安排在集首/集尾做视觉钩子 |

> **标记可叠加**：一个节点可以同时标🔴⭐🎬（必保留+高爽点+高视觉化），这种节点是全剧最核心的名场面。

### 5.3 情节节点表示例

| 序号 | 章节 | 主要事件 | 出场角色 | 场景 | 情绪 | 钩子/反转 | 视觉化难度 | 来源锚点 | 标记 |
|------|------|---------|---------|------|------|----------|-----------|---------|------|
| P001 | 第1章 | 林晚离婚，被赶出公司 | 林晚、张浩、保安 | 公司楼下 | 压抑、屈辱 | — | 低 | 章1段5 | 🔴必保留 |
| P002 | 第2章 | 苏瑶收留林晚，劝她打官司 | 林晚、苏瑶 | 苏瑶家 | 温暖、犹豫 | — | 低 | 章2段3 | 🟡可压缩 |
| P003 | 第3章 | 酒吧偶遇张浩，被当众羞辱 | 林晚、张浩、红裙女 | 夜色酒吧 | 屈辱、愤怒 | ⭐羞辱→隐忍（情绪反转铺垫） | 高 | 章3段2-7 | 🔴⭐🎬 |
| P004 | 第3章 | 林晚电话苏瑶，决定复仇 | 林晚（电话）、苏瑶（声音） | 酒吧后巷 | 坚定、决绝 | ⭐复仇宣言（情绪反转） | 中 | 章3段12 | 🔴⭐ |
| P005 | 第4章 | 回忆：张浩如何吞并公司 | 林晚、张浩、张父 | 多个闪回场景 | 愤怒、悔恨 | — | 高（闪回多场景） | 章4全章 | ⚪可删除 |
| P006 | 第5章 | 苏瑶查到第一条证据线索 | 苏瑶、林晚 | 律师事务所 | 紧张、希望 | 🔍信息揭露 | 低 | 章5段7 | 🟡可压缩 |

### 5.4 节点颗粒度标准

| 维度 | 标准 |
|------|------|
| 一个节点 = | 一个完整的戏剧事件（有起因→动作→结果） |
| 不要太碎 | "林晚走进酒吧"不是节点，"林晚在酒吧被张浩羞辱"才是 |
| 不要太大 | "林晚复仇全过程"不是节点，要拆成"羞辱→觉醒→宣战"等多个节点 |
| 参考粒度 | 一章通常拆出2-5个节点；全书节点数 ≈ 目标集数的1.5-2倍 |

## 六、来源锚点系统

### 6.1 为什么要锚点

改编不是重写。每一个情节节点都必须能追溯回原文，否则：
- 后续岗位无法回查"这个情节原著是怎么写的"
- 总编终审（岗位8）无法校验"改编是否偏离原作核心"
- 出现版权争议时无法证明"哪些是原著的、哪些是原创的"

### 6.2 锚点格式

```
标准格式：章X段Y

示例：
  章3段2    → 第3章第2自然段
  章3段2-7  → 第3章第2到第7自然段（跨段落事件）
  章4全章   → 第4章整章（用于"可删除"的整章支线）
  章3§2     → 第3章第2节（适用于有分节的长章节）
```

### 6.3 锚点规则

1. **每个节点必须有锚点**：包括"可删除"的节点——删了也要知道删的是原文哪里
2. **跨章事件拆分标注**：一个事件跨多章时，拆成多个节点，各自标注所在章节
3. **原创内容标注"（原创）"**：本岗位不产生原创内容，但如果用户指示需要新增情节，标注来源为"（原创·用户指示）"
4. **锚点精确到段落**：不要只写"第3章"，要写"第3章段8"——后续回查时能快速定位

### 6.4 锚点校验清单

岗位1交付前自检：

- [ ] 情节节点表每一行都有来源锚点（列I不为空）
- [ ] 锚点格式统一（章X段Y，不混用"第三章"和"第3章"）
- [ ] 抽查3个节点，锚点指向的原文段落确实包含该节点描述的事件
- [ ] "可删除"节点也标注了原文出处

## 七、标记系统详解

### 7.1 五种标记定义

| 标记 | 全称 | 判定标准 | 保留率 |
|------|------|---------|--------|
| 🔴 | 必保留 | 删了主线剧情就不成立的节点 | 100% |
| 🟡 | 可压缩 | 有信息价值但篇幅可缩减、可与其他节点合并 | 保留信息，压缩篇幅 |
| ⚪ | 可删除 | 支线剧情、内心独白、回忆杀、世界观灌水、不影响主线的配角戏 | 0%（直接砍） |
| ⭐ | 高爽点 | 打脸/逆袭/复仇/揭秘/甜宠/金手指——观众留下来的理由 | 100%且强化 |
| 🎬 | 高视觉化 | 动作戏/大场面/名场面——适合做视觉钩子 | 优先保留 |

### 7.2 标记叠加规则

```
单标记场景：
  🔴 必保留       → 普通核心剧情
  ⭐ 高爽点       → 爽点但可能不是主线骨架（如配角的精彩戏份）
  🎬 高视觉化     → 视觉强但剧情重要性中等

双标记场景：
  🔴⭐            → 核心爽点（最重要，必须保留+强化）
  🔴🎬            → 核心名场面（必须保留+视觉重点设计）
  ⭐🎬            → 爽点+名场面（集首/集尾视觉钩子候选）
  🟡🎬            → 可压缩但有视觉价值的（压缩剧情，保留画面）

三标记场景：
  🔴⭐🎬          → 全剧最核心的名场面（打脸高潮/终极反转/大结局对决）
                   → 这种节点通常每剧只有3-8个，是整剧的"锚点场面"
```

### 7.3 标记分配比例参考

| 标记 | 占比参考 | 说明 |
|------|---------|------|
| 🔴 必保留 | 30-40% | 主线骨架 |
| 🟡 可压缩 | 20-30% | 有价值但可精简 |
| ⚪ 可删除 | 20-30% | 灌水/支线/内心戏 |
| ⭐ 高爽点 | 10-15% | 核心卖点 |
| 🎬 高视觉化 | 10-15% | 视觉名场面 |

> 以上比例不是硬性要求，但如果⚪可删除占比低于10%，说明拆书不够狠——短剧的信息密度要求远高于小说，大量内容必须砍掉。

## 八、角色合并规则

### 8.1 合并法则

| 法则 | 说明 | 示例 |
|------|------|------|
| 功能相同→合并 | 两个角色在剧情中承担相同功能（都给主角提供证据/都阻挠主角），合并为一个 | 王律师+李律师→合并为苏瑶（她既是律师又是闺蜜） |
| 只出场1-2次→删除/降路人 | 出场极少且不影响主线的角色，直接删除或变成无名路人 | "酒吧老板"只在第3章出现一次→降为"路人甲" |
| 有记忆点但戏份少→并入主角色 | 角色有特色但戏份不足以独立存在，把其功能并入某个A级角色 | "张浩助理小王"的戏份并入张浩本人（由张浩直接做那些事） |
| 原著叙述者→消除 | 小说中可能有一个"我"叙述者，短剧没有旁白叙述者（除非用画外音），叙述者的功能转化为视觉叙事 | 第一人称小说的"我"→直接变成主角视角的镜头叙事 |

### 8.2 合并决策表

| 原著角色 | 出场频次 | 功能 | 合并建议 | 合并后归属 |
|---------|---------|------|---------|-----------|
| 林晚 | 156次 | 主角 | A级保留 | — |
| 张浩 | 89次 | 反派/前夫 | A级保留 | — |
| 苏瑶 | 42次 | 闺蜜/智囊 | A级保留 | — |
| 王律师 | 8次 | 提供证据 | 合并 | →苏瑶（她本身是律师） |
| 李总 | 5次 | 投资人 | 降路人 | →"投资人"（无名龙套） |
| 张父 | 4次 | 张浩靠山 | 删除 | 闪回中一句话带过 |
| 红裙女 | 3次 | 张浩新欢 | 降路人 | →"张浩女伴"（无名龙套） |

### 8.3 合并后角色清单标准

合并完成后，输出最终角色清单：

```
A级角色（≤5个，全程锁死）：
  1. [角色名] - [定位] - [核心功能] - [出场章节范围]
  2. ...
  3. ...

路人角色（无名/一次性）：
  - [功能描述] - 出场章节
  - [功能描述] - 出场章节

已删除角色：
  - [角色名] - 删除原因 - 原著章节
  - [角色名]+[角色名] - 合并为[合并后角色名] - 原著章节
```

## 九、场景筛选标准

### 9.1 筛选原则

小说可能有上百个场景，短剧只保留最关键的。

### 9.2 A级场景筛选三问

| # | 问题 | 通过标准 |
|---|------|---------|
| 1 | 是不是核心剧情的必经之地？ | 这场戏不在，主线剧情就断了吗？断→A级 |
| 2 | 有没有强视觉冲击力？ | 这个场景能不能拍出名场面？能→A级 |
| 3 | 能不能承载多场戏？ | 一个场景能不能反复用（不同集数的不同戏份）？能→A级 |

> 三个问题中**至少满足2个**才能评为A级场景。

### 9.3 场景分级

| 级别 | 数量限制 | 说明 | 用途 |
|------|---------|------|------|
| A级 | ≤8个 | 核心场景，全剧70%以上的戏在此发生 | 贯穿全剧的主战场 |
| B级 | 不限 | 次要场景，单次使用 | 某一集的特定戏份 |
| C级 | 不限 | 过场/闪回场景 | 一闪而过的交代性场景 |

### 9.4 场景清单格式

```
A级场景（≤8个）：
  ① [场景名] - [视觉特征一句话] - [承载的核心戏份] - [出现集数范围]
  ② ...

B级场景：
  - [场景名] - [用途] - [出现章节]
  - ...

C级场景（过场/闪回）：
  - [场景名] - [用途] - [出现章节]
  - ...
```

### 9.5 场景筛选示例

```
A级场景（5个）：
  ① 夜色酒吧 - 霓虹灯+昏暗+震耳音乐 - 羞辱+觉醒+宣战 - EP01
  ② 设计公司 - 现代办公+玻璃幕墙+冷色调 - 职场对决+夺回署名 - EP03/06/12/18
  ③ 苏瑶家 - 温暖灯光+书架+沙发 - 闺蜜密谋+情感支撑 - EP01-05多集
  ④ 张氏集团大楼 - 高层写字楼+落地窗+俯视感 - 反派老巢+对峙 - EP06/12/15
  ⑤ 设计大赛现场 - 聚光灯+评审席+大屏幕 - 最终对决+打脸高潮 - EP18

B级场景：
  - 律师事务所 - 证据分析 - 第5章
  - 咖啡厅 - 秘密接头 - 第7章
  - ...

C级场景：
  - 法院走廊（闪回） - 离婚判决 - 第1章
  - 老家门口（闪回） - 童年回忆 - 第4章
```

## 十、核心五要素提取

> 本节对应六步管线的第3步（核心提取），是本岗位最重要的分析产出。

### 10.1 核心欲望（一句话）

**公式**：[主角] + [想要什么] + [为什么想要] + [阻碍是什么]

**提取方法**：
1. 通读全书后，用一句话回答："主角到底想要什么？"
2. 如果一句话说不清，说明原著欲望线不聚焦——需要提炼/强化
3. 对照总编知识库（00）中的Logline，确保核心欲望与Logline一致

**示例**：
- ✅ "被前夫夺走公司和名誉的落魄设计师，要靠自己的实力夺回一切，让背叛者付出代价"
- ❌ "林晚想过得好一点"（无阻碍、无代价、太模糊）

### 10.2 核心角色（≤5个A级）

| 角色类型 | 数量 | 功能 | 选择标准 |
|---------|------|------|---------|
| 主角 | 1个 | 欲望最强烈的人 | 全剧视角中心 |
| 反派/对手 | 1个 | 主角的直接阻碍 | 与主角欲望正面冲突 |
| 关键助力 | 1个 | 导师/盟友/金手指 | 帮助主角但无法替代主角 |
| 情感线 | 1个 | 恋人/亲人/兄弟 | 承载情感弧光 |
| 关键变量 | 1个 | 反转角色/神秘人物 | 后期反转的关键棋子 |

> 对照总编知识库（00）人物总档案，确保A级角色名单与知识库一致。如有出入，以知识库为准，本岗位修正角色合并方案。

### 10.3 核心场景（≤8个A级）

见第九章·场景筛选标准。

### 10.4 核心爽点/反转（每集至少1个）

**爽点分类清单**：

| 类型 | 模式 | 视觉化方式 |
|------|------|-----------|
| 打脸爽 | 被轻视→展示实力→震惊全场 | 表情特写+慢动作+围观者反应 |
| 逆袭爽 | 从底层→一步步爬到高位 | 蒙太奇+身份揭示 |
| 复仇爽 | 被伤害→精准报复→大快人心 | 计划执行+对方崩溃 |
| 揭秘爽 | 悬念→反转→真相大白 | 闪回拼接+关键道具特写 |
| 甜宠爽 | 误会→心动→撒糖 | 双人构图+暖色调+微表情 |
| 系统/金手指爽 | 获得能力→碾压对手 | 能力激活特效+对手震惊 |

**提取方法**：
1. 从情节节点表中筛选所有⭐高爽点标记的节点
2. 按爽点类型分类
3. 评估每个爽点的强度（1-5星）
4. 确保爽点分布均匀——不能前5集全是爽点后面没有，也不能全挤在最后

### 10.5 核心设定（世界观规则）

**设定三问筛选法**（引用总编知识库00）：

1. 观众不知道这个设定，能不能看懂这场戏？→ 不能就保留
2. 这个设定能不能用画面展示，而不是台词说？→ 能就用画面
3. 能不能留到后面再解释？→ 能就往后放

**输出格式**：

```
必知设定（观众必须知道才能看懂剧情）：
  规则1：[规则名] - [一句话说明] - [影响哪些场景]
  规则2：...

可延后设定（后续再解释也不影响理解）：
  - [设定名] - 计划在第X集揭示

可删除设定（不影响主线理解的背景设定）：
  - [设定名] - 删除原因
```

> 对照总编知识库（00）中的世界观规则，确保本岗位提取的设定与知识库一致。

| 坑 | 表现 | 怎么避 |
|----|------|--------|
| 缩写症 | 把小说缩写一遍就叫节点表了 | 每个节点必须有事件+情绪+钩子判断，不是简单缩写 |
| 锚点缺失 | 节点表没有来源锚点，后续无法回查 | 每写一个节点立即标注章X段Y，不留到最后补 |
| 标记不一致 | 同类节点有的标🔴有的标🟡，没有统一标准 | 先定标准再标——先通读全书，再回头统一标记 |
| 角色合并不彻底 | A级角色超标（>5个）或不合并功能重复角色 | 严格执行合并法则，功能相同的必须合并 |
| 场景太多 | A级场景超过8个 | 三问筛选法严格过滤，只留核心主战场 |
| 爽点不够 | ⭐节点数<目标集数 | 从原著中深挖，必要时向总编建议新增爽点 |
| 二读漏标 | Versely二读只做了部分章节 | 所有🔴⭐章节都必须二读，不能跳过 |
| 设定轰炸 | 把原著所有世界观设定都保留 | 三问筛选法——只保留"不知道就看不懂"的设定 |
