## 二、SD台词七维诊断系统（引用 dialogue-7d-speed-system.md）

> 来源：`（扣子独立版已内化的方法论模块）`

### 2.1 七维全量诊断矩阵

每条台词须通过七维度诊断。本岗位作为润色执行方，须在修改前先诊断、修改后复检。

| 维度 | 诊断指标 | 致命病灶（必须切除） | 润色方向 |
|------|---------|-------------------|---------|
| **1. 角色辨识度** | 词汇量、句式长短、口头禅、身份语感 | 全员同一种文绉绉或书面化语调 | 对照知识库语言特征卡校准，确保"听声辨人" |
| **2. 潜台词层级** | 表面台词与真实动机的错位 | 0层直白陈述（"我很愤怒，我要杀了你"） | 核心对白≥2层错位，避免直给 |
| **3. 冲突推进力** | 改变局面、转移筹码、逼迫表态 | 礼貌寒暄、无意义重复、被动附和 | 每句台词必须产生信息/立场/情绪/行动变动 |
| **4. 类型语感** | 时代与题材契合度 | 古装戏冒出"经济损失/逻辑漏洞"等现代词 | 严格匹配题材语感：古风简炼，港派生猛，市井接地气 |
| **5. 信息效率** | 消除反向灌输设定（Exposition） | 自报家门向观众交代背景 | 已知信息不出口，转动作/微表情 |
| **6. 节奏与音乐性** | 语速预算、停顿气口、长短句交错 | 连续30字以上无气口大长句 | 单句控制在6~18字，关键金句预留0.5s停顿发酵 |
| **7. 金句潜力** | 记忆点、截图传播力 | 通篇大白话，无任何记忆点 | 提炼蕴含哲理、反常识或极度反差的高光金句 |

### 2.2 七维诊断执行流程

```
Step 1：逐条提取台词
  → 按场景顺序，提取每句台词

Step 2：七维打分
  → 每条台词×7维度，标记致命病灶

Step 3：判定修改优先级
  → P0（致命）：语速超限、OOC、直白陈述、设定灌输
  → P1（严重）：角色辨识度不足、类型语感错配、无推进力
  → P2（一般）：缺金句、节奏单调

Step 4：执行润色修改
  → 按三段式重构输出

Step 5：复检
  → 修改后再过一遍七维，确保病灶已切除
```

## 三、语速自检系统

> 方法论归属：台词七维诊断（已内化）第二部分

### 3.1 语速三档标准

| 档位 | 语速 | 适用场景 |
|------|------|---------|
| **标准语速** | **3.5~5字/秒** | 普通对白、文戏推进、信息交代（默认） |
| **慢速重音** | <3.5字/秒 | 金句宣言、临终遗言、情绪顶点、威慑台词（一字一顿） |
| **快速爆发** | >5字/秒 | 情绪失控、争吵、紧张逼问、连珠炮（单段连续>5字/s不得超过3秒） |

### 3.2 速算公式

```
口播时长 = 可发音字符数 ÷ 语速（字/秒）
对白总时长 = 口播时长 + 标点停顿 + 情绪停顿 + 金句余韵
```

- **最短时长（最快有效）**：`字数 ÷ 5`
- **最长时长（最慢有效）**：`字数 ÷ 3.5`
- **字数口径**：只数可发音字符（汉字、数字、外文字母），标点不计入语速
- **标点停顿**：顿号/逗号 ≈ 0.1~0.3s，句号/感叹/问号 ≈ 0.3~0.6s

### 3.3 三档判定与处置

| 判定 | 条件 | 处置 |
|------|------|------|
| ✅ **合规** | 语速在3.5~5字/s，且单句≤24字 | 通过，保留 |
| ⚠️ **超长句（P1）** | 单句>24字 | **强制拆镜**：通过正反打/过肩/切入反应镜头拆2~3镜，每镜≤18字 |
| ⚠️ **金句缺发酵（P2）** | 关键台词/高潮金句后无0.3~0.8s无对白反应镜头 | 补微表情/旁观者反应镜头标注 |
| 🔴 **超时（P0）** | 台词所需时长超出该镜预算 | 重构台词或调整镜次分配，严禁超镜时长 |

### 3.4 字数速查表（标准语速）

| 字数 | 所需时长 | 判定 |
|------|---------|------|
| ≤8字 | 1.6~2.3s | ✅ 短句，适合金句/威慑 |
| 10字 | 2.0~2.9s | ✅ 标准句 |
| 14字 | 2.8~4.0s | ✅ 标准句 |
| 18字 | 3.6~5.1s | ✅ 上限附近（建议拆分） |
| 24字 | 4.8~6.9s | ⚠️ 触发拆镜阈值 |
| 30字 | 6.0~8.6s | 🔴 必须拆2~3镜 |

### 3.5 五步自检流程

1. **拆句**：把台词按逗号/句号/感叹/问号拆成独立小句
2. **计数**：每句只数可发音字符（汉字/数字/字母），标点不计
3. **停顿预算**：句内逗号（≈0.1~0.3s）+ 句末符号（≈0.3~0.6s）
4. **套档**：按场景情绪选定语速档（标准/慢速/快速）
5. **速算判定**：口播时长 + 停顿 + 余韵 = 对白总时长 → 对照镜次预算

### 4.2 拆镜示范（超长句处理）

**原台词**（33字）：
> "三年前你杀我师父灭我师门占我武馆今日我陈烬归来倒要看看谁该灭门偿命"

**拆镜方案**：
```
镜1（近景·正面）："三年前，你杀我师父，灭我师门，占我武馆。"
  → 16字 ≈ 3.2~4.6s + 4处停顿≈0.6s，总≈3.8~5.2s ✅

镜2（特写·眼神）："今日我陈烬归来。"
  → 7字 ≈ 1.4~2.0s + 句末停顿，金句前预留0.3s ✅

镜3（近景·步步逼近）："我倒要看看——谁，该灭门偿命！"
  → 11字 ≈ 2.2~3.1s + 破折号与感叹停顿，结尾预留0.5s发酵 ✅
```

## 五、麦基对白潜台词法

> 调用时机：本岗位润色核心对白时按需调用，作为对白质量增强层
> 路径：`（扣子独立版已内化的技能模块）` → 引擎三
> 完整对白潜台词引擎可配合「麦基叙事引擎」技能；本节已含可直接使用的要点

### 5.1 引擎三·15个对白模块

来源：罗伯特·麦基《对白：文字、舞台、银幕的言语行为艺术》

| 模块 | 核心功能 | 一句话摘要 | 在润色中的应用 |
|------|---------|-----------|---------------|
| **3.1 对白三种功能** | 功能分类 | 每句台词至少承担叙事/表达想法/影响说服一种功能 | 检查每句台词的功能是否明确 |
| **3.2 潜台词** | 对白核心力量 | 字面是冰山一角，真正含义在水下——三层意义场域（已说/未说/不可说） | 核心对白须有≥2层错位 |
| **3.3 行为vs语言** | 行为揭示真相 | 语言可欺骗，行为不会——行为五步骤（欲望→对抗→选择→行动→表达） | 台词与角色动作须一致或有意错位 |
| **3.4 不可说之物** | 张力驱动秘密 | 每个场景须标注角色不能说什么，何时以何种方式暴露 | 标注每场戏的"不可说"清单 |
| **3.5 对白经济性** | 用最少字说最多话 | 三层经济：字数/信息/潜台词 | 压缩长对白的核心方法论 |
| **3.6 场景vs叙事对白** | 对白模式区分 | 旁白仅用于场景对白无法表达的内容 | 判断哪些台词应转为旁白/动作 |
| **3.7 停顿即动作** | 沉默的戏剧功能 | 停顿是"被中断的动作"——核心字眼置末原则 | 关键台词前预留停顿，标注停顿位置 |
| **3.8 台上vs台下动作** | 显隐之间的张力 | 告知→展示→暗示三层递进 | 判断对白应直接说出还是用行为暗示 |
| **3.9 对白完全定义与三种说话路径** | 对白本质定义 | 对话/内心独白/旁白三种路径与媒介适配 | 判断每句台词的说话路径 |
| **3.10 媒介差异与对白密度** | 媒介适配 | 舞台重台词、影视重行为、文学可入心理 | 短剧=影视媒介，重行为轻台词 |
| **3.11 解说技巧库** | 信息传递策略 | 五种解说技巧+"演而非讲"原则 | 背景信息通过冲突中的行为释放 |
| **3.12 台词设计与句式策略** | 语言微观设计 | 句式长短=情绪控制力（情绪短/理性长），核心字眼置末 | 句式长度匹配情绪状态 |
| **3.13 角色专属语言系统** | 角色声音设计 | 语法四要素（名词/动词=知识，形容词/副词=个性） | 每个角色语言指纹校准 |
| **3.14 冲突类型光谱与节拍推进** | 冲突模式选择 | 直接/非直接/自反性/微限四种冲突类型 | 对白冲突模式匹配 |
| **3.15 在角色内写作法** | 对白创作方法 | "如果我是这个角色"正确问法+三轮问答法 | 润色时进入角色视角验证 |

### 5.2 重点应用模块

本岗位润色时重点应用以下模块：

#### 模块3.2·潜台词设计

三层意义场域：

```
已说层（台词字面意思）
  → 角色直接说出的话

未说层（角色想说但没说的）
  → 通过停顿、犹豫、转移话题暗示

不可说层（角色绝不能说的秘密）
  → 通过行为泄漏（微表情、小动作、语气变化）
```

**润色检查**：核心对白至少有1层潜台词，不能0层直白陈述。

#### 模块3.3·行为vs语言

语言可以欺骗，行为不会。润色时须检查：
- 角色嘴上说A，身体做B → 有意错位，保留
- 角色嘴上说A，行为也A → 一致表达，正常
- 角色嘴上说A，行为应该B但没写B → 补充行为描写，标注给岗位3

#### 模块3.4·不可说之物

每场戏标注角色"不能说什么"：
```
不可说标注模板：
  @角色A 不可说：[不能说的内容]
  暴露方式：[以何种方式、在何时泄漏]
  暴露后果：[泄漏后引发什么]
```

#### 模块3.5·对白经济性

三层经济：
1. **字数经济**：用最少的字传达同样的信息
2. **信息经济**：每句话传递新信息，不重复已知内容
3. **潜台词经济**：一句话同时承载表面含义和深层含义

**八种避免干巴巴的方法**（润色时参考）：
- 用行为替代陈述
- 用停顿替代解释
- 用反问替代直说
- 用暗示替代明说
- 用错误信息替代正确信息（角色说谎）
- 用转移话题替代直接回答
- 用重复替代新信息（强调情感）
- 用沉默替代对白

#### 模块3.7·停顿即动作

停顿是"被中断的动作"。润色时须：
- 关键金句前预留0.3~0.8s停顿
- 核心字眼放在句末（最强调位置）
- 标注停顿位置：`（停顿）`或`（沉默）`

#### 模块3.13·角色专属语言系统

语法四要素：
- **名词/动词** = 角色的知识领域（职业用语、身份词汇）
- **形容词/副词** = 角色的个性特征（修饰习惯、表达偏好）

润色时须确保每个角色的用词与其身份一致：
- 武者：动词为主，短句，动作性词汇
- 文人：名词丰富，长句，修辞性词汇
- 商人：数字+利益相关词，精打细算感
- 江湖人：江湖黑话+粗犷短句

## 六、声音情绪三维度词库

> 调用时机：本岗位润色情绪戏台词时引用，为每条台词标注声音情绪方向
> 说明：声音情绪三维度词库已在本节内内化，可直接使用

### 6.1 三维度词库

从三个维度组合，每个维度选1-2个值：

**音色维度**（按强度递进）：
- 轻柔 / 平稳 / 低沉 / 沙哑 / 嘶哑 / 哽咽 / 尖锐

**语速维度**：
- 缓慢 / 不疾不徐 / 正常 / 急促 / 混乱

**语气修饰维度**：
- 尾音颤抖 / 尾音上扬 / 尾音下压 / 每个字带冷意 / 带哭腔 / 带笑意 / 强装镇定 / 底气不足 / 破碎感 / 克制的冷意 / 疲惫的释然

**组合规则**：音色(1个) + 语速(1个) + 语气修饰(1-2个) = 完整声音情绪描述

### 6.2 同一台词的十种情绪写法

以"你走吧"为例，展示同一台词在不同情绪下的标注方式：

| 情绪 | 完整声音情绪标注 |
|------|----------------|
| 失望 | 声音低沉沙哑，语速缓慢，尾音几不可闻地颤抖，带着疲惫的释然 |
| 隐忍愤怒 | 声音压得极低，语速沉缓顿挫，每个字都带着克制的冷意 |
| 崩溃 | 声音沙哑带哭腔，语速急促混乱，满是情绪崩溃的破碎感 |
| 嘴硬 | 语调刻意放硬装不耐，尾音偏软底气不足，口是心非 |
| 温柔释然 | 声音轻柔平稳，语速不疾不徐，带着释怀后的淡淡笑意 |
| 虚弱 | 声音虚弱气短，语速极慢，每个字都像用尽力气才挤出，尾音消散 |
| 威胁 | 声音低沉平稳，语速极慢，每个字咬字清晰，尾音下压带寒意 |
| 嘲讽 | 声音尖锐上扬，语速忽快忽慢，尾音拖长带着不屑的笑意 |
| 哀求 | 声音颤抖哽咽，语速急促，尾音上扬带着最后的期盼 |
| 死寂 | 声音毫无起伏平板如水，语速缓慢，不带任何情感 |

### 6.3 在润色中的应用

本岗位在润色台词时，须为关键对白（承重戏台词、金句、情绪爆发台词）标注声音情绪方向：

```
角色名（情绪）：台词
  └─ 声音情绪：[音色] + [语速] + [语气修饰]
```

示例：
```
林婉（隐忍愤怒）：我父亲从不生病。
  └─ 声音情绪：低沉，沉缓顿挫，每个字带着克制的冷意
```

> 注意：声音情绪标注用于下游视频生成阶段的音频方向参考。本岗位只标注方向，不指定具体音效。

### 7.1 四大核心任务

| 任务 | 说明 | 对应工具 |
|------|------|---------|

### 7.2 标准润色流程

```
Step 1：读取初稿+知识库
  → 读取岗位3初稿（全部场景+台词）
  → 读取知识库人物档案·语言特征（每人一卡）

Step 2：逐条台词七维诊断
  → 按场景顺序，提取每条台词
  → 七维度逐条打分，标记致命病灶

Step 3：语速自检
  → 每条台词拆句计数
  → 套档速算，标记超长句（>24字）

Step 4：执行润色
  → 书面→口语转化
  → 风格统一（对照语言特征卡）
  → 长对白压缩/拆镜
  → 潜台词检查（核心对白≥2层）
  → 声音情绪标注（承重戏台词）

Step 5：OOC复检
  → 逐条对照知识库语言特征
  → 检查口头禅/用词偏好/语速是否一致
  → 检查禁用设定（角色绝不会说的话）

Step 6：输出润色后剧本
  → 保留全部场景标题、动作描写、钩子标注
  → 替换台词为润色后版本
  → 附润色修改报告（三段式重构记录）
```

## 八、OOC防护体系

### 8.1 OOC定义

OOC（Out of Character）= 角色说了不符合其人设的话，或用了不属于其身份的说话方式。这是短剧最常见的人设崩坏原因。

### 8.2 OOC防护规则

**规则1·语言特征对照**：每条台词须与知识库中该角色的语言特征卡一致。

知识库语言特征卡包含：
```
角色名：
口头禅：[标志性重复用语]
说话风格：[简练/啰嗦/文绉绉/粗犷/阴阳怪气/温柔/冷酷]
用词偏好：[职业用语/方言色彩/古风/现代/江湖黑话]
语速特征：[快/慢/忽快忽慢/沉稳]
句式习惯：[短句为主/长句为主/反问多/感叹多/陈述为主]
禁用语言：[这个角色绝不会说什么]
```

**规则2·行为一致性**：角色台词须与其角色弧线阶段一致。
- 开篇阶段角色：说话方式体现初始状态（懦弱/隐忍/无知→用词怯弱、句式犹疑）
- 转折阶段角色：说话方式开始变化（决心渐显→用词变硬、句式变短）
- 终局阶段角色：说话方式与开篇形成对照（强大/决绝→用词干脆、句式利落）

**规则3·禁用设定执行**：知识库中标注的角色"绝不会说什么"必须严格执行。
- 示例：角色禁用设定为"绝不会求人"→ 全剧中该角色不得出现"求求你""帮帮我"等台词
- 示例：角色禁用设定为"绝不会说脏话"→ 全剧中该角色不得出现任何粗口

### 8.3 OOC检查清单

| 序号 | 检查项 | 通过标准 |
|------|--------|---------|
| 1 | 口头禅出现频率 | 角色口头禅在合理频率出现（不过密不缺席） |
| 2 | 说话风格一致 | 全集风格统一，无突变 |
| 3 | 用词偏好匹配 | 职业用语/身份词汇出现且正确 |
| 4 | 语速特征一致 | 角色语速与知识库标注一致 |
| 5 | 句式习惯匹配 | 句式长短/反问感叹比例与知识库一致 |
| 6 | 禁用语言零出现 | 知识库标注的禁用语言绝对不出现 |
| 7 | 弧线阶段一致 | 说话方式与角色当前弧线阶段一致 |
| 8 | 角色间辨识度 | 遮住角色名也能分辨是谁在说话 |

```markdown
### 修改1
* **原台词**："大小姐回来了。老爷走了。"
* **字数/语速**：12字，标准语速约2.4~3.4s，判定：✅

  1. 【维度1 角色辨识度】：赵管家作为下属，加顿号体现拘礼的说话习惯
  2. 【维度6 节奏/语速】：加停顿，增加"走了"二字的冲击力
  3. 【维度7 金句潜力】："走了"二字独立成句，更有死亡宣告的力度

### 修改2
* **原台词**："什么时候的事。"
* **字数/语速**：6字，判定：✅
* **改写建议**："……什么时候。"
* **为什么这么改**：
  1. 【维度2 潜台词】：省略"的事"，台词更短，潜台词更强（不是在问时间，是不敢相信）
  2. 【维度6 节奏/语速】：省略后更短，配合"……"前导停顿，体现震惊后的迟滞
  3. 【维度1 角色辨识度】：林婉作为将门之女，说话简练不啰嗦

### 修改3
* **原台词**："我父亲从不生病。"
* **字数/语速**：7字，判定：✅
* **改写建议**："我爹从不生病。"
* **为什么这么改**：
  1. 【维度1 角色辨识度】："爹"比"父亲"更口语化，符合林婉私下场合的说话习惯
  2. 【维度4 类型语感】：古风宅门场景，"爹"比"父亲"更有家庭亲密感
  3. 【维度2 潜台词】：用"爹"暗示父女亲密，反衬"从不生病"的质疑力度
```
