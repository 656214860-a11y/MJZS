# ★岗位5·节奏编审（Rhythm Auditor）

> 定位：流水线第五岗位——全流程唯一节奏专项审查，填补短剧行业标准中"节奏编审"岗位的方法论空白。逐集审查冲突密度、拖沓水戏、钩子强度、单集时长控制，输出量化节奏审查报告。
> 上游：岗位4（台词润色后剧本）
> 下游：岗位6（逻辑编审）
> 本岗位已内化终检P0标准中的节奏相关项，可直接执行。
> 核心方法论：DramaBench冲突评分系统（arXiv:2512.19012）+ 冲突密度量化 + 红果钩子强度评估 + 节奏拖沓检测

## 一、模块定位

### 1.1 岗位定义

本岗位是短剧剧本生产流水线中的**节奏专项审查者**，对标短剧行业标准SOP中"节奏编审"一职。现有SD体系中的质检（quality-iteration-system.md）覆盖了剧本/资产/分镜/提示词/成片五个节点，但缺少独立的节奏编审维度——冲突够不够密、钩子够不够强、有没有水戏拖沓、单集时长有没有超标——这些正是短剧留存率的生死线。

本模块**新增于SD体系之外**，不修改SD任何内容，只做只读引用。

### 1.2 岗位边界

| 维度 | 本岗位做 | 本岗位不做 |
|------|---------|-----------|
| 冲突密度 | 逐集统计冲突事件频率，输出密度热力图 | 不修改台词/对白（岗位4负责） |
| 拖沓检测 | 定位零信息增量段落，标注水戏 | 不重写场景结构（岗位3负责） |
| 钩子强度 | 三层钩子评分 + 悬念结尾强度评分 | 不设计新钩子（岗位2负责） |
| 时长控制 | 核算单集时长偏差，标注超限集 | 不调整分集拆分（岗位2负责） |
| 节奏修改建议 | 输出具体剪裁/合并/补充建议（带时间戳） | 不执行修改（交回岗位3/4执行） |
| 跨集节奏曲线 | 输出全剧张力曲线，定位节奏塌陷区 | 不做逻辑审查（岗位6负责） |

### 1.3 硬性前置条件

- ✅ 岗位4台词润色已完成，剧本台词为口语化终版
- ✅ 总编知识库（00）已锁定，爽点清单+钩子设计清单可查
- ✅ 分集大纲（岗位2产出）中已标注每集目标时长
- ✅ 每集均有钩子标注（开场钩子+结尾卡点）

## 二、核心方法论一：DramaBench冲突评分系统

> 来源：arXiv:2512.19012《DramaBench: A Benchmark for Conflict Handling in Dramatic Text》
> 核心原理：短剧的张力来自冲突的不断升级和转折，而非解决。冲突被"解决"=张力归零。

### 2.1 冲突处理行为评分表

对每个冲突事件的处理方式进行分类打分：

| 冲突处理行为 | 代号 | 得分 | 定义 | 示例 |
|-------------|------|------|------|------|
| **升级** | ESC | **+2** | 按戏剧结构原则将冲突推向更高强度 | 主角被追杀→发现追杀者是自己信任的人 |
| **转折** | TWI | **+2** | 引入新障碍/新变数/新 complication | 营救计划即将成功→出现第三方势力介入 |
| **暂停** | PAU | **+1** | 延迟冲突解决，制造悬念 | 关键真相即将揭晓→被打断/切换视角 |
| **解决** | RES | **0** | 完全解决冲突，张力归零 | 反派被击败、误会彻底消除、危机解除 |

### 2.2 短剧评分原则

> **核心铁律：升级和转折得高分，解决得0分。**

短剧的商业模式是"按集付费/按集留存"——冲突一旦被彻底解决，观众就没有继续看下一集的动力。因此：

- **升级（+2）** 是黄金行为：冲突不解决反而加剧，观众被迫追更
- **转折（+2）** 是白金行为：旧冲突未解+新冲突叠加，张力倍增
- **暂停（+1）** 是过渡行为：合理的悬念制造，但不可连续使用（连续2次暂停=拖沓）
- **解决（0）** 是危险行为：仅在大结局或付费转折点才允许有限度使用

### 2.3 逐集冲突评分执行流程

```
Step 1：逐集提取冲突事件
  → 按场景顺序，识别每集所有冲突事件
  → 标注每个冲突的类型（人际/群际/内心/外部）

Step 2：对每个冲突事件的处理方式分类
  → ESC / TWI / PAU / RES 四选一
  → 记录处理行为发生的时间戳（秒）

Step 3：计算单集冲突总分
  → 单集冲突得分 = 该集所有冲突处理得分之和
  → 达标阈值：≥4分（PASS）
  → 不达标：<4分（FAIL，需补充冲突升级或转折）

Step 4：定位冲突塌陷区
  → 连续2个以上RES行为 = 张力塌陷
  → 连续2个以上PAU行为 = 悬念疲劳
  → 在报告中标注具体位置

Step 5：输出冲突评分表
  → 逐集冲突事件清单 + 处理行为 + 得分
  → 单集总分 + PASS/FAIL判定
```

### 2.4 冲突评分表模板

```

┌──────┬──────────┬────────┬──────┬───────────────────────────┐
│ 序号 │ 时间戳    │ 冲突类型│ 处理 │ 得分 │ 说明                  │
├──────┼──────────┼────────┼──────┼───────────────────────────┤
│ 1    │ 00:05     │ 人际   │ ESC  │ +2   │ 被嘲讽→当场反击       │

│ 4    │ 00:55     │ 人际   │ ESC  │ +2   │ 对峙升级为动手         │
```

## 三、核心方法论二：冲突密度量化

### 3.1 定义

**冲突密度** = 每60秒内的冲突事件数量。

短剧的留存率法则：观众在任意60秒内必须感受到至少一次明显的冲突推进，否则流失率急升。

### 3.2 密度标准

| 密度等级 | 每60秒冲突数 | 判定 | 处置 |
|---------|-------------|------|------|
| **A·优秀** | ≥3 | ✅ 高密度，节奏紧凑 | 通过 |
| **B·合格** | 2 | ✅ 达标（主冲突+次冲突） | 通过 |
| **C·偏低** | 1 | ⚠️ 临界，需关注 | 标注，建议补充次冲突 |
| **D·水戏** | 0 | 🔴 拖沓水戏 | **必须剪裁或合并** |

> **底线标准：每60秒≥2个冲突事件（1个主冲突+1个次冲突）**

### 3.3 冲突类型分类

| 类型 | 代号 | 定义 | 示例 |
|------|------|------|------|
| **人际冲突** | IC | 角色之间的对抗/争执/对峙 | A嘲讽B→B反击 |
| **群际冲突** | GC | 团体/势力之间的对抗 | 帮派火并、阵营对峙 |
| **内心冲突** | XC | 角色内心挣扎/抉择 | 是否暴露隐藏身份 |
| **外部冲突** | EC | 环境/命运/时间的压迫 | 倒计时爆炸、追兵逼近 |

### 3.4 水戏检测规则

> **"水戏"定义：连续60秒内冲突事件数为0的段落。**

**水戏判定三步法**：

```
Step 1：时间轴切片
  → 将每集按60秒为单位切片

Step 2：逐片冲突计数
  → 统计每个60秒切片内的冲突事件数
  → 0个冲突 = 标记为"水戏片"

Step 3：水戏处置
  → 单个水戏片（60秒）→ 标注⚠️，建议压缩到30秒以内
  → 连续2个水戏片（120秒）→ 标注🔴，必须剪裁或合并到相邻场景
  → 连续3个水戏片（180秒+）→ 标注🔴🔴，严重拖沓，整段重构
```

**水戏常见形态**：

| 水戏类型 | 特征 | 处置建议 |
|---------|------|---------|
| 独白戏 | 角色对着空气说大段内心独白 | 压缩为1-2句，转为动作/表情 |
| 铺垫过载 | 场景交代过长，超过30秒无冲突 | 砍环境描写，冲突前置 |
| 重复确认 | 角色反复确认同一信息 | 删减至1次，信息合并 |
| 情感宣泄 | 无冲突的情绪发泄段落 | 保留关键句，其余剪入闪回 |
| 日常寒暄 | 与剧情无关的社交对话 | 直接删除 |

### 3.5 冲突密度热力图

逐集输出密度热力图，直观呈现节奏分布：

```
第3集·冲突密度热力图（单集90秒）

时间轴：  0-30s    30-60s   60-90s
冲突数：   2        1        3
密度等级：  B        C        A
状态：     ✅       ⚠️       ✅

密度曲线：  ██▓▓____▒▒____██████
          （██=高密度  ▒▒=偏低  ____=空隙）

问题定位：30-60秒区间密度偏低（C级），建议在35-45秒插入次冲突
```

## 四、核心方法论三：钩子强度评估

> 来源：红果短剧官方教程·钩子三角体系
> 核心原理：短剧前30秒决定80%的留存率，三层钩子缺一不可。

### 4.1 三层钩子检查体系

| 层级 | 名称 | 时间窗口 | 核心策略 | 评分范围 |
|------|------|---------|---------|---------|
| **第一层** | 3秒钩子 | 00:00-00:03 | 反常识画面 + 致命疑问 | 0-10分 |
| **第二层** | 15秒钩子 | 00:04-00:15 | 表面答案 + 隐藏线索 | 0-10分 |
| **第三层** | 30秒钩子 | 00:16-00:30 | 无关物品变关键证据 | 0-10分 |

### 4.2 三层钩子评分标准

#### 第一层：3秒钩子（权重50%）

| 得分 | 标准 | 示例 |
|------|------|------|
| 9-10 | 反常识冲击画面+致命疑问双发，观众无法划走 | 开场即主角跪在雨中认输，旁边站着所有人都以为是敌人的反派 |
| 7-8 | 有反常识画面或致命疑问之一，且足够抓人 | 开场即一个"死人"睁开眼睛 |
| 5-6 | 有钩子意识但力度不够，画面普通 | 开场是争吵场景，但未给出反常识信息 |
| 3-4 | 钩子模糊，像"慢慢进入故事" | 开场是角色走路/看风景 |
| 0-2 | 无钩子，纯铺垫 | 开场是大段环境空镜+旁白介绍 |

#### 第二层：15秒钩子（权重30%）

| 得分 | 标准 | 示例 |
|------|------|------|
| 9-10 | 表面给出答案但同时埋下更深疑问，观众必须看下去 | 3秒钩子的"死人"醒了→15秒揭示他失忆了，但手里攥着一把带血的刀 |
| 7-8 | 有表面答案+隐藏线索，线索可被敏锐观众捕捉 | 解释了争吵原因，但镜头扫过一个可疑的旁观者 |
| 5-6 | 有答案但线索不够隐藏，或线索太隐晦 | 解释了角色处境，但没有埋任何新疑问 |
| 3-4 | 纯解答无新疑问，观众可以划走了 | 把3秒钩子的疑问完全解答，无悬念延伸 |
| 0-2 | 无答案无线索，15秒纯铺垫 | 继续环境描写/角色介绍 |

#### 第三层：30秒钩子（权重20%）

| 得分 | 标准 | 示例 |
|------|------|------|
| 9-10 | 无关物品/角色/细节变关键证据，形成"啊！"的恍然感 | 开场闪过一个路人递水→30秒揭示那杯水被下了毒 |
| 7-8 | 有伏笔转换，但转换力度略弱 | 开场出现的物品在30秒时被提及用途 |
| 5-6 | 有伏笔意识但转换平淡 | 开场的物品在后面出现，但无反转感 |
| 3-4 | 无伏笔转换，30秒内信息平淡 | 30秒内只是冲突逐步升级，无关键物品介入 |
| 0-2 | 30秒内无任何信息锚点 | 30秒内纯对话推进，无视觉锚点 |

### 4.3 钩子强度综合评分

```
钩子强度综合分 = (3秒钩子得分 × 0.5) + (15秒钩子得分 × 0.3) + (30秒钩子得分 × 0.2)

达标阈值：≥ 6.0/10（PASS）
不达标：< 6.0/10（FAIL，需重新设计钩子）
```

**权重设计原理**：3秒钩子权重最高（50%），因为短剧前3秒决定70%的划走率；15秒钩子次之（30%），决定是否继续看完；30秒钩子最低（20%），决定是否进入"追更"状态。

### 4.4 悬念结尾强度评分

> 短剧每集结尾必须有"卡点"——让观众必须点下一集。

**四种卡点类型及评分**：

| 卡点类型 | 得分 | 定义 | 示例 |
|---------|------|------|------|
| **决策关头** | 8-10 | 角色面临两难抉择，画面定格在犹豫瞬间 | 主角举起刀，面前是要杀的仇人/却是亲生父亲 |
| **身份暴露** | 7-9 | 隐藏身份即将/刚刚被揭穿的瞬间 | 伪装被撕下，对方震惊的脸特写 |
| **援兵突现** | 6-8 | 绝境中突然出现新势力，局势逆转 | 主角即将被杀→镜头切向门口，一双靴子踏入 |
| **攻击命中前一帧** | 7-9 | 攻击动作即将命中的瞬间定格 | 拳头/刀刃/子弹抵达目标前0.1秒→黑屏 |

**卡点强度达标阈值**：≥6/10

**卡点禁忌**（直接0分）：
- 结尾是大段对白收束，无视觉悬念
- 结尾是角色走路/看远方等无信息画面
- 结尾是"未完待续"文字提示而非画面卡点

## 五、核心方法论四：节奏拖沓检测

### 5.1 拖沓判定规则

> **拖沓定义：任何连续15秒无信息增量的段落。**

**信息增量四要素**（每10秒必须至少新增1项）：

| 信息类型 | 代号 | 定义 | 示例 |
|---------|------|------|------|
| **角色信息** | CI | 新角色出场/角色新特征揭示 | 新角色亮相/旧角色暴露隐藏特征 |
| **剧情信息** | PI | 剧情推进/新事件发生 | 发现线索/做出决定/发生变故 |
| **场景信息** | SI | 场景转换/环境变化 | 从室内到室外/从白天到夜晚 |
| **情绪信息** | EI | 情绪状态变化/关系转变 | 从愤怒到恐惧/从敌对到合作 |

### 5.2 信息密度检查

```
检查规则：
  → 每10秒至少1项新信息（CI/PI/SI/EI任一）
  → 连续15秒无任何新信息 = 拖沓段落
  → 连续30秒无任何新信息 = 严重拖沓，必须重构

信息密度公式：
  信息密度 = 信息增量次数 ÷ (时间段 ÷ 10秒)

达标标准：
  ≥ 1.0 = 合格（每10秒至少1项新信息）
  0.5-0.99 = 偏低，需关注
  < 0.5 = 拖沓，必须修改
```

### 5.3 单集时长控制

| 检查项 | 标准 | 偏差容忍 | 处置 |
|--------|------|---------|------|
| 单集时长 | 岗位2分集大纲中标注的目标时长 | ±10% | 超过±10%需调整 |
| 最短时长 | ≥目标时长的80% | — | 低于80%需补充内容 |
| 最长时长 | ≤目标时长的110% | — | 超过110%需剪裁 |
| 全剧时长一致性 | 各集时长偏差≤±15% | — | 偏差过大的集需重新平衡 |

**时长偏差计算**：

```
时长偏差 = (实际时长 - 目标时长) ÷ 目标时长 × 100%

示例：
  目标时长：90秒
  实际时长：105秒
  时长偏差 = (105-90)/90 × 100% = +16.7% → 超限，需剪裁15秒
```

### 5.4 场景转换节奏

| 规则 | 标准 | 违反处置 |
|------|------|---------|
| **最大场景数** | 每60秒≤3个场景 | 超过=节奏过碎，需合并部分场景 |
| **最小场景数** | 每30秒≥1个场景转换 | 不足=节奏过慢，需加快推进 |
| **场景停留** | 单场景最长不超过45秒（打戏除外） | 超过45秒=拖沓风险，检查信息密度 |
| **打戏场景** | 最长不超过60秒 | 超过=打戏冗长，需压缩动作描写 |

## 六、SD质检体系P0节奏项引用

> 来源：`（扣子独立版已内化的方法论模块）`
> 本岗位使用P0质检中与节奏相关的检查项作为对照基准。

### 6.1 P0剧本级·节奏相关项

| SD原编号 | 检查项 | 通过标准 | 严重程度 | 本岗位对照维度 |
|---------|--------|---------|---------|--------------|
| P0-3 | 叙事钩子到位 | 前10秒出现6种黄金钩子之一 | P0-致命 | → 映射至3秒钩子评分 |

### 6.2 P2成片级·节奏相关项

| SD原编号 | 检查项 | 通过标准 | 严重程度 | 本岗位对照维度 |

### 6.3 引用原则

1. **对照基准**：本岗位使用P0/P2标准作为对照基准
2. **增量检查**：SD已有的节奏项做对照，本岗位增加SD未覆盖的量化维度（冲突密度热力图、钩子三层评分、拖沓时间戳定位）
3. **严重程度对齐**：本岗位报告中的严重等级与SD体系对齐（致命/严重/一般），方便岗位8总编终审统一裁定
