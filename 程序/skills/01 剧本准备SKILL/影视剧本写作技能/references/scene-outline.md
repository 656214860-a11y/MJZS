# 分场大纲与场景设计

## 一、场景的定义

同一时间、同一地点的连续段落为一场。

如果场地没变，只是时空变了，也可以分场。

## 二、场景要素

### A. 时间和地点
- 时间：白天/黑夜，具体时段
- 地点：内景/外景，具体位置

### B. 转场（换场）
- 切至（CUT TO）——最常用
- 淡入（FADE IN）
- 淡出（FADE OUT）
- 叠化（DISSOLVE TO）

### C. 场景类型
- 内景（INT）——室内场景
- 外景（EXT）——室外场景
- 外景/内景——内外结合

### D. 场景作用
1. 推进情节
2. 展示角色
3. 营造氛围
4. 交代信息
5. 制造冲突

### E. 创作场景前明确4个问题
1. **谁驱动这场戏？**——确定场景的主体
2. **矛盾是什么？**——找出冲突核心
3. **价值变化是什么？**——开始和结尾的价值对比
4. **多长？**——预估时长，控制节奏

### F. 转场方式
- 硬切：直接切换场景
- 软切：通过动作或视觉元素过渡
- 声音先行：声音先于画面切换

## 三、场景分析四步法

### 第一步：确定冲突
- 找出是谁促使该场景发生
- 为什么
- 有什么样的矛盾冲突

### 第二步：分解节拍
- 找出动作与反应的交流
- 节拍之间以行为的明显变化来区分
- 节拍一个接一个进展形成独特节奏

### 第三步：概述节拍
- 找出期望与结果裂开鸿沟的瞬间
- 即转折点的位置
- 这也是三大冲突的爆发点

### 第四步：比较价值
- 比较场景开始和结尾价值的不同
- 是否有正负价值的转变
- 有什么意义

## 四、分场大纲写法

### 个人使用版
- 用电子表格
- 列：集号、分集内容、场景数、主要情节及时间
- 修改时用插入批注功能

### 对外推销版
- 把分集内容拷出来再修改
- 用大白话不温不火写出来
- 具体到事件
- 别掖着藏着怕剽窃
- 想尽办法把最抓人的东西写出来

### 由粗而细的加工
```
剧本大纲：对整部戏总括
  ↓
分集大纲：如全剧25集，每集一纲
  ↓
分场大纲：如每集30-50场，每场一纲
  ↓
剧本正文
```

## 五、场次与时间

### 电影
- 80-120分钟
- 平均一分钟一场戏
- 80-120场

### 电视剧
- 每集40-45分钟
- 国内常见30-45场（整体标准30-50场）
- 国外1分钟1场（30-50场）

### 情景喜剧
- 每集20分钟
- 8-12场

## 六、时间控制

### 剧本内容与时间
剧本只有"字数"，没有"时间"。时间指文字化的剧本经拍摄和剪辑后的成片长度。

### 三大时间要素
1. **对话**——影视对话慢于正常语速（含表演、抑扬顿挫、情绪起伏和伴随动作）
2. **空镜、过场**——几秒到十几秒，电影中不可忽视
3. **动作**——最难估算，伸缩空间大

### 对话时间控制
- 不够熟练时一边写一边念，掐表念几段对话
- 每场对话长度不平均摊开
- 写了对话丰满的重场戏后，在其他场次控制对话
- 各场次长度对应形成起伏和节奏

### 空镜过场
- 电视剧节奏慢，空镜过场不多
- 电影画面节奏快，空镜过场时间不可忽视
- 渲染情调和情绪的场面慎重使用（拖节奏）

### 动作时间
- 战争、枪击、格斗、追车等激烈场面无法精确估算
- 普通人物动作伸缩空间大
- 最好多打出一点时间，给导演预留余地
- 宁长勿短

### 节奏控制
- 1000字≈3分钟（简快明了风格）
- 1页剧本≈1分钟成片
- 整体长度在梗概阶段就应有数

## 七、序列概念

### 定义
一系列场景构建成序列，传达具有决定意义的变化。

### 特点
- 一般为二到五个场景
- 每个冲击力递增
- 最后达到顶峰

### 与幕的关系
- 一系列序列构成幕
- 幕以一个高潮场景为顶点
- 导致价值重大转折

## 八、场景设计常见问题

### 避免的问题
1. **人物总是吵架**——冲突不等于吵架，电影可以表现冲突的化解
2. **过场处理不干净**——八十年代前电影节奏慢的原因之一
3. **情节和视觉衔接不流畅**——影响叙事节奏
4. **渲染场面过多**——拖节奏，慎重使用

### 好的场景设计
- 每场戏都有存在的理由
- 场与场之间有因果关联
- 形成起伏和节奏
- 推动情节或展示角色
- 有价值变化（正负转变）
