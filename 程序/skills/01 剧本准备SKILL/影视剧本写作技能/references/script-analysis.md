# 拉片与剧作分析方法

## 一、剧作分析的重要性

### 为什么需要分析
- "熟读唐诗三百首，不会吟诗也会诌"
- 对成功作品的借鉴是最好的学习方法
- 对别人作品缺点的批判是提高鉴赏能力
- 鉴赏能力是创作能力的前提和基础
- "眼高"不一定"手高"，但"眼低"只能是"手低"

### 看片方法
- 泛读与精读结合
- 泛读：走马观花，保证看片量
- 精读：深入分析研究，写读片笔记
- 北京电影学院的学生就是大量影片"喂"出来的

## 二、拉片方法

### 什么是拉片
精读一遍片子，把场景一个一个写在纸上，然后考虑每一个细节。

### 拉片步骤
1. 逐场景记录：场景编号、时间、地点、内/外景
2. 记录每场戏的情节内容
3. 分析每场戏的功能
4. 统计序列数量、场次数量
5. 分析几场戏构成一个情节
6. 分析每个情节需要多少场戏
7. 分析序列如何组合

### 拉片示例
《暖春》数据分析：
- 33个序列
- 104场戏
- 除6个空镜，还有98场戏
- 平均2-5场是一个序列
- 重头戏可以多至六七个

### 拉片思考
- 他为什么把这个故事情节放到这里？
- 假如我来写会怎么写？
- 两者之间谁是最佳的方法？
- 对人物的对话：他为什么这么说？我写会怎么说？

## 三、剧作分析内容

对一部影片的剧作分析包括：

1. **题材选择**
2. **叙事风格**
3. **剧作样式**
4. **情节构思**
5. **人物设置**
6. **性格塑造**
7. **主题内涵**
8. **结构手法**
9. **细节运用**
10. **对话写作**
11. **声画关系**

### 分析原则
- 不需面面俱到
- 抓住该影片呈现出的特色部分
- 像介绍人的长相——抓住与众不同的特点

## 四、分析范例

### 《秋菊打官司》

1. **题材选择**
   - 中国农村广阔，戏剧性事件多
   - 编导偏偏选定一件司空见惯的小事——农村妇女不满村长打丈夫，从乡里告状到省城
   - 与地头蛇欺男霸女等相比太普通了
   - 但通过小官司过程展现农村组织结构问题、真实生存状态、典型人际关系

2. **风格特色**
   - 追求故事片真实性
   - 将喜剧性与纪实性完美揉合

### 《霸王别姬》分析要点

1. **激励事件**：卖子（艳红斩骈指卖小豆子给科班）
2. **三幕结构**：学艺期→鼎盛期→衰落期
3. **九个中心场景**：每幕三个序列
4. **主次情节**：主=程蝶衣的戏剧理想，次=三角爱恋
5. **主题**：人性与命运，戏梦人生
6. **结构特点**：时空顺序，因果相连，戏剧化节奏美

### 《唐人街》第二幕高潮场景分析

1. **确定冲突**：吉提斯拿到证据去找伊夫林对质
2. **分解节拍**：
   - 敲门/被卡恩挡住
   - 强行闯入/她期待他帮助
   - 探问真相/拒绝他
   - 打电话报警/恐惧他
   - 拿出证据/否认他的推断
   - 追问真相/吐露事实
   - 放她走/带女儿离开
3. **找出鸿沟**：第六个节拍——案件出现重大转折
4. **价值比较**：吉提斯从愤怒转化为同情和怜爱

## 五、场景四步分析法

### 第一步：确定冲突
- 是谁促使该场景的发生？
- 为什么？
- 有什么样的矛盾冲突？

### 第二步：分解节拍
- 找出动作与反应的交流
- 节拍之间以行为的明显变化来区分
- 节拍一个接一个进展形成独特节奏

### 第三步：概述节拍
- 找出期望与结果裂开鸿沟的瞬间
- 即转折点的位置
- 三大冲突的爆发点

### 第四步：比较价值
- 场景开始和结尾价值的不同
- 是否有正负价值的转变？
- 有什么意义？

## 六、影视基本常识

### 电影属性论
- 电影是宣传工具——国内主旋律概念
- 电影是商品工具——商业性电影
- 电影是机械记录现实的工具——纪录片理论
- 电影是表达爱与非爱的工具——欧洲个人化电影理论

不同创作目的有不同理论支持和操作方式，清晰知道自己的目的再创作很有好处。

### 字数与时间
- 电影剧本：28000-32000字
- 电视剧本：12000-18000字/集（40-45分钟，30-50场）
- 情景喜剧：5500字以内/集
- 字数代表的是时间，和抒情无关

### 投资与报酬（⚠ 教材旧例，仅作历史参考）

> **注意**：以下金额来自早期教材，早已脱离当前市场行情。引用前必须重新调研当下的行业数据，切勿直接套用。

- 电影投资：最少200万起（教材旧例）
- 电视剧投资：每集20-40万（教材旧例）
- 情景喜剧投资：每集约10万（教材旧例）
- 电视电影投资：40-60万/部（教材旧例）
- 编剧报酬：通常占总投资的5%-8%（教材旧例）

影视语言就是导演按照预定的顺序，把各个形象、各个要素（镜头）一个一个地接连而成的画面。
