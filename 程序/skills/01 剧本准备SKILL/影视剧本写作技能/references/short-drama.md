# 精品短剧创作规范

> 本文件覆盖**专业向精品短剧剧本**的创作。若用户需要竖屏短剧批量生成、一键成片，请引导使用 ai-short-drama 技能。

## 一、短剧是什么

短剧（微短剧）是单集时长极短（多为1-3分钟）、节奏极快、以强钩子驱动的视频剧种，主要在竖屏平台（抖音、快手、小程序等）播出。

与电影/电视剧的本质差异：

| 维度 | 电影/电视剧 | 短剧 |
|---|---|---|
| 单集时长 | 40-120分钟 | 1-3分钟 |
| 单集字数 | 12000-32000字 | 800-1500字 |
| 单集场景 | 8-120场 | 1-3场 |
| 出场角色 | 3-10+人 | 2-4人 |
| 节奏 | 铺垫-发展-高潮 | 3秒钩子-连续反转 |
| 观看场景 | 影院/客厅 | 碎片时间、竖屏 |
| 结构单位 | 幕 | 单集小事件 + 主线钩子 |

## 二、单集规格

- **时长**：1-3分钟（常见90秒-150秒）
- **字数**：800-1500字（含动作描述与对白）
- **场景数**：1-3场（场景越少越省钱越好拍）
- **角色**：2-4人（每集出场角色尽量少）
- **对白密度**：高于电影——短剧靠对白和反转推进，动作描述要短促有力

## 三、节奏铁律

1. **3秒钩子开场**：第一句台词/第一个动作必须在3秒内制造悬念、冲突或情绪冲击（"你根本不配做我妈！""离婚！马上离！"）
2. **每15-20秒一个小反转**：信息差、误会、身份揭晓、背叛、意外——单集内至少2-3次情绪起伏
3. **每集结尾留钩子**：悬念 / 反转 / 情绪爆发点，逼观众点下一集（"叮——您有一条新消息""他……竟然是他？"）
4. **整体法则**：前一集结尾的钩子 = 后一集开场的钩子，环环相扣

## 四、全剧结构

以常见80-100集为例：

- **第1-3集 · 立人设**：主角处境、核心矛盾、最大反转预期，快速建立观众代入
- **第4集至倒数第5集 · 单集事件+主线推进**：每集一个完整小事件（能独立成钩），同时主线伏笔逐步推进
- **最后5集 · 收束主线**：终极反转、真相揭晓、情感爆发、结局（爽/虐/和解）

关键：**每集都能独立抓人，但整体有一条贯穿主线**。纯单集段子剧（无主线）不属于本规范讨论范围。

## 五、题材与卖点

常见高热度题材：逆袭翻身、豪门恩怨、战神赘婿、复仇虐渣、甜宠错位、穿越重生、悬疑反转、家庭伦理。

无论题材，卖点三要素：
1. **情绪价值**：让观众爽（打脸）、虐（心疼）、甜（磕CP）、怕（悬念）
2. **身份反差**：扮猪吃虎、隐藏身份、阶层错位
3. **反转密度**：每集至少一个意料之外、情理之中的反转

## 六、格式要求

竖屏短剧剧本常用简式格式，场景标头精简：

```
第1集  夜  内  酒店房间

（画面）女主抬手，一记耳光扇在男主脸上。
女主：离婚！今天就离！
（特写）男主嘴角勾起，眼底全是算计。
男主：行啊……签之前，先看看这个。
（画面）女主接过文件，脸色骤变。
女主：这……不可能！
```

要点：
- 标头：集号 + 时间 + 内/外景 + 地点
- 动作描述用（画面）/（特写）/（慢镜）等极简提示，不写机位术语
- 对白短促，单句不超过30字为佳
- 每集结尾在文末标注【本集钩子】说明

## 七、创作流程

与电影剧本同源，但压缩迭代：

```
一句话故事（含最强反转点）
  ↓ 确认
梗概：全剧3-5句主线 + 每集一句话梗概表
  ↓ 确认
分集大纲：每集写出【开场钩子】→【本集小事件】→【结尾钩子】
  ↓ 确认
正文：按单集规格逐集写作（先写3集样章确认风格）
```

每集交付时附：
- 【本集钩子】：结尾用什么留人
- 【情绪走向】：本集让观众爽/虐/甜/怕
- 【主线推进】：本集推进了哪条主线/埋了哪个伏笔

## 八、常见错误

1. **把电影节奏塞进短剧**：前30秒还在铺垫，观众早划走了——3秒必须见钩子
2. **一集塞太多场景/角色**：成本高且节奏散
3. **对白书面化**：短剧台词要口语、有火药味、有潜台词
4. **结尾不设钩子**：每集结尾必须有"不得不看下集"的理由
5. **伏笔不回收**：短剧追更期短，主线伏笔要高频回收，不能埋太深
6. **忽视平台规则**：不同平台对时长、单集字卡、审核有要求，交付前提醒用户核对平台规范
