# 角色设定与人物传记

## 一、角色传记的写作

角色传记是一个"做加法"的过程，从五个方面做调查收集资料：

### 1. 故事发生的时代背景
- 政治环境
- 社会风貌
- 文化氛围
- 经济状况

### 2. 故事发生的时间
- 具体年代
- 季节
- 时段特征

### 3. 故事发生的地点
- 地理环境
- 文化区域
- 社区特征

### 4. 故事发生的相关时间
- 关键事件的时间节点
- 历史背景事件
- 人物命运转折点

### 5. 角色分类
- **主要角色**：故事的核心驱动者
- **重要角色**（次要角色）：与主要角色有密切关联
- **对立角色**：与主要角色形成冲突

## 二、角色分析

### 角色共性
分析时代特点和民族传统：
- 这个时代的人有什么共同特征？
- 这个民族的文化传统如何影响角色？
- 社会环境对角色的塑造作用

### 角色差异
从五个维度区分角色：
1. **观念**——价值观、信仰、世界观
2. **人生态度**——积极/消极、理想/现实
3. **个性**——内向/外向、果断/犹豫
4. **行为方式**——行动派/思考派
5. **动作**——具体的外在表现

## 三、角色冲突设计

### 方法一：力量抗衡
故事里的人物想做一些事情，但有一股力量抗衡他。
- 外部力量：社会制度、自然灾害、敌对势力
- 内部力量：自身弱点、道德困境、心理障碍

### 方法二：不能分解的关系
角色之间被命运或情感绑定，无法分离：
- 亲情（如父子、母女）
- 爱情（如三角关系）
- 责任（如师徒、战友）
- 仇恨（如世仇）

### 冲突类型
1. **角色与角色之间的冲突**
2. **角色与自身价值观的冲突**
3. **角色与社会的冲突**
4. **角色与自然的冲突**

## 四、角色塑造要点

### 细节决定角色
- 人物要有细节
- 细节要有张力，很有点
- 画龙点睛的细节就是剧本的闪光点
- 千万不要老生常谈

### 角色弧光
角色在故事中应有成长或变化：
- 初始状态 → 激励事件 → 挣扎与转变 → 最终状态
- 高潮部分通过两难选择完成主要人物的性格塑造

### 角色第一次出场
- 用黑体字标注
- 第一次出场要有鲜明的动作或场景来展示性格
- 避免用大段文字描述性格，用行动展示

## 五、角色与演员的关系

- 编剧写的是"人物"，不是"演员"
- 不要在剧本中指定演员
- 角色动作设计要考虑可行性
- 给导演和演员留出创作空间

## 六、角色数量控制

### 故事大纲中
- 主要人物不超过三个
- 每个人物个性、特点、背景不超过三行字

### 剧本正文中
- 根据故事需要设置角色数量
- 避免太多枝节角色
- 每个角色都要有存在的理由
- "Simple is the best!"

## 七、内心独白处理

### 什么时候用内心独白
- 角色有不可言说的感受时
- 需要展示角色内心世界时
- 关键转折点需要点明时

### 格式规范
```
角色名（内心独白）：独白内容……
```

### 注意事项
- 不可滥用，内心独白是辅助手段
- 优秀的剧本对白越少，画面感越强
- 能用画面表达的，不用内心独白

## 八、对白写作

### 对白原则
- 影视对话要慢于正常语速
- 对话也是一种动作
- 对白越少，画面感越强，冲击力越大
- 电影语言≠文学语言

### 对白功能
1. 推进情节
2. 展示性格
3. 交代信息
4. 制造张力

### 对白禁忌
- 不宜有太多对话（除非剧情需要）
- 否则故事不连贯，缺乏动作
- 观众看起来像听读剧本一样，好闷
- 只适合读不适合看的不是好剧本

### 对白与画面
- 一部优秀的剧本，对白越少，画面感越强
- 冲击力就会越大
- 能用画面表达的不用对白
- 对白和动作描述应形成起伏和节奏
