# 剧本格式规范与范例

## 一、单栏剧本格式（标准格式）

### 场景标头
```
序号. 内景/外景    场景发生的地点              白天/黑夜  页码.
```

示例：
```
1. 外景/内景        室外/室内（萨尔瓦多的故居）          白天1.
```

> **⚠ 页码说明**：场景标头**行尾的数字（如"白天1."中的"1."）是页码**，表示本页剧本的页码，不是场景元素，写作时按页自动递增。初稿无需手填，排版定稿时标注。

### 动作描述
- 详细描述镜头中的主体——角色的动作
- 可描述道具、角色位置、环境
- 长度在5/40格之间
- 画面化叙述，不用抒情句、修辞手法

### 角色名
- 写在台词上方，居中位置
- 使用黑体字
- 角色第一次出现要用黑体字

### 台词
- 在角色名下方
- 长度在10/34格之间
- 说话方式或情绪标注在括号内（18/26格之间）

### 转场方式
- 场景之间使用转场方式
- 黑体字标注
- 常用：切至、淡入、淡出、叠化

## 二、格式标注规范

### 黑体字使用
以下内容必须使用黑体字：
- a. 所有标注（内景/外景、白天/黑夜等）
- b. 角色第一次出现
- c. 机位、角度和镜头等简单推荐性提示
- d. 转场方式
- e. 对白角色的名字
- f. 场景换页但内容继续时写"CONTINUED"

### 空行使用
以下位置必须空行：
- a. 不同的场景之间
- b. 场景与转场方式之间
- c. 一个角色的台词与另一个角色的名字标注之间
- d. 角色的台词与镜头中主体的详细描述之间
- e. 两个镜头主体的详细描述之间

## 三、镜头相关说明

### 剧作者不需要告诉导演怎样运用视听语言
- 视听语言是导演的功课
- 对"摄影机的机位、角度"和"细致的镜头术语"不要具体写作
- 如确需，只写出简单推荐性的提示
- 对于120分钟的电影剧本，这种提示可能少到只有十处

### 镜头定义
镜头（shot）就是摄影机所看到的东西。

### 主镜头和局部镜头
- **主镜头**（master shot）：覆盖一个场景的全貌（如一个房间、一条街道）
- **局部镜头**（specific shot）：专拍场景的某一部分（如房门、商店门前）
- 写完"内景/外景·地点·时间"后，可从任一镜头开始
- 具体写作时不标明是主镜头还是局部镜头

### 找出镜头中的主体
- 角色正在画面内进行动作或对白
- 或完成动作并离开画面（出画）
- 画外对白为画外音

        母亲示意坐在身边的萨尔瓦多的妹妹，萨尔瓦多的妹

## 五、日本/中文剧本格式（参考《入殓师》）

### 场景标头格式
```
时间  内/外景  场景名称
```

示例：
```
夜  内  演奏厅
夜  外  大悟的公寓·外观
日  内  大悟公寓起居室  同上
```

### 动作描述
- 直接叙述，画面化
- 不用引号标记动作

### 角色名与台词
```
角色名：台词内容

角色名（情绪/状态）：台词内容
```

### 内心独白
```
角色名（内心独白）：独白内容……
```

### 画外音
```
角色名（画外音）：台词内容
```

### 范例（《入殓师》）
```
夜  内  演奏厅
在古典音乐的演奏厅里，回旋着大提琴优雅的乐声。
正在演奏的人是大悟。
大悟一副陶醉的神情演奏着，但乐队其他成员的脸上，
却多少流露出一丝冷淡。

夜  内  演奏厅·后台
大悟：今天人也挺少呀。
同僚：恩。
大悟：我看，在多拍发些宣传册就好了。
同僚：……
大悟（内心独白）：这简直就是晴天霹雳。好不容易才得到
管弦乐队演奏者的职位，就在这短短的一瞬间，已经化为
过去的记忆了。
```

## 六、格式选择建议

### 电影剧本
- 推荐使用标准单栏格式（好莱坞格式）
- 场景标头完整：序号 + 内/外景 + 地点 + 时间
- 转场方式明确标注

### 电视剧本
- 可使用简化中文格式
- 场景标头：时间 + 内/外景 + 地点
- 对白用"角色名：台词"格式

### 短剧/网络剧
- 可进一步简化
- 但保持场景、动作、对白三要素清晰
- 注意画面感
