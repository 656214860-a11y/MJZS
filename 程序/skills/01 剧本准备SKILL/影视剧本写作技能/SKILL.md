# 影视剧本写作技能

## 概述

本技能基于专业编剧教材与经典电影剧本实例（含《入殓师》《天堂电影院》《霸王别姬》等完整范例），提供从零到完整剧本的端到端创作指引。涵盖故事构思、角色塑造、结构搭建、格式规范、写作技巧、修改方法与拉片分析。

**核心原则**：剧本创作是从粗到细、逐级确认的渐进过程，每个阶段都有明确的产出物规格。写剧本 ≠ 写小说——用文字表达画面，不写抒情句和内心描写。

## 触发场景

- 用户要写剧本、创作影视故事（电影/电视剧/情景喜剧/精品短剧）
- 用户需要编写故事梗概、大纲、分场分集
- 用户需要角色设定、人物传记
- 用户需要剧本格式排版、格式规范指导
- 用户要修改润色已有剧本（改稿）
- 用户需要拉片分析、剧作分析
- 用户询问编剧基础知识、写作技巧

## 技能边界（重要）

为避免与其他技能冲突，请按下述规则路由：

| 用户需求 | 使用技能 |
|---|---|
| 专业影视剧本创作（电影/电视剧/情景喜剧/精品短剧） | **本技能 screenplay-writer** |
| 长篇小说 / 网文创作 | novel-writing / novel-writer |
| 竖屏短剧批量生成、一键成片 | ai-short-drama |
| 剧本生视频、分镜成片 | script-to-video |
| 端到端剧本工作室（含 AI 视频提示词、Seedance 等） | script-writing-studio |

当需求同时命中多个技能时，以本技能为准处理**剧本文本创作本身**；涉及成片/批量生成时引导用户切换到对应技能。

## 执行协议（拿到请求后按此顺序工作）

### Step 0 · 需求确认（必做，先问清再动笔）

开工前必须收集齐剧本基础信息。**请以 `assets/script-info-form.txt`（剧本创作开发总表）为收集工具**：把总表**区块A（项目档案）**展示/发送给用户填写，AI 按表逐项核对，缺（必填）项时主动询问（用户无法回答时取表格中标注的默认值，并明确告知"已采用默认值"）。

> 范例先行：用户不知如何下笔、或首次使用本技能时，**先展示 `assets/script-info-form-example.txt`（《哪吒闹海》填写范例）**——十二个部分全部填写完毕的对照样板，用户照着葫芦画瓢即可；之后再发空白总表区块A。

区块A需收集的信息（与总表一一对应）：

1. **类型**：电影 / 电视剧 / 情景喜剧 / 精品短剧 / 短片 / 其他
2. **题材与类型片**：主类型+副类型（爱情、悬疑、动作、喜剧……）
3. **篇幅**：电影（分钟数）、剧集（集数×每集时长）、短片（分钟数）
4. **时代与地点**：故事发生的年代与空间
5. **平台与观众**：院线 / 网络平台 / 电视台；目标观众群体
6. **已有素材**：有完整构思 / 一句话点子 / 改编原作（改编须确认授权）
7. **创作目标**：参赛投稿 / 商业开发 / 学习练习
8. **人物初设**：主要人物（≤3个）的姓名、身份、一句话特质、核心欲望与内在需求

产出：**填写完成的《剧本创作开发总表》区块A**，向用户复述确认（尤其是类型/篇幅/主题/一句话故事/核心冲突/改编授权六项），确认后再进入 Step 1。

> 提示：总表分两块——**区块A（项目档案）开工即填；区块B（专业创作区）不在开工时填写**，而是随后续阶段逐级登记：第六部分故事梗概（Step 2 定稿后）、第七部分悉德·菲尔德基本框架（Step 4 确认后）、第八部分段落大纲（Step 4-5 之间）、第九部分分场大纲（Step 5）、第十部分人物弧光追踪（Step 3 定稿后）、第十一部分伏笔与呼应登记（写作中随埋随记）、第十二部分分集大纲（电视剧/情景喜剧项目）。后续各阶段模板（梗概/角色/正文）中重复的字段（片名、类型、人物名等）一律从总表带入，避免重复询问。

### Step 1 · 创意构思

**做什么**：确定创作起点——"有感而发"才能"有话可说"。
**产出物**：主题（不超过三行字）+ 一句话故事 + 类型定位。
**给用户看**：一句话故事，确认方向后再继续。

1. **寻找主题**：从感兴趣的话题出发，主题即"思想立场"。来源途径：新闻热点、社会现象、个人经历、民间传说、历史事件、文学作品改编。
2. **提炼一句话故事**：
   - 格式1：某主要角色 在做/做了/遇到 某事情
   - 格式2：某主要角色 在 某地点 在做/做了/遇到 某事情
   - 格式3：某时间 某地点 某主要角色 在做/做了/遇到 某事情
3. **明确类型**：故事片、战争片、爱情片、喜剧片、灾难片、科幻片、动作片、恐怖片、动画片。

### Step 2 · 故事梗概（阶段确认节点①）

**做什么**：写让制片人了解故事内容的文件。
**产出物**：1000-2000 字故事梗概。
**给用户看**：梗概全文，**必须等用户确认后才进入角色传记**。
**登记**：定稿后把三句话故事、段落梗概（起承转合）、完整梗概登记到总表第六部分。

**三要素**：说了什么故事 → 体现什么主题 → 有什么创意。

**写作规范**：
- 主题不超过三行字；主要人物不超过三个
- 一行一行写，不用对白、形容词、性格描述、独白
- 白描手法，叙述清晰；注意"起承转合"：一上来就进入状态，高潮处一句话结束
- 检查错别字——有错别字，人家一看觉得编剧没文化

详见 `references/story-outline.md`，填空用 `assets/outline-template.txt`。

### Step 3 · 角色传记

**做什么**："做加法"，从五个方面收集资料。
**产出物**：每个主要角色的传记文档（按 `assets/character-bio-template.txt` 填写）。
**给用户看**：角色档案摘要，确认角色关系与冲突设计。
**登记**：角色定稿后，把每个主要角色的弧光（A状态→B状态、揭露时刻、Want→Need 转变）浓缩登记到总表第十部分。

1. 故事发生的时代背景；2. 故事发生的时间；3. 故事发生的地点；4. 故事发生的相关时间；5. 主要角色、重要角色、对立角色。

**角色分析**：
- 角色共性——分析时代特点和民族传统
- 角色差异——观念、人生态度、个性、行为方式、动作

详见 `references/character-design.md`。

### Step 4 · 三幕式框架

**做什么**：搭建整体结构骨架。
**产出物**：三幕结构表（每幕的核心任务、主要序列、转折点位置与预估页码）。
**给用户看**：结构表，确认后再分场。
**登记**：把激励事件、情节点Ⅰ/Ⅱ、（中点、至暗时刻）、高潮、结局（各含预估页码）登记到总表第七部分；序列划分登记第八部分（电视剧落实为第十二部分分集大纲）。

采用悉德·菲尔德的经典三幕式框架：

| 幕 | 功能 | 占比 | 核心任务 |
|---|---|---|---|
| 第一幕（起） | 建立冲突 | 约25% | 介绍角色、设定情境、激励事件打破平衡 |
| 第二幕（承转） | 展开冲突 | 约50% | 冲突升级、鸿沟扩大、转折点层层推进 |
| 第三幕（合） | 解决冲突 | 约25% | 高潮对决、价值转变、结局收束 |

**结构微观链条**：节拍 → 场景/事件 → 序列 → 幕 → 故事。

详见 `references/story-structure.md`。

### Step 5 · 分场大纲

**做什么**：把结构落实为一场一场的纲要——形成剧本前的关键过程。
**产出物**：分场大纲表（序号 / 内·外景 / 地点 / 时间 / 场作用 / 主要情节 / 价值+/- / 预估时长）。
**给用户看**：大纲表，确认后可先按集/幕交付审阅。
**登记**：分场表完成后登记到总表第九部分，价值+/-需正负交替（连续三场同向即调整），并按"场景四问"自查重场戏。

**场景定义**：同一时间、同一地点的连续段落为一场。

**场景要素**：
- A 时间和地点；B 转场方式；C 场景类型（内景/外景、白天/黑夜）；D 场景作用
- E 创作场景前明确 4 个问题：谁驱动这场戏？矛盾是什么？价值变化是什么？多长？

**写法**：可用电子表格，列出集号、分集内容、场景数、主要情节及时间。

详见 `references/scene-outline.md`。

### Step 6 · 剧本正文（阶段确认节点②）

**做什么**：按照标准剧本格式逐场写作。
**产出物**：符合格式规范的剧本正文（按 `assets/script-template.txt`）。
**给用户看**：剧本正文——建议先交付 1 场样章确认格式与文风，再批量推进；全稿完成后整篇交付。

**格式核心要素**：
- 场景标头：序号 + 内/外景 + 地点 + 时间（日/夜）；**行尾数字是页码**，不是场景元素
- 动作描述：画面化叙述，5-40格；角色名：居中，黑体；台词：角色名下方，10-34格
- 转场方式：切至、淡入、淡出、叠化（黑体）

详见 `references/script-format.md` 和 `assets/script-template.txt`。

## 改稿润色协议（用户提供已有剧本时）

不从头走创作流程，直接进入修改环节：

1. **通读理解**：先通读全文，判断剧本类型、阶段（初稿/二稿/定稿）、体量
2. **诊断问题**：按以下维度逐项检查，输出「问题清单」：
   - 结构：三幕是否完整、激励事件是否到位、高潮是否有力
   - 冲突：是否"冲突=吵架"、有无鸿沟设计、张力是否持续
   - 人物：角色是否有弧光、动机是否清晰、对白是否千人一面
   - 格式：场景标头、黑体、空行、转场是否符合规范
   - 画面感：是否混入小说式抒情/内心描写（三大忌检查）
   - 字数/场数：是否符合对应类型规范（见下表）
3. **与用户确认修改范围**：整体重写 / 局部修改 / 仅格式整理 / 仅润色台词
4. **执行修改**：逐项修改并说明改了什么、为什么改；改后给出「修改说明」清单
5. **交叉检查**：改稿后检查伏笔是否闭合、时间线是否一致、人物称呼是否统一

## 拉片分析协议

用户要求分析某部影片/剧本时：

1. **确认对象**：给出片名/剧本文件路径；无文件时按用户口述或经典片例进行
2. **拉片流程**（详见 `references/script-analysis.md`）：
   - 逐场景记录：编号、时间、地点、内/外景、情节内容
   - 统计序列数、场次数，分析几场构成一个情节
   - 分析每个场景的功能与价值变化（场景四步分析法）
3. **输出分析报告**（固定结构）：
   ```
   《片名》剧作分析报告
   一、题材与叙事风格
   二、三幕结构与激励事件
   三、主要人物与弧光
   四、情节与序列拆解（含场次统计）
   五、冲突与鸿沟设计
   六、特色细节与对白
   七、可借鉴之处 / 值得批判之处
   ```
4. 报告语言平实、抓住特色，不需面面俱到

## 字数与时长规范（唯一权威标准，各参考文档均已与此一致）

| 类型 | 时长 | 字数 | 场景数 |
|---|---|---|---|
| 电影剧本 | 80-120分钟 | 28000-32000字 | 80-120场 |
| 电视剧本（每集） | 40-45分钟 | 12000-18000字 | 30-50场 |
| 情景喜剧（每集） | 20分钟 | 5500字以内 | 8-12场 |
| 电视电影 | 90分钟 | 27000-28000字 | - |
| 10分钟短片 | 10分钟 | 约3000字（动作/留白为主可低至2000字） | - |
| 15分钟短片 | 15分钟 | 约4500字（动作/留白为主约3500字） | - |
| 30分钟中篇 | 30分钟 | 约8000字（动作/留白为主约7000字） | - |
| 60分钟独立电影 | 60分钟 | 约19000-20000字 | - |
| 精品短剧（每集） | 1-3分钟 | 800-1500字 | 1-3场 |

**换算规律**：简快明了的写作风格 **1000字≈3分钟**（对白叙述为主的常规密度）；1页剧本≈1分钟成片。短片因动作、留白、空镜占比高，文字密度约为 200字/分钟——这是短片字数低于换算值的唯一原因，不是矛盾。

## 精品短剧规范（专业向）

适用于有剧作要求的精品短剧；**批量一键生成请引导用户使用 ai-short-drama 技能**。

详见 `references/short-drama.md`。核心要点：

- 每集 1-3 分钟，800-1500 字，1-3 场戏，角色 2-4 人
- 节奏铁律：**3 秒钩子开场**、每 15-20 秒一个小反转、每集结尾留钩子（悬念/反转/情感爆发）
- 全剧结构：第 1-3 集立人设，中段每集一个完整小事件+主线索推进，结尾集收束主线
- 格式：竖屏，场景少而精，对白密度高于电影，动作描述短促

## 编剧三大忌

1. **写剧本变写小说**：剧本用文字表达画面，不用抒情句、修辞手法、内心描述。让读者见文字即联想到画面。
2. **用对话交代剧情**：对白越少，画面感越强，冲击力越大。电影语言≠文学语言。
3. **故事太多枝节**：Simple is the best! 愈简单愈好。但简单永远是最困难的。

## 核心写作技巧

### 创造角色冲突
- 方法一：人物想做事，但有一股力量抗衡（外部：社会/自然/敌对势力；内部：弱点/道德困境）
- 方法二：不能分解的关系（命运纠葛：亲情、爱情、责任、仇恨）

### 创造表面张力
- 让观众知道角色不知道的事（信息不对称）
- 让观众感到角色走在错误的路上
- 设置时间限制（倒计时）
- 使用转折点制造意外效果

### 其他技巧
- **伏笔**：埋下伏线吸引追看，观众回头看才恍然大悟
- **关键匙**：象征整个故事的对象（如《公民凯恩》的"玫瑰花蕾"）
- **蒙太奇**：把不同画面按创作意图组接，产生单个镜头不具备的新意义（详见 `references/writing-tips.md`）
- **鸿沟**：人物期望与客观结果之间的落差，推动情节发展（行动→反应→鸿沟→新行动……）

## 合规与伦理提示（必读）

1. **改编授权**：改编小说、真实人物、历史事件时，必须提醒用户确认版权与授权问题；未授权不承诺可用于商业开发
2. **内容红线**：不输出违法、宣扬暴力恐怖、涉及未成年人色情等违规内容；涉及政治历史题材时提示用户谨慎处理
3. **数据时效**：教材中的投资金额、行业行情类数据仅作历史参考，引用前需以当下行业调研为准
4. **原创性**：鼓励原创；参考经典剧本结构可以，禁止整段照搬抄袭
