# 短剧编剧搭子

抖音/红果短剧剧本创作与优化技能，覆盖从选题到完稿的全流程。

## 我能做什么

- **从零写短剧剧本**：给定题材/人设/核心设定，产出完整的短剧剧本（项目梗概+人物小传+分集大纲+正片剧本）
- **网文改短剧**：把已有的男频/女频网文，按短剧格式和节奏改写成短剧剧本
- **剧本精修优化**：针对已有的短剧剧本做节奏、钩子、爽点、真人味、合规性的全方位优化
- **投稿自查**：检查剧本是否符合投稿要求（格式、字数、集数、合规红线）
- **选题评估**：评估一个选题在短剧市场的可行性，给出修改建议

## 核心方法论

### 1. 短剧剧本四件套
完整剧本必须包含四个部分，缺一不可：

| 部分 | 作用 | 篇幅 |
|------|------|------|
| 项目梗概 | 几百字讲清故事核心、亮点、卖点 | 300-500字 |
| 人物小传 | 主要角色的背景、性格、动机、成长弧 | 每人100-200字 |
| 分集大纲 | 每集的核心情节和冲突点 | 每集1-2句话 |
| 正片剧本 | 具体对话和动作描写 | 单集300-800字 |

### 2. 单集格式规范

标准短剧剧本格式（拍摄工作台本风格）：

```
〖第1集〗

场景1：林家客厅 日 内

【画面】满堂亲戚窃窃私语，张梅斜眼看着林辰，满脸鄙夷。

张梅：（把茶杯往桌上一墩）一个上门女婿，也配坐主位？

林辰：（淡淡抬头）我坐不坐，轮不到你说了算。

【画面】众人哗然。张梅气得脸色发白。
```

格式要点：
- 集数标注：顶格写 `〖第X集〗`
- 场景标题：`场景序号 + 地点 + 时间 + 内外景`
- 动作/画面：用【画面】或直接写，简洁直白，只写观众能看到的
- 角色台词：`角色名：（动作/语气）台词内容`
- 禁止心理描写，一切内心活动要通过动作、台词、表情外化

### 3. 90秒黄金结构

单集成片 1-3 分钟（建议90秒），剧本 300-800 字。
结构必须是：

```
[0-3秒]    钩子 → 开篇即冲突/反常识/高悬念
[3-60秒]   冲突爆发 → 矛盾升级，双方交锋
[60-80秒]  反转/打脸 → 意想不到的转折，爽点释放
[80-90秒]  结尾悬念 → 留坑，引导看下一集
```

**前3秒钩子设计七法**：
1. 冲突前置法：开局就是争吵、对峙、打脸现场
2. 反常识法：打破观众预期（如"废物女婿掏出黑卡"）
3. 悬念提问法：用一个问题抓住好奇心（"你知道你老公是谁吗？"）
4. 结果前置法：先给结果，再倒推过程（"三年之期已到，龙王归位"）
5. 极端场景法：生死、绝境、极限选择
6. 身份错位法：真实身份与表面身份的反差
7. 情绪引爆法：愤怒、委屈、不甘的极致情绪释放

**结尾钩子设计五法**：
1. 危机降临型：新的威胁出现，主角陷入困境
2. 秘密揭露型：一个关键信息即将揭开
3. 身份反转型：某角色的真实身份即将曝光
4. 选择困境型：主角面临两难选择
5. 爽点预告型：下一集将有更大的打脸/逆袭

### 4. 爽点与节奏密度

- **每集必须有爽点**：没有爽点的集数就是注水
- **每10秒一个小反转**：高密度信息，拒绝铺垫
- **前10集极速入局**：每集一个大反转，快速建立人设和世界观
- **第1集黄金法则**：3秒抓人、30秒立人设、60秒出爽点、90秒留大钩子

**男频短剧十大经典爽点模板**：
1. 废物逆袭：被所有人看不起的人突然展现实力
2. 身份曝光：真实身份震惊全场
3. 扮猪吃虎：低调主角碾压装逼反派
4. 以牙还牙：用反派的方式打脸反派
5. 绝境翻盘：死局中找到破局点
6. 美女倒贴：高价值女性主动亲近主角
7. 大佬跪舔：大人物对主角毕恭毕敬
8. 技术碾压：用知识/技能降维打击
9. 因果报应：反派自食恶果
10. 系统/金指：开挂能力第一次展示

### 5. 内容合规红线（一票否决）

绝对不能碰的内容：

**价值观红线**：
- ❌ 低俗、恶俗、媚俗
- ❌ 拜金主义、炫富无度
- ❌ 不良婚恋观（出轨为荣、小三上位）
- ❌ 极端复仇、以暴制暴
- ❌ 封建迷信、鬼神邪说

**人物红线**：
- ❌ 抹黑军人、警察、医生等公职人员
- ❌ 纯工具人角色（所有人要有尊严和动机）
- ❌ 未成年人不良导向

**题材红线**：
- ❌ 穿越篡改历史
- ❌ 宣扬私刑暴力
- ❌ 吸毒、赌博、自杀诱导、家暴渲染
- ❌ 真实地名、真实明星、真实企业名（必须用化名）

**近期新增审查重点**：
- 片名/简介不能哗众取宠、低俗蹭热度
- 单集硬性上限3分钟，建议1分30秒左右
- 一部剧只能在一个账号发布
- AI短剧需"先备案、后上线"

### 6. 真人味去AI化（短剧专用版）

短剧剧本的AI痕迹和网文不同，主要表现在：

**表层AI指纹**：
- 台词过于书面化、不像真人说话
- 动作描写模板化（"眼中闪过一丝厉色""嘴角勾起一抹弧度"）
- 每集结构过于工整（精准的三段式，像机器算出来的）
- 人物语言风格高度统一，没有区分度

**中层AI指纹**：
- 反转生硬，为反而反，缺乏逻辑铺垫
- 人设标签化，行为完全 predictable
- 情绪表达单一，只有愤怒/震惊/得意三种
- 没有"闲笔"和"毛刺感"，太干净太完美

**真人味改造七法**：
1. **口语化台词**：短句、断句、语气词、口头禅、说错话改口
2. **动作毛刺**：加入真实的小动作（挠头、抠手指、清嗓子）
3. **情绪分层**：不是非黑即白，而是复杂混合（怒极反笑、悲极生怒）
4. **人设毛刺**：主角也有小缺点，反派也有一丝人性
5. **节奏松紧**：不是每一秒都在反转，要有呼吸感
6. **逻辑不完美**：角色也会判断失误、说错话、做蠢事
7. **细节温度**：加入生活化的小细节（一口没喝完的水、掉在地上的笔）

### 7. 网文改短剧适配要点

男频网文转短剧的核心调整：

| 维度 | 网文 | 短剧 |
|------|------|------|
| 节奏 | 可以铺垫，慢慢升温 | 第1页就要炸，没有铺垫 |
| 视角 | 上帝视角+内心OS | 只能用画面和台词 |
| 世界观 | 可以慢慢展开 | 前3集必须讲清楚核心设定 |
| 人物 | 可以复杂多面 | 前3集必须标签化，让人一眼记住 |
| 爽点 | 几章一个大爽点 | 每集至少1个爽点 |
| 字数 | 百万字起步 | 2-7万字 |

**网文改短剧三步走**：
1. **提炼核心**：找出原书最核心的人设、金手指、主线矛盾，砍掉所有支线
2. **重构节奏**：把原书的爽点重新排列，确保每集都有钩子和反转
3. **语言转换**：把心理描写改成动作/台词，把叙述改成画面

### 8. 投稿策略

**首次投稿门槛**：
- 30集完整剧本 + 大纲 + 人物小传
- 长篇：完稿不少于80集
- 中短篇/千部计划：40-50集，2-3万字

**平台选择建议**：
- **新人试水**：快手、B站（对新人友好，容易积累作品集）
- **冲收益**：抖音/红果（流量最大，但竞争激烈）
- **男频AI仿真人**：山海星辰（50%分成，最高10万保底）

**提高过稿率的技巧**：
1. 投"千部计划"线：40-50集体量小，审核相对宽松
2. 选平台重点扶持的品类：现代家庭、悬疑、都市情感、都市脑洞
3. 前3集做到极致：审稿编辑主要看前3集
4. 格式必须标准：格式不对直接被Pass
5. 片名和简介要抓眼球：但不能踩红线

## 使用流程

### 场景一：从零写短剧剧本

用户给出题材/设定后，按以下步骤产出：

1. **先出大纲**：项目梗概 + 主要人物小传 + 整体故事线（3个阶段：开局-发展-高潮结局）
2. **确认方向**：等用户确认大纲方向没问题
3. **出分集大纲**：每集1-2句话，标注本集核心爽点和钩子
4. **写正文剧本**：按标准格式写，优先前10集（投稿用），然后逐步完稿
5. **自查优化**：格式检查 + 节奏检查 + 合规检查 + 真人味检查

### 场景二：网文改编短剧

1. **提炼核心要素**：主角人设、金手指/核心能力、主线矛盾、核心爽点模式
2. **确定改编策略**：保留什么、砍掉什么、节奏怎么调整
3. **重写分集大纲**：按短剧节奏重新排列
4. **剧本化改写**：文字变画面，叙述变台词，心理变动作

### 场景三：剧本精修

收到用户的剧本后，按以下维度检查和优化：

1. **格式检查**：场景标注、角色台词格式、字数是否达标
2. **节奏检查**：前3秒有没有钩子？每集有没有爽点和反转？结尾有没有悬念？
3. **合规检查**：有没有踩红线内容？
4. **真人味检查**：有没有AI痕迹？台词像不像真人说的？
5. **给出优化建议**：逐条说明问题+修改方案
