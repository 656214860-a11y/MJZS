# 短剧剧本格式模板

## 完整剧本四件套模板

### 1. 项目梗概模板

```
【项目名称】XXX
【题材类型】都市逆袭/古装甜宠/悬疑推理/...
【集数建议】80集/60集/50集
【单集时长】90秒
【核心卖点】一句话说清楚最大的亮点和差异化
【故事梗概】
300-500字，讲清：主角是谁、遇到了什么事、核心冲突是什么、最终要达成什么目标、过程中最大的看点是什么。
```

### 2. 人物小传模板

```
【主角-姓名】
年龄：XX岁
身份/职业：
性格：3个核心关键词+具体表现
背景故事：为什么会变成现在这样
核心动机：他/她最想要什么
成长弧光：从什么样的人变成什么样的人
口头禅/标志性动作：（增加辨识度）

【反派-姓名】
年龄：
身份：
性格：
核心动机：为什么和主角作对
弱点：（便于被主角利用）

【重要配角-姓名】
...
```

### 3. 分集大纲模板

每集一句话，标注爽点类型和钩子：

```
第1集：【场景】【爽点：身份错位】【钩子：危机降临】
第2集：【场景】【爽点：扮猪吃虎】【钩子：秘密揭露】
...
```

### 4. 正片剧本模板

```
〖第1集〗

场景1：林家客厅 日 内

【画面】满堂亲戚窃窃私语，张梅斜眼看着林辰，满脸鄙夷。

张梅：（把茶杯往桌上一墩）一个上门女婿，也配坐主位？

林辰：（淡淡抬头）我坐不坐，轮不到你说了算。

【画面】众人哗然。张梅气得脸色发白，手指颤抖地指着林辰。

张梅：你……你敢这么跟我说话？

林辰：（站起身，气场全开）为什么不敢？

【画面】林辰缓缓摘下眼镜，眼中再无半分怯懦。门外，一排黑色轿车停下。

【黑场，字幕：三年之期，已到。】
```

## 格式规范细节

### 场景标题格式
- 必须包含：场景序号 + 地点 + 时间 + 内外景
- 时间：日/夜/晨/昏
- 内外景：内/外
- 正确示例：`场景1：林家客厅 日 内`
- 错误示例：`第一幕：客厅`（缺序号、缺时间、缺内外景）

### 动作描写格式
- 用【画面】开头，或直接写（两种风格都可以，但全剧要统一）
- 只写观众能看到的，不能写心理活动
- 正确：`林辰握紧了拳头，指节发白。`
- 错误：`林辰心里非常生气，他觉得张梅太过分了。`

### 台词格式
- 角色名顶格，后跟冒号
- 语气/动作放在角色名后的括号里
- 台词不加引号
- 正确：`张梅：（拍桌）滚出去！`
- 错误：`张梅说："滚出去！"`

### 字数与时长参考
- 300字 ≈ 1分钟
- 450字 ≈ 1分30秒
- 600字 ≈ 2分钟
- 800字 ≈ 2分30秒（接近上限）
- 建议控制在400-600字/集，给拍摄留余地

## 投稿格式要求

- 文件格式：Word（.docx）或 PDF
- 字体：宋体，正文小四，标题四号
- 行间距：1.5倍
- 页码：底部居中
- 文件名格式：《剧名》-编剧名-集数
