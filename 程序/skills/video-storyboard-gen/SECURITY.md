# 安全政策

## 支持范围

安全修复面向当前 `main` 分支。此项目不保存凭据、不调用网络，也不执行用户输入；但路径处理、输出注入、误导性内容边界和依赖供应链仍属于安全审查范围。

## 报告漏洞

请使用 GitHub 仓库的 **Security > Report a vulnerability** 私下报告。若该功能不可用，请联系仓库所有者，并在获得安全渠道前不要公开利用细节。

报告请包含受影响版本、复现步骤、影响、建议修复和是否已公开。请勿在测试中访问不属于你的系统或数据。维护者会尽快确认报告，但不承诺固定响应时限。

普通功能缺陷、内容建议和平台参数更新请使用公开 issue，不作为安全漏洞提交。
