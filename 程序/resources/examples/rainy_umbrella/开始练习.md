# 雨夜修伞 · 首次制作练习

项目首页点击“创建练习项目：雨夜修伞”。每次创建独立副本，10镜、每镜6秒、2人2景；没有首帧、声音或成片，也不预先标记任何阶段完成。

## 原创练习剧本
雨夜，顾川抱着坏伞来到林禾的修伞铺，怀里的信仍是干的。林禾检查伞骨，取出备件，在灯下修好。顾川递给她干毛巾。两人到门口试伞，顾川撑伞继续送信，林禾挥手送别。

人物：林禾，修伞人，深蓝围裙；顾川，快递员，橙色雨衣。地点：暖灯下的修伞铺、雨夜店门口。对白和建议时间已放在episode.json；实际配音后重新对齐。

## 按顺序练习
1. 在剧本准备中保存上面的剧本，填写创作简报与制作锁。建议60秒、竖屏1080×1920、25fps、二维动画；按页面提示补齐必填项。
2. 在初步分镜核对10镜内容；角色和场景只是文字设定，进入资产管理制作或导入你有授权的参考图。核对服装、灯光及引用后再定稿，不跳过前置门禁。
3. 在模型管理确认文本、图片、视频和TTS模型配置及连接。没有可用模型时，按[制作失败与人工替代](../../../docs/process/制作失败与人工替代.md#从失败处继续操作)导入授权素材；不要把空配置视为免费。
4. 先选SH001试做一镜：记录价格表版本、预计图片次数、视频秒数、TTS字符及预算。价格缺失则费用未知；单镜验收后再批量。总预算应包含失败和重试，而不是单镜成本直接乘10。
5. 制作首帧与视频；成功镜头保留，任务状态未知先查询，避免重复提交。配音可导入自己的录音；确认字幕时间，再在剪辑阶段生成预览。
6. 完整观看60秒，核对10镜、对白、字幕和音画同步。导出成片、字幕与编辑清单，打开实际剪辑软件验证。技术通过与商用资料核验分开记录。
