# R479 全量回归收口与可靠性修复

## 完成内容

- 将密钥相关测试的 Windows DPAPI 依赖替换为带格式校验的可逆假保护器，继续验证加密保存、读取和拒绝损坏密文的行为。
- 开发信息页的复制邮箱测试改为验证调用唯一剪贴板出口；实际系统剪贴板写入由该出口的专用测试覆盖。
- `workflow_engines.terminate()` 在 `taskkill` 后等待已登记进程实际退出；超时后直接终止并再次等待，避免“已停止”返回时子进程仍在运行。

- 架构门禁 75/75、默认冒烟 8/8 通过。
