# R1312：O07 白模工作目录的项目身份与集维度

类型：功能轮，承接 R1267 清单 O07（O01—O06 已完成）。中央轮次 1312。

## 实现
- `white_model_service`（L2）：白模镜头目录从「工作区／项目目录名／镜头」改为「工作区／项目身份／集／镜头」。
  - 项目身份取项目 `config.json` 的 `project_id`。身份写在项目目录内，所以项目改名或整体移动后跟着走，不会串到另一处同名项目；没有这一项时仍按旧布局解析，旧成果只读兼容、不迁移不改名。
  - 集身份按可信度取值：镜头编号自带的 `EP…_` 前缀 → 本次调用显式传入的 `source` → 项目 `ui_settings.json` 的 `frame_json`／`storyboard_file` → 配置的 `episode_file`。项目移动后配置里的绝对路径会失效，此时按阶段目录名在项目内重新定位同一份分镜，集号不会退回「未分集」。都无法判定时落到 `未分集` 段，绝不与外集混放。
  - 目录段统一过安全文件名转义；身份缺失或含分隔符一律当没有，不猜、不带出工作区。
- `projects.create`：新建项目当场写入 `project_id`（uuid4）。新建项目从第一天起就按身份隔离，同名项目互不覆盖。
- `migrate_legacy_directories`（L2）＋ `stage_execution_service.migrate_white_model_directories`（L3 注入正式发布器）：把旧布局目录迁入身份布局。
  - 可重复：项目已有身份直接返回，不重复搬；
  - 不覆盖：新目录已存在就跳过并记账，旧目录原样保留；
  - 失败回滚：搬迁中途或身份落盘失败，已搬目录按逆序原样搬回，旧成果保持可用、身份不落盘；
  - 迁移清单落到 `工作流任务/白模目录迁移/<时间>/迁移清单.json`：逐镜记录 `episode_id`、旧/新目录与来源版本（分镜路径、集号、字节数、修改时间），并记 planned／completed／rolled_back 状态。
  - 任一旧目录找不到对应采用分镜时整批不开始（不把旧成果藏进读不到的布局）；项目配置读不出来时拒绝写入身份。
- 白模页（09）在无任务运行、项目尚无身份或存在旧目录时调用一次迁移，结果写进页面状态；失败只提示原因，不阻断页面。
- `previs_batch_service`、`previs_automation`、白模页（09）、视频页把本次集来源显式传进目录解析，避免跨集只按「当前集」猜。

## 风险与边界
- 未实发 Blender 或线上白模调用、未重启应用；目录隔离为单元与静态验证，不等于真实交互验收。
- 未迁移的旧项目仍用旧布局：同项目两集都用 SH001 时，旧布局下仍共用同一目录；这正是要在打开白模页完成迁移后消除的窗口。迁移不删除任何旧成果，也无法映射的旧目录会让整批迁移不开始并给出原因。
- 迁移清单的「来源版本」记录的是迁移时刻的分镜路径／集号／字节数／修改时间，不是内容哈希；后续镜头调度变化的过期判定属于 O09。
