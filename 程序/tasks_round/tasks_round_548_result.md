## 发布契约

1. 调用方提供现有内容校验器；空白文本或校验器返回 `False` 时立即失败，不创建或覆盖成果。
2. 校验通过后复用 `agent.core.save_text()`，其同目录临时文件与 `replace()` 语义保证成果替换原子化。
3. 成果发布后才执行调用方提供的既有索引更新。
4. 索引更新抛异常时，`restore_bytes()` 恢复旧内容（新文件则移除），异常继续向上传播。函数不会发送完成事件、不会吞掉该异常，也不会返回成功路径；阶段完成仍只能由既有核验/完成服务在成功后决定。

本轮仅修改 2 个 Python 模块（一个生产模块、一个测试模块）；没有新增页面、功能、依赖、层级或对外接口变更。
