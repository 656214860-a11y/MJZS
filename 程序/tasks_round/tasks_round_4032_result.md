# R4032 Git 显式提交隔离和中断续接
修复轮。实施范围是显式文件模式的提交器与相关测试。无路径模式和合并轮沿用现有索引语义。需求决策沿用两轮澄清的 1A、2A 与 1A、2A、3A。
- 验收 A：无关暂存存在时，调用不改变 HEAD 和索引；提交开始之后并发新增的暂存路径不会夹带。
- 验收 B：同一工作树、同分支、同任务的原进程退出后，输入、证据和索引均匹配时可以接续。重新执行本轮应有的验收；无法证明归属时保留现场并报告差异。其他工作树和执行者不能争用正在执行的同一轮次。
- 验收 C：回执丢失且对应提交仍在当前分支父链时，核验父版本、任务和变更树后返回已有提交。后续合法提交不受影响。
- 首次复现：未修的 master 03e66cef 运行 R4027 的显式隔离用例，预暂存 A、指定 B 时 main 返回 0（期望拒绝）。
- 助手分工：CR-I 独占提交器实现；CR-T 独占新测试。主控单独验证并集成。执行结论以实际运行记录为准。
- 主控复验：13 项既有提交器测试通过；14 项新增回归已逐项验证，覆盖竞争执行者、输入漂移、合并父链以及回执丢失。另以隔离克隆实跑提交钩子并模拟提交后硬退出，后续 HEAD 前移仍返回原提交。CR-I 因服务不可用由主控接手，CR-T 交付测试后由主控修正临时仓库夹具。
