## 1. 总目标

**让付费墙、会话凭据、设备绑定这三件事真正成立，并补上退订退款的商业闭环。**

现状是「文档写得细，但代码与文档已对不上，且有 6 个设计漏洞」。其中 3 项高危：

- **B-1** 门禁开关 `GATE_ENFORCED` 是明文模块常量，改一行废掉 11 个收费阶段
- **B-2** `session.json` 明文存 `refresh_token` 无完整性校验，复制文件即接管会话
- **B-3** 设备指纹回退种子 `device_seed` 就存在**同一个** `session.json` 里，复制文件即搬走设备指纹
- **C-1** 全仓 `/v1` **无任何退订／退款端点**，上线收费即纠纷

**可验收目标**：消除 B-1／B-2／B-3，补齐 C-1／C-2／C-4，并把 6 项决策登记为 ADR。

**明确不做**（见 §2 D6／D7）：不加模型启用开关、不加额度查询、不做图片验证码、不做用户侧 2FA、不引入 `jsonschema`、不换 UI 框架。

### 轮 2：`session.json` 文件级 HMAC（B-2）

**改动**（桌面端）：
1. 新建 `infra/session_integrity.py`（L1）：
   - `seal(data) -> dict`：对规范化 JSON（`sort_keys=True`、`separators`、UTF-8）算 HMAC-SHA256，附 `_mac` 与 `_mac_key_id`
   - `verify(data) -> bool`：常量时间比对（`hmac.compare_digest`）
   - 密钥：32 字节随机，经 `model_secrets.protect` 加密存 `程序/private/账户/.mac_key.dpapi`；密钥丢失时 `verify` 返回 False 并允许重新登录（**不阻断用户**）
2. `infra/account_store.py`：`_write()` 写前置 `seal()`；`load()` 读后 `verify()`，**校验失败按"未登录"处理**（清空并提示重新登录），不静默接受
3. **重述 D10**：`account_store.py` 模块 docstring 与 `说明/账户会员云端设计.md` 需说明——MAC 只防篡改、不防搬运，与"不走 DPAPI 机器绑定"的 D10 意图**兼容**，不是推翻

**验收勾选**：
- [ ] 正常写入→读取 round-trip 通过
- [ ] 手工改动 `session.json` 任一字段 → `verify()` 返回 False，加载按未登录处理（**负向自测必做**）
- [ ] 删除 `.mac_key.dpapi` → 不崩溃、按未登录处理、可重新登录恢复
- [ ] 密钥文件本身是 DPAPI 密文（断言头部 20 字节符合 `model_secrets` 的识别规则）
- [ ] `session.json` 内容不进日志、不进任务 JSON（沿用既有约束，抽查）
- [ ] 定向：`-k account_store session_integrity`
- [ ] 冒烟 + 架构门禁，红集与改前一致

## 6. 风险与回滚

| 风险 | 触发 | 处置 |
| --- | --- | --- |
| **锁死用户**（轮 2 MAC、轮 5 时钟） | 密钥丢失／注册表损坏 | 一律**降级到"未登录/仅本机基线"**，不允许崩溃或永久拒绝；提示用户重新登录即可恢复 |
| **升级丢设备指纹**（轮 1） | 迁移逻辑错误 | 迁移必须幂等且**指纹值不变**（验收项已列）；先在副本上跑迁移再上主树 |
| **改 `GATE_ENFORCED` 削弱测试**（轮 3） | patch 改法降低断言强度 | 结果文件逐条写明改前改后断言；**不得删测试、不得跳过** |
| **服务端宽限窗口放大重放风险**（轮 7） | 窗口过长 | 默认 10 秒且可配；窗口外行为不变；文档写明取舍 |
| **退款登记被当成"已退款"**（轮 10） | 界面或文档措辞不清 | 状态命名 `requested`，**不叫 `refunded`**；文档写明"不自动退款" |
| **两端版本不匹配**（轮 4／7／9／10） | 服务端先上、客户端未更新 | 服务端接口**向后兼容**（新字段可选）；客户端遇未知字段忽略不报错 |
| 多车道并行冲突 | 同时改 `entitlement_service.py` | 轮 3／5／6 都改该文件，**必须串行**；不与其他车道并行 |

**回滚**：每轮独立提交（`R<N>: ...`），失败 `git revert` 单提交；**优先 revert 不 reset**（`AGENTS.md §2.6`）。服务端与桌面端分别回滚。
