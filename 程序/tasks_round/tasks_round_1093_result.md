## 根因与边界

压缩文件的 1 MB 限制不能约束 DOCX/XLSX 解压量；原 ZipFile.read 全量读取 XML。XLSX 共享字符串重复引用还会放大转换文本。现在所有被读取 XML 都经过同一预算：单成员 2,000,000 字节、累计 8,000,000 字节；先检查声明大小，再 read(剩余额度 + 1) 检查实际字节。重复读取同一成员同样累计计费。转换输出（含分隔符和表头）限 1,000,000 字符，对输出累计计数，超限即拒绝继续转换；错误只展示文件名及拆分建议。

不解析嵌入对象、不执行公式；原缓存值、工作表顺序和中文文本语义不变。API 原文件 1 MB、本地原件 50 MB、API 提示词 24000 字上限不变。API 转换超预算明确拒绝；本地模式仍保留原件并省略失败的转换稿，继续传项目内路径。归档、下载、简报引用和 API 文本边界机制未改。

预算限制是受控读取边界，不声称 Office 文件全面安全审计或 XML 解析内存精确上限；没有对真实用户附件进行压力测试。
