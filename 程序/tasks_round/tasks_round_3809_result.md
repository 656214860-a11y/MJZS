## 关键设计结论（本轮拍板）

1. **UI 框架锁定 Tkinter**（ADR-0013）。实测：控件数量是瓶颈、目录扫描是瓶颈，**都不是换框架能解决的**；PySide6 需重写 106 个 UI 模块 + 上千测试，工期 3–6 个月，用户明确不接受。
2. **不把主存储搬到 SQLite**。实测：3000 镜 JSON 2.5 MB／解析 9.6 ms／查找 0.066 ms，不是瓶颈；真瓶颈是目录扫描 583 ms。维持「JSON 真源 + SQLite 派生层」，判据写死为「丢了能不能重建」。
3. **3000 镜表格用分页 + 筛选**（每页 ≤100 行），表格内不放缩略图（`asset_thumbs` 是实测热点）。
4. **安装双通道**：Inno Setup（个人）+ WiX MSI（企业）；**首期不买代码签名证书**，用 minisign 签 `SHA256SUMS`，并写明升级到 Authenticode 的三个触发条件。
5. **高 DPI 是必修缺口**：当前无任何 `SetProcessDpiAwareness` 调用，Windows 缩放下位图拉伸导致发虚，与 PRD §5.4「支持 4K 缩放」不一致。
