# R583 修复轮结果：桌面自动流程测试调用点迁移

## 结果

完成 P0 回归治理的第一簇修复：将 3 条仍调用已移除 `Desktop.tick()` 的测试迁至当前 `_tick_once()` 入口，并隔离启动对账测试中无关的首帧项目选择计时器。未改生产代码、业务规则或用户数据。

## 根因

R555 将 `tick()` 的自动流程调度重构至 `DesktopAutomationScheduler`，桌面保留 `_tick_once()` 作为调度器注入的单次执行回调；旧测试仍直调已不再公开的 `tick()`。另一个测试在异步首帧项目选择的状态提示执行后才读取对账状态，造成与对账无关的状态覆盖。

## 改动

- `tests/test_ui_edges.py`
  - 自动粗剪、自动交接两类测试的 3 个 `d.tick()` 调用改为 `d._tick_once()`；原有产物、状态、幂等和失败恢复断言均保留。
  - 启动对账测试在创建 `Desktop` 后取消仅属于项目选择的 `startup_controller` 计时器，避免其“正在打开今日项目…”提示覆盖被测的对账状态；对账动作与断言不变。

本次改测试因控制器接口迁移，断言未动。
