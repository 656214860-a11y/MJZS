# R1605 全量失败闭环修复

类型：修复轮（含全量基线验证）。来源：R1604必要全量回归失败；未完成全量，不切换O8。

## 根因与修复
1. 发布锁引用随附Windows Python不支持的fcntl，导致3项导入闭包失败。agent/publication.py改用既有msvcrt锁；非Windows显式拒绝，不绕过依赖扫描。
2. 空持久队列启动领取仍创建事务并递归清理日志。desktop_automation_service.py在同一读取锁内确认无候选后返回，有候选仍按事务领取。
3. 宠物启动静默期同步递归盘点。pet_ui_voice.py静默期读取缓存，结束时仍按实际缺口对表；没有放宽启动零递归标准。启动探针补齐traceback导入及失败栈；宠物测试验证静默期不盘点、结束后盘点。
4. 资产页面测试以源码tests目录作为应用目录，新持久历史写入tests/outputs导致全量凭据无效。两处夹具改为临时应用目录。
