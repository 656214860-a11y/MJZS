# R477 密钥回归的环境隔离

## 轮次类型

全量安全自检失败归类与测试迁移。

## 根因与整改

- `unittest discover -f` 在 1,252 项后显示 `test_pet_llm.CredentialTests` 直接调用真实 Windows DPAPI；当前会话 DPAPI 不可用时，两项纯凭据优先级测试失败。
- 测试改为注入格式化可逆假保护器：可验证保存/读取，也能识别损坏密文；生产 DPAPI 行为没有改动。

## 验证

- 原失败凭据测试 3/3 通过。
- 全量 fail-fast 尚待从本轮变更后重新执行并继续收口。

## 后续

- 若全量再报错，按首个可复现错误逐项区分产品缺陷、测试环境耦合与外部服务依赖，修复后重跑。
