# R658｜修复轮：创意对话文本选择高亮契约

## 开工三问与验证档位

1. 本轮只处理创意对话气泡文本框的选择高亮色与既有 UI 回归契约不一致的问题。
2. 不改动消息内容、对话状态、控制器逻辑、用户项目数据或模型调用。
3. 修复目标是使可复制的消息文本在活动和非活动选择状态均使用既定的 `#3564a8`。

本轮改动涉及 1 个模块，按分级规则执行默认冒烟 + `--affected desktop`，跳过架构门禁和全量，理由：单模块 UI 样式契约修复，未触及导入关系、启动路径、用户数据格式、L0 契约或删除路径。

## 改动文件清单

- `desktop.py`：创意对话消息文本框的活动/非活动选择背景和选择前景色恢复为既定 UI 契约值。

确认：未改动用户数据、对话内容、项目资产、模型调用或页面控制器逻辑。
