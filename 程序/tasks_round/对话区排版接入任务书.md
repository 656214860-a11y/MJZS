## 0. 总目标

「01 剧本准备」页里模型的回话，现在是把原文直接贴进气泡：`**加粗**`、`# 标题`、`- 列表` 这些记号原样露在外面。本书把它接到程序里已有的排版模块上：

1. **模型回话按排版显示**：标题、加粗、行内代码、代码块、列表（编号保留、嵌套分层）、引用、分隔线。
2. **用户自己发的话不变**，仍按原文显示。
3. **边写边排**：回话还在一段段出来的时候，写完的行就排好，没写完的那一行先按原文显示。
4. **复制不走样**：「复制这条」得到原文；用鼠标选中再复制，得到看到的文字。
5. **别的页面也能用**：排版函数做成任何文本框都能调用的形式，后面给第 2 到 13 页加「过程与回话区」时直接用。

**明确不做**（原因见 §4.5、§9）：表格对齐；把「先结论、再分点、最后给下一步」写进提示词；第 2 到 13 页的「过程与回话区」；可点的选项卡片。

### 2.4 Tk 文本框标签的两条特性（设计依据）

1. 同一个字上有多个标签时，后创建的标签优先级高，除非用 `tag_raise` 调整。气泡标签每条消息新建一次，一定比先建好的排版标签优先级高。所以每次插入后必须把排版标签提到气泡标签上面，否则加粗、代码底色都会被气泡标签的字体和底色盖住；提完还要把 `sel` 再提到最高。
2. `text_widget.tag_names()` 不带参数时，按优先级从低到高返回全部标签，测试用它判断优先级。

```yaml

名称: parse() 加「对话口径」：不吞正文、保留编号、列表分层、空行规则
类型: 功能轮（需求 REQ-S01-99、设计 DES-S01-99 已由主控写进 docs/stages/S01_剧本准备.md，本卡不改文档）
车道: codex/chat-render
前置: 无

  - 程序/ui/skill_note_render.py

  - 程序/tasks_round/tasks_round_<N>_result.md
接口契约:
  函数: "parse(markdown, *, profile='note') -> list[tuple[str, tuple[str, ...]]]"
  新增常量: "NOTE = 'note'；CHAT = 'chat'；LIST_L2 = 'list_l2'；LIST_L3 = 'list_l3'"
  note 口径: 与改动前逐片段相同（已有测试全部不改且通过）。profile 传别的值一律按 note 处理。
  chat 口径与 note 的差别（只有这五条，其余相同）:
    - C1: 不删开头的文件头。开头的 --- 和别处的 --- 一样，是一条分隔线，它后面的文字照常显示。
    - C2: 不识别「正在生成中文说明」这类提示前缀，这些行按普通正文处理（不出 hint 标签）。
    - C3: 编号列表保留数字。行首是「数字加 . 或 )」时，片段文字以「数字. 」开头（原文写 3) 也输出 3. ；数字照抄，不重新编号）。无序列表仍以「• 」开头。
    - C4: 列表分层。按行首缩进算层级：维护一个缩进栈；遇到列表项，先把栈里比它缩进大的弹掉，栈空或栈顶比它缩进小就把它的缩进压栈，层级等于栈的长度（制表符按 4 个空格算）。第 1 层的标签是 (LIST,)；第 2 层是 (LIST, LIST_L2)；第 3 层及更深是 (LIST, LIST_L3)。遇到不是列表项的非空行，栈清空；空行不清空。列表项里的加粗、行内代码照常拆成片段，层级标签加在这一项的每个片段上。
    - C5: 空行。两个块之间有一个或多个空行时，输出一个空行片段 ("\n", (BODY,))。下列情况不输出：全文开头和结尾；上一块或下一块是标题或分隔线；上一块和下一块都是列表项。代码块内部的空行照旧是代码行。
    - 「块」的定义: 每个非空的原文行是一块；一个围栏代码块（从开围栏到闭围栏）整体算一块；被跳过的注释不算块。
  不变: apply() 的签名和行为（它只用 note 口径）；所有现有标签名；任何输入都不抛异常；parse 不依赖 Tk、不读写文件。

  - T6: 空行规则。把 chat 口径的片段文字拼起来比较——
      "甲\n\n\n乙" 得 "甲\n\n乙\n"；
      "# 标题\n\n正文" 得 "标题\n正文\n"；
```

## 6. 风险与回滚

| 风险 | 等级 | 缓解 |
| --- | --- | --- |
| 模型把剧本草稿放在回话里，行首的「1.」「-」被排成列表，观感改变 | 中 | 只改显示，不改保存的文件，「复制这条」仍是原文；目检时用真实剧本草稿看一眼；不满意时由主控决定把范围收窄到「非产物回话」 |
| 排版标签的优先级低于气泡标签，加粗和代码底色不生效 | 中 | CHT-2 的 T3、T7；CHT-3 的 T7 |
| 选中高亮被代码底色盖住（违反 REQ-S01-65） | 中 | `insert()` 的 R5；CHT-3 的 T4、T7 |
| 流式阶段每拍整段重排，长回话卡顿 | 中 | CHT-4 的 S3、T3 |
| 已有用例断言了模型回话的原文 | 中 | CHT-3「测试期望变更」：停下报告，由主控逐条定 |
| 新增同层依赖造成互相引用 | 低 | LR-03 守着；CHT-3 禁止事项 |
| 旧对话重画后外观改变 | 低 | 这正是目标；记录文件一个字不改 |

**回滚**：每张卡独立提交，按 CHT-4、CHT-3、CHT-2、CHT-1 的顺序 `git revert`；回滚 CHT-3、CHT-4 时把阶段文件里对应需求的状态改回 ⬜。不用 `reset --hard`，不删工作树。本书不改任何保存格式，回滚不需要迁移数据。
