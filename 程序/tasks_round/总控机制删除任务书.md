# 内建总控退役任务书

文件名中的 R3811 是历史任务标签，不是预留轮次。执行者必须按开工时的仓库规则领取真实轮次，禁止直接沿用本标签或预先占用 ADR 编号。

## 1. 目标与已确认决策

用户决定：应用不再内建一套总控来管理 SKILL；以后安装的 SKILL 可携带自己的创作说明。删除内建总控数据、专用桥接代码和专用工具，保留通用 SKILL 注册、安装、引用解析、阶段执行和制作锁能力。

已确认：

- 删除 `skills/00全流程SKILL/`，不迁入 legacy，历史通过 Git 查询。
- 删除专用机检桥 `infra/aigc_lint.py`、维护脚本 `维护记录/基准脚本/aigc_package_diff.py` 及应用专用的五个工具注册。
- 五个工具不重写、不补替代实现：`feed.validate`、`feed.gateCheck`、`feed.auditContract`、`style.lockRecommend`、`style.lockLadder`。
- 保留 `/engine` 交互类别，取消对内建总控路径的依赖，改为从已有的用户 SKILL 注册与发现机制获取候选。不得另建一套绕过注册器的发现、安装或执行体系。
- 本任务与目录治理分开交付；后一任务依赖本任务通过验收。

4. 下表是 2026-11-19 的盘点线索，不是当前树事实的替代品。重新核对后才编辑；行号与数量只用于定位。
5. 一次提交应形成可运行、可独立回滚的完整变化。不得先提交删包、再让坏掉的调用链留到下一轮。
