## 2. 要改（两处，都很小）

### 改动 1：去掉 `* 9 // 10` 折扣

**现在**（`runtime_context_length`，约 `:35-36`）

```python
        if failed_tokens:
            limits.append(max(1, int(failed_tokens) * 9 // 10))
```

**改为**

```python
        if failed_tokens:
            # 被拒只证明「这个量不被接受」，上界即此量本身。
            # 乘折扣系数是引入无依据的猜测，不是收紧。
            limits.append(max(1, int(failed_tokens)))
```

**理由**

- 一次请求被认为 65000 token 而被拒，**能安全推出的上界就是 65000**。
- 乘 0.9 得到 58500，是把一个**已知上界**换成一个**更小的猜测值**。
- 更麻烦的是：`failed_tokens` 来自 `token_saver.request_tokens()`，本身是**估算**。
  估算 × 0.9 是「估算的估算」，两层不确定性叠加。
- 上界不够紧的代价是「可能多拒一次」；引入无依据系数的代价是「凭空造数」。
  前者可接受，后者正是本任务书要消灭的模式。

### 改动 2：学习值不参与预检判定

**现在**（`_context_preflight`，约 `:382-396`）用 `runtime_context_length` 的结果做阻断：

```python
        limit = min(configured, learned) if configured and learned else learned
        if limit and token_saver.request_tokens(payload) > limit:
            error = '本次请求超过服务端拒绝后收紧的上下文窗口（%d token）。%s' % (...)
            return {... 'reason': 'context_budget_exceeded' ...}
```

**改为**：预检**只用显式 `context_length`**；学到的上界只用于**提示**，不用于阻断。

```python
        configured = model_pool.context_length_of(self._context_record(target).get('context_length'))
        learned = runtime_context_length(self._context_record(target))   # 仅提示用
        if configured and token_saver.request_tokens(payload) > configured:
            error = '本次请求约 %d token，超过该模型已配置的上下文窗口 %d。%s' % (
                token_saver.request_tokens(payload), configured, CONTEXT_OVERFLOW_ADVICE)
            return {'ok': False, 'status': 0, 'kind': 'configuration', 'error': error,
                    'error_class': 'context_overflow', 'reason': 'context_budget_exceeded',
                    'model': target, 'text': '', 'usage': pet_llm.usage_of(None), 'accepted': False,
                    'failure': failure_policy({'error_class': 'context_overflow', 'accepted': False})}
        return None
```

**理由**：V2 §A1 规定观测值「**不得**参与预检判定，否则等于把猜测换了个字段名」。
阻断能力仍由**显式配置**提供——那条路径本来就是正确的。

> **允许保留的唯一自动收紧**：若已有显式 `context_length`，且观测值明确**更小**，
> 可下调到观测值（用观测推翻更乐观的旧配置，方向安全）。**仅降不升**，且须写日志记录改前改后值。
