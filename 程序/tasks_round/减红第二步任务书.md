### 2.4 工具脚本的编码报错

- 现象：合入时终端打印 `UnicodeDecodeError: 'gbk' codec can't decode byte 0xab in position 5`，出自 `subprocess` 的 `_readerthread`；合入本身成功。R3970、R3974 两次合入都出现。
- 复现（在任一车道的 `程序\` 下；不带 `-X utf8`，环境变量里没有 `PYTHONUTF8`）：

```powershell
& $PY -B -c "import sys, pathlib; sys.path.insert(0, str(pathlib.Path('维护记录') / '基准脚本')); import lane_registry; print(lane_registry._worktree_info(pathlib.Path('.')))"
```

  现在的输出：先是上面那条 `UnicodeDecodeError`，然后 `AttributeError: 'NoneType' object has no attribute 'strip'`（`lane_registry.py` 第 41 行），退出码 1。加上 `-X utf8` 后输出正常：`('<车道目录名>', 'codex/<分支>', 'D:/漫剧制作助手/.agents/worktrees/<车道目录名>')`。

- 范围（语法树扫描版本库里 1579 个 `.py`／`.pyw`：`subprocess.<函数>` 形式的调用 256 处，其中捕获文本又没指定编码的 39 处）：

### 4.0 通用规则（把任务卡交给执行者时，连同本节和 §4.6 一起给）

1. 只在指定的车道工作树里干活。车道由主控建好：`git worktree add -q -b codex/<名> 'D:/漫剧制作助手/.agents/worktrees/<名>' master`。不进主工作区 `D:\漫剧制作助手` 改文件、切分支或提交。
2. `PY` 指 `D:\漫剧制作助手\运行环境\Python\python.exe`；命令都在车道工作树的 `程序\` 下运行；终端是 Windows PowerShell 5.1（没有 `&&`，用 `;`）。
3. 开工先读 `程序\AGENTS.md`，再领号：`PY -B 维护记录\基准脚本\round_claim.py next`，得到轮次号 N。
4. 改代码的轮次先写测试、看到它红，再改实现；改前的失败输出贴进结果文件。
5. 结果文件 `tasks_round\tasks_round_<N>_result.md`：标题 `# R<N> 结果：<一句话>`，第一节 `## 1. 三问`，回答「轮次类型」「测试跑了吗、三个基线过了吗」「欠账少了吗」。
6. 提交只用任务卡里的「提交」命令（文件路径相对 `程序\`，写在 `--tests` 前面）。不用 `git add -A`，不用 `--no-verify`，不 `git push`，不自己合并。提交后 `git status --short` 必须为空。
7. 不跑全量测试（`run_selftests.py --all`／`--safe`、`smoke_test.py --all`／`--safe`）。会开窗口的测试经 `scripts\gui_hidden.py` 在隐藏桌面跑。
8. 临时脚本放 `$env:TEMP`，用完删除。不在车道的 `程序\` 下放临时 `.py`：架构门禁会把它当成新模块而失败。
9. 不读、不写、不输出任何账号、密钥、令牌；输出里的系统用户名换成 `%USERNAME%`。不动别人的车道、分支和锁。
10. 调用子进程读取文本时显式写 `encoding="utf-8"`（§2.4）。

## 6. 风险与回滚
