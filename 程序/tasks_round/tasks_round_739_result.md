# R739 结果｜同日自动续开首屏壳修复

## 修复内容

- `desktop.py`：自动续开进入 `show_loaded_project()` 后，`show(0)` 现在先替换旧“我的项目”页为“剧本准备／正在打开剧本准备…”的轻量可见壳。
- 完整的 `writing()` 页面构建延后 40ms 执行；这给 Windows 一次实际消息循环和重绘机会，不再让旧项目页停留到完整建页结束。
- 项目恢复维护和启动心跳跟随完整页面构建后再排程，避免它们抢在首屏壳之前阻塞。
- 关闭窗口时会取消新增的待建页回调，防止窗口销毁后的 Tk 残留回调。
- `test_desktop_startup_perf.py` 新增并收紧回归：`show_loaded_project` 仅允许在 0.2 秒内完成，且必须先显示剧本准备状态、随后完成完整页面。

## 验证

- `smoke_test.py`：8/8 通过。
