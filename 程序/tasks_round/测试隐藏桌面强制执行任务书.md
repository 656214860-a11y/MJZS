## 1. 总目标

把「含 Tk 的测试一律在隐藏桌面运行、不弹到用户屏幕」从**文档约定**升级为**运行器强制**，并保证规则不再回潮。

- **现状**：除后台自动补跑（post-commit → `auto_full_safe.py` → `工作流任务/gui_hidden.py`）外，所有测试入口——
  `run_selftests.py`（默认/`-k`/`--serial`/`--all --safe` 等全模式）、`smoke_test.py` 各门禁（`--gate`/`--affected`/`--architecture`）与默认 widget 检查、`dev.py full`、`dev.py commit --tests`、`local_ci`、三虎测试模式——都在用户可见桌面直接跑含 Tk 的测试，窗口弹到用户屏幕。
- **目标**：载体入库（任何工作树/干净检出可用）+ 唯一咽喉点自包装（全部入口一次覆盖）+ 失败即中止（绝不降级直跑）+ 门禁守护（回潮即红）。

## 2. 已确认决策清单（用户已拍板，执行者不得自行变更）

1. 隐藏桌面包装逻辑收编为**入库模块** `程序/scripts/gui_hidden.py`；主工作区的旧 `工作流任务/gui_hidden.py`（未跟踪运行现场）停止被引用、留作历史，不删除用户现场文件。
2. 硬闸放**唯一咽喉点**：`run_selftests.py` 自包装（检测本轮范围含 Tk 测试 → 用入库模块把自己重新拉起到隐藏桌面）；`smoke_test.py` 默认模式的进程内 widget 检查同样接入。`dev.py`/`local_ci`/三虎等调用方不改（它们最终都调 `run_selftests.py`）。
3. 判定方式：**自动检测**（扫描本轮范围测试模块是否 `import tkinter`／建 `tk.Tk()`），不维护人工登记表。
4. 隐藏桌面创建失败 → **中止并告警**，绝不降级直跑；`auto_full_safe.py` 删除「helper 缺失则直跑」的静默 fallback，缺失/失败记 **BLOCKED**（环境阻塞不冒充测试红）。
5. 生效范围：**agent 会话与用户手动跑一视同仁**。唯一逃生舱：`--visible` 显式参数（默认关，打印醒目警告），仅人工调试用；后台补跑禁止 `--visible`。
6. 每轮 smoke 附带**秒级自检**：只探测「隐藏桌面能否创建」（`--probe`），失败即报错，不静默。
7. 新增**架构门禁测试**守护（回潮即红），登记进 `architecture.md`「当前架构门禁清单」并同步基线。
8. `selftest_scheduling.sink_test_windows()`（置顶改写＋压底，第 31 期第 3 条）恢复调用，定位为最后一道缓解，不承担防弹窗职责；断言与测试契约不动。
9. 仓库外钩子 `~/.claude/hooks/gui_test_guard.py`（R1837 所装）**废弃不再维护**，职责收敛到入库硬闸。
10. 验收：门禁红绿记录进结果文件 ＋ **用户亲眼看一次 `--all --safe` 全量，桌面零窗口**。
11. 全任务书执行完成后，按规则 35 输出《任务完成文件》至 `程序/tasks_round/任务完成/`。

## 5. 测试方案

- 修复轮：先红后绿——先写/先跑门禁与定向用例（记录失败输出），改完复验到绿（AGENTS.md §5「写测试」）。

## 6. 风险与回滚

| 风险 | 缓解 |
|------|------|
| 自包装递归/死循环 | `DRAMA_HIDDEN_DESKTOP=1` 环境标记：已置则直接跑，绝不二次包装 |
| 隐藏桌面下托盘/按键用例行为差异 | 既有平台豁免（`skip_reasons.PLATFORM_NO_TRAY_HOST`）不变；`fresh_children` 机制保留，断言不动 |
| 与并行车道 add/add 冲突（新文件 `scripts/gui_hidden.py`） | 开工前 `dev.py scope`；提交时 `commit_round.check_scope_overlap` 兜底 |
| `--probe` 拖慢每轮 smoke | 建桌面即销毁，秒级；失败才展开告警 |
| 隐藏桌面不可用（服务会话等） | 一律中止＋BLOCKED/告警，不静默、不弹窗（宁可不测） |
| 回滚 | 修复轮为单一变更集，`git revert` 整轮回退；旧 `工作流任务/gui_hidden.py` 保留在原位可手工恢复旧路径 |
