# R736 结果｜当天项目选择记忆修复

**轮次类型：** 修复轮。

## 根因与修复

- 根因：当天项目选择只在“选择项目”弹窗的“进入项目”按钮成功后记录。侧栏、项目首页、新建项目和导入项目虽然能成功打开项目，却没有写入当天选择，因此后续启动仍会显示项目选择页。
- 修复：`desktop.open_project_or_cleanup()` 在成功载入后记录当天选择；新建和导入项目成功载入后同样记录。自动续开仍复用既有 `daily_project_choice()` 与 `load(..., defer_page=True)`，直接进入“01 剧本准备”。
- 新增回归：侧栏／项目首页打开项目成功时，必须调用当天选择记录；载入失败时不记录。
- 用户实机复验后发现第二个根因：自动续开已经找到当天项目，但 `load()` 在首屏页面回调前同步扫描生成资产、清理遗留图并恢复台账；这会堵住 Tk 事件循环，使窗口停留在“我的项目 / 正在载入今日项目”。
- 补充修复：自动续开先显示“01 剧本准备”，再以空闲回调执行可延后的资产导入、清理和恢复；关闭窗口时会取消该回调。新增性能回归以 0.35 秒维护延迟模拟，锁定首屏不能再被该维护阻塞。
