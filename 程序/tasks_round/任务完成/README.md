# 任务完成文件（规则 35 建档）

- 本目录存放各任务书的《任务完成文件》，与 `程序/tasks_round/<任务书名>任务书.md` 一一对应，命名 `<任务书名>·任务完成.md`。
- 内容要求：逐条任务（含验收勾选）给完成证据——轮次号、结果文件、测试凭据、commit hash；未完成项如实标注并给出处置（转欠账／请求授权／放弃原因），不得只写「完成」。
- 背景：R3039 起新增 `AGENTS.md` §2.5 规则 35（任务书闭环：每个任务书必须执行完成全部任务，收尾输出本目录的完成文件）。此前项目无独立「任务完成文件」存量；`docs/review/` 下带「完成」字样的文件属阶段评审文档，不归入本目录。
- 维护：同主题同名维护一份，不散落他处；新任务书完成后在此建档。
