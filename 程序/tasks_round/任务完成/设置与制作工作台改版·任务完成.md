# 设置与制作工作台改版验收

控制端为 Codex，开发子任务交给 Devin。任务使用项目既有的 Tk、ttk、Fluent 图标、主题令牌、公共输入框和阶段服务。媒体播放复用 Windows Media Foundation。

| 范围 | 交付要求 | 验收入口 |
| --- | --- | --- |
| 设置、模型、技能包 | 压缩说明和表单，导航图标与主界面一致，保留键盘操作和保存；先列包再展开子技能 | 设置→基础功能／模型管理／技能管理；定向凭据 R4522 |
| 结构剧本、初步分镜 | 左侧文档导航，编辑器右上角关闭；保存失败时保留编辑内容 | 两页分别关闭、重开以及模拟保存失败 |
| 主界面、三虎、公共弹窗 | 清除图标下方冗余文案；跟随日夜主题刷新正文、选区、状态和对话 | 13 个阶段往返换肤，打开三虎对话验证 |
| 阶段导航与文件 | 资产子栏保持展开；前后阶段可回看；两侧与同一阶段对齐 | 窄窗及两侧发起滚动，比较 13 对图标中心 |
| 聊天、制作操作 | 自然剧本以外使用覆盖式聊天卡，不挤动正文；后续阶段通过输入框、右键、文件栏操作 | 展开收起、键盘菜单、跨阶段切换与文件操作 |
| 分镜预演 | 按历史规格恢复页内播放、逐镜操作、时间线和版本确认 | 播放带音轨的 H.264 样片、暂停、关闭；定向用例覆盖小窗与前置条件 |
| 加载 | 设置页按需创建，模型表格按需读入，先完成重绘再显示弹窗 | 懒加载及首帧顺序测试，实际 Windows 窗口切页 |

对应源码、测试与机器凭据见同目录上一级的 `tasks_round_4522_result.md` 和 `tasks_round_4523_result.md`。用户清单第 19 项无正文。访问第三方生成服务和真实计费不属于本次界面验收。
