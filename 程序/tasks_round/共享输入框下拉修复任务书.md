# 任务书 · 共享输入框图标下拉修复：✦勾选框失效 与 ＋菜单下钻自闭

> 本任务书自包含，执行者无需会话上下文。单轮修复（AGENTS.md §3.2 修复轮），
> 开工先 `维护记录/基准脚本/round_claim.py next` 领号；验收、提交按 §5/§2.6/§7。
> 已确认决策（用户 2026-11-16 拍板）：勾选框恢复"所见即真"、跨阶段行不渲染勾选框、
> `_widget_within` 改路径串比较。执行者不得自行变更。

## 1. 背景与用户报告

共享输入框底栏 `[✦技能][＋添加][🎤语音] | [输入框] | [模型][发送]`（R2971/R2980 引入，
R3013 合入 master）。用户实测报两个缺陷：

1. ✦ 技能下拉卡片的**勾选框无法选中**；
2. ＋ 添加列表点「添加技能…」**没有响应**。

## 2. 根因（已用隐藏桌面 Tk 复现取证）

### Bug A：＋菜单下钻自闭（`desktop_shared_input.py` + `desktop_shared_menus.py`）

- `_build` 给顶层窗 `bind('<Button-1>', _panel_outside_click, add='+')`，点面板外收掉下拉。
- 「添加技能…」「‹ 返回」行 `close=False`，点击走 `_drill_in/_drill_out → refresh() →
  clear()`，**销毁被点 label**。
- Tk 按 bindtags 派发：widget 绑定先跑（完成下钻重建），顶层绑定后跑；此时
  `event.widget` 经 `tkinter/_nametowidget` 查 `children` 已 KeyError，回退为**路径字符串**
  （CPython `tkinter/__init__.py` `e.widget = W` 分支）。
- `_widget_within(widget, panel)` 对字符串走 `getattr(node,'master')` → None → 恒 False
  → 判"外部点击" → `panel.hide()`。实测：下钻后 `drilled=True` 但 `open=False`，
  面板瞬间自闭，「‹ 返回」同病。
- 现有 `test_add_menu_entries_and_skill_drilldown` 只断言文本（销毁与否都能查到），
  未断言 `is_open()`，故漏网。

### Bug B：✦勾选框失效（`desktop_shared_menus.py::SkillPickPanel` + `stage_config.py`）

- 面板列"本阶段在前＋其余全部技能"（实测 12 行中 8 行属其他阶段），每行都画勾选框。
- 勾选写回 `stage_config.put → clean_skills(values, stage)` 只保留 `getByStage(stage)`
  名单；`synchronize()` 还会把错阶段项归位。**跨阶段行的勾选框永远写不进 → 永远停在未勾**。
- R2980 把打开预填改为"一律未勾选"（注释标用户定版），但 `_toggle_skill_default`
  对**配置真值**取反：本就在默认里的技能首次点击是**移除**，视觉本就未勾 → 看似无响应；
  第二次点击才加回显勾。实测 `was_default=True→now_default=False`。

## 3. 已确认决策（用户拍板）

1. **勾选框恢复"所见即真"**：`SkillPickPanel.refresh` 按 `host._default_skills()`
   预填勾选态（撤销"一律未勾选"）；点击经既有 `_toggle_skill_default → sync_check`
   即时取反写回，视觉与 `skill_config.json` 永远一致。
2. **跨阶段行不渲染勾选框**：仅当技能归属阶段 == `host.stage`（经
   `skill_registry.stage_id` 归一比较）且 `host.project is not None` 时画勾选框；
   其余行只保留名称点击插入 `/名称`。阶段无法判定的条目同样不画（宁可缺不可死）。
3. **`_widget_within` 改路径串比较**：widget 入参可能是 Widget 对象或 Tk 路径字符串
   （销毁后事件回退），统一取 `_w`/`str()` 路径，`wpath == apath or
   wpath.startswith(apath + '.')` 判包含；ancestor 为根 `.` 时恒 True。
   `_panel_outside_click` 其余逻辑不动。

## 6. 风险与回滚

| 风险 | 缓解 |
| --- | --- |
| 路径比较误判（`apath` 前缀撞名） | 用 `apath + '.'` 边界与全等两条判据；根 `.` 特判 |
| 预填勾选暴露历史脏配置 | `stage_config.get` 自带 `synchronize` 归位与 `clean_skills` 过滤，读到的即真值 |
