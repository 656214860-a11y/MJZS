# R588 只读诊断轮结果：自检增量台账权限提示

## 结论

定向 UI 回归结束时的“增量台账写不出来”不是项目代码或用户环境故障，而是当前受限诊断沙箱禁止向 `D:\漫剧制作助手\程序\维护记录` 写入造成的环境差异。

## 证据

- 台账文件 `维护记录/自检增量.json` 存在，目录 ACL 为授权账户提供修改权限，且没有残留 Python 自检进程。
- 受限环境调用与自检完全相同的 `run_selftests.save_cache(run_selftests.load_cache())` 路径，复现随机 `.tmp` 文件的 `Permission denied`。
- 在项目真实权限上下文执行完全相同的调用，成功返回正式台账路径 `D:\漫剧制作助手\程序\维护记录\自检增量.json`。
- 因而无需修改 `run_selftests.py`、`line_endings.py` 或原子替换逻辑；把沙箱失败重试写进产品代码既不能改善真实环境，也会掩盖真实锁定错误。

## 影响与后续

- 不影响先前 UI 回归、默认冒烟或架构门禁的通过结论。
- 已从项目状态中的产品观察项移除。真实用户环境未来若再次出现该提示，应记录发生时的外部占用进程；不能根据本轮沙箱现象直接归因。
