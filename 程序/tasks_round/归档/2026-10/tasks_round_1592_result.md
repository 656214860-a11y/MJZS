## 根因与复现

运行日志在 2026-10-16 15:06:00 记录模型请求失败：ValueError（API 根地址不完整）。只读核对所选 Google Gemini 4 Argon 的非敏感配置：调用方式为 Desktop，provider 为 desktop，API 地址为空，指定的桌面程序存在。

复现：在剧本准备页选择此自定义 Desktop 模型后发送。writing_api.selected_model 仅按内置模型 ID 排除桌面调用，没有读取模型池的 call_mode，于是错误进入 API 适配器；空地址校验失败被归入 bug，界面显示“系统内部错误”。

## 修复

- 直连模型识别读取 model_pool.call_mode，兼容旧 provider=desktop，显式 API 模型仍保留直连。
- 工作流将自定义 Desktop 模型解析为 desktop-app，沿用所选应用路径与显示名；阶段 API 参数解析排除 Desktop。
- 沿用任务文件、技能冻结和下载收件入口，复制完整任务到剪贴板，打开所选程序并提示粘贴、手动发送；回执为 prepared，不声称模型已收到任务。
- 后台与 CLI 入口拒绝 desktop-app，缺少程序路径时给出模型管理提示，避免错误切换到 Codex/Claude。
- 原有 Claude Desktop 自动粘贴逻辑保持原路径；未改用户配置、剧本或附件。
