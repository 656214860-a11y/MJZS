# R499 结构治理轮：资产分类目录初始化服务化

## 结论

- 资产页面不再直接创建用户可见的资产分类目录。
- 无 Tk 的 `asset_context.ensure_browser_directory()` 统一校验资产类别，并仅初始化请求的目录。

## 变更与边界

- `Desktop.assets()` 只请求当前资产库和类别对应的浏览目录，随后继续执行原有表格渲染和交互。
- 服务拒绝未知类别，避免 UI 拼接出未登记目录；新静态边界禁止资产页回流为直接 `mkdir()`。
