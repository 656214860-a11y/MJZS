## A 改动

- 新增 `skill_note_render.py`（L4）：纯函数 `parse(markdown) -> [(text, tags)]` 与 `apply(text_widget, markdown)`；标题、粗体、行内代码、围栏代码块、列表、引用、分隔线、表格、front matter、链接、HTML 注释行均转成 Text 标签或可读文本，未知语法原样保留，空串／畸形输入不抛异常。
- `ui_tokens.py`：新增标题 1–4、粗体、等宽代码、斜体提示等具名字体档位，代码浅底色 token，以及说明栏高度、目录宽度上下限和正文内边距 token。
- `skill_panel.py`：`build_notes` 的说明区高度改为紧凑 8 行／常规 16 行，正文与目录改 `FONTS['body']`，正文左右内边距加大，选中项使用 selection token；目录宽度按最长条目 `_display_width` 自适应（12–28），仍保留 `grid_propagate(False)` 与剩余空间伸缩；`render_note` 改调 `skill_note_render.apply`。
- `tests/architecture/_layers.py`：仅在 L4 登记行加入 `skill_note_render`。
- 新增 `tests/test_skill_note_render.py`（10 条）：解析层、Tk 标签层、真实 3 个 SKILL 文件、畸形输入、`Panel.render_note` 集成断言。

## B 语法支持与尺寸

**已支持**：`#`～`####` ATX 标题；`**粗体**`／`__粗体__`；反引号行内代码；```／~~~ 围栏代码块；`-`／`*`／`+`／`1.` 列表（统一 `•` 悬挂缩进）；`>` 引用；`---` 分隔线；带首尾竖线的表格行（分隔行丢弃，列间用全角 `｜`，等宽字体）；文件开头 YAML front matter（直接隐藏）；`[文字](url)` 与图片语法只显示文字；整行及行内 HTML 注释移除。

**未支持／按纯文本显示**：Setext 标题（下划线式）；单星／单下划线斜体；嵌套列表的独立层级；无首尾竖线的表格；引用式链接、自动链接、脚注；图片本身不加载；front matter 中的字段不展开显示；多行行内强调、复杂嵌套 Markdown。

**新旧值**：

- 说明区高度：紧凑 `5` → `8` 行；常规 `12` → `16` 行。
- 正文字体：`FONTS['caption']`（雅黑 10）→ `FONTS['body']`（雅黑 10）。仓库当前两者实际同为 10，故本轮只完成字体 token 切换，未改变全局正文字号。
- 新增标题字体：16／14／12／11 号雅黑粗体；等宽：Consolas 10；提示：雅黑 9 斜体。
- 正文左右内边距：`8` → `12`；上下内边距：`4` → `8`。
- 目录宽度：固定 `18` → 按最长条目的显示宽度自适应，限制 `12`～`28`；目录字体 `caption` → `body`。
- Tag 间距：正文 `spacing2=4`；一级标题 `spacing1=16/spacing3=8`，二级 `12/8`，三、四级 `12/4`；引用缩进 12；列表悬挂缩进 `16/20`；代码块前缀缩进 4。
- 实际构造检查（紧凑档）：说明栏高度 8，目录宽度 24，正文 `padx/pady=12/8`，状态 `disabled`，四个标题 tag 均已注册。
