# R1593：修复剧本 CLI 排队无法中断与无限等待

- 类型：§3.2 修复轮；用户直接报告，无对应队列 ID。
- 测试：先红后绿；冒烟 8/8，workflow / idea_chat 定向 10 文件、0 红；新增排队回归 5/5、注册表 7/7。架构定向 5/5；本轮未跑完整架构或全量。
- 欠账：不修改分支禁止写入的 project_status.md 与共享接力快照；无新增待修复测试失败。

## 根因与证据

截图状态为“模型请求排队中（第1位）”，此时尚未取得并发名额，Claude Code CLI 尚未启动，不能据此认定模型本身死循环。代码复现确认：CLI 排队每 200ms 重试，没有取消登记、项目切换检查和等待上限；中断逻辑不撤销这张队列票。剧本页面重建时又无条件禁用中断按钮，没有根据现有任务恢复状态。

另一个可复现的阻塞来源是已退出进程仍占有登记名额：申请/认领容量没有先回收退出进程。启动前准备任务异常也可能遗留预留名额。未取证截图发生时究竟哪个进程持有名额，不将这一可能来源冒充现场事实。

## 修复

- 将当前剧本 CLI 排队票登记到窗口，支持精确中断、取消定时器，拒绝重复发送；取消后的迟到轮询不再启动 CLI，不取消其他项目的队列票。
- 切换项目或关闭时撤销排队；等候超过 120 秒退出并给出明确提示。
- 申请/认领名额前回收已退出的自有进程；保留活进程及尚未绑定进程的预留；启动异常释放本次预留。
- 页面创建按钮后按当前请求状态刷新，排队/启动中保持可中断。未修改 Tk 控件创建、销毁、重建生命周期。
- 沿用原有 CREATE_NEW_CONSOLE 启动路径，并加入断言；没有名额时明确提示 CLI 尚未启动。
