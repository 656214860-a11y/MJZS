## 实施记录

### 修改文件

- `idea_chat.py`：新增 `default_brief_document()`；`initial_brief_document()` 在无历史文件时复用它。页面可以先拿到默认写入路径，不再在 Tk 构建期同步递归扫描。
- `desktop.py`：剧本准备页先绑定默认路径，随后经既有 `async_()` 后台执行 `initial_brief_document()`；`queue_initial_brief_document()` 用 `_idea_brief_generation`、当前页面、控件身份和当前路径四重条件接收结果。离开或重建剧本准备页时递增代次，因此旧页结果不能覆盖新页。
- `tests/test_idea_chat.py`：新增 240 份临时 Markdown 的排序/3 秒明显退化阈值回归；新增旧代次回调抵达时不覆盖新页面编辑目标的回归。
- `project_status.md`、本结果文件：仅轮次台账与交付记录；未改用户项目数据。

### 新增契约

1. 240 份分类创意 Markdown 的发现结果仍按修改时间从旧到新排序，且测试环境中不得超过 3 秒（阈值只拦明显退化）。

3. 页面已切走或被重建导致代次变化时，旧回调无副作用。
