## 1. 总目标

对主窗口进行一轮外观与交互打磨，共 7 条用户诉求，全部落在 L4 表现层与既有附件/布局链路：

```
① 上传附档 → 不再单独卡片行，改为「@原名」逐行落在输入框文本最顶（与手动 @ 同显示效果）
② 项目文件图标 → 右移贴边、左侧聊天区右移、图标占位缩短
③ 输入框 → 输入区与工具行共用一条外框，无内框线；聚焦时外框高亮（DSH 风格）
④ 启动默认尺寸 → 加高，保证左侧目录图标完整显示
⑤ 模型选择器 → 下拉卡收窄、推理徽标紧跟模型名、右侧加可见滚动条
⑥ 共享输入框宽度 → 全页对齐上方聊天框宽度（项目文件面板开合同步收窄）
⑦ 发送/终止/返回按钮 → 统一 Fluent PNG 图标风格（替换 MDL2 字形与手绘箭头）
```

## 2. 已确认决策清单（用户逐条拍板，不得自行变更）

1. **附件行内化选「后者」**：上传完成后把 `@原名` 作为**独立行**写进输入框最顶（1.0 处插入块、已有内容整体下移、光标经 mark 复位）；每附件一行。手动 `@` 选择维持光标处插入、不进顶部引用区（登记 `_idea_cursor_ref_names` 防重复）。
2. **右边距**：`body_padding` 右缘 `xl(24)→md(12)`；文件图标按钮 padding `sm(8)→xs(4)`，**不归零**。
3. **内框线**：`TextArea` 去 `highlightthickness`；ttk 主题不支持 `-highlight*`，外框由包裹层 `input_ring`（`tk.Frame` 底色边，Card 内缩 1px 露环色）承担；`<FocusIn>/<FocusOut>` 切 `border_input_hover`/`border_default`。
4. **启动尺寸**：默认 `1280×800→1280×900`（最小仍 `800×600`），侧栏图标轨在 800 高下放不下。
5. **模型选择器**：模型名 Label 去 `expand`，推理徽标紧随其后（`anchor='w'`）；卡片宽＝最宽行自然宽；`ScrollForm(scrollbar=True)` 右缘可见竖向滚动条。
6. **输入框宽度**：共享输入框宿主从 `body` 改为画布列底部 `input_dock`，**全页统一**（不只剧本页）；面板打开时画布与输入框同步收窄。
7. **图标**：选 Fluent PNG 方案——`assets/nav/send.png`、`stop.png`（主色底配卡片色墨水）、`back.png`（卡片底配主题色墨水）；缺 PNG 时退回 MDL2 字形／手绘箭头。返回钮保留「返回生成方式」文字。
8. **附件删除/引用**：chip 行撤除后，`@名` 行右键出「打开附件／删除附件（移入回收站）／取消引用」；「取消引用」只移本轮发送名单、不动项目副本（新增 `idea_chat_controller.unreference_attachment`）。

## 5. 风险与备注

- **pack 需求宽度竞争**：`stage_area` 内含宽输入框，共享输入框 reqwidth 会挤占面板——以「`panel_dock` 空列先占位、面板内容长高后 `stage_area` 让位」解决（实测 800×600 面板宽约 198px、画布 486px 正常）。
- **环境欠账（非本轮引入）**：工作树缺 `AIGC创作全流程` 子模块内容与 `编剧技能集`/`剧本锻造` 忽略层嵌套仓库——已从主工作区补齐（gitignored，不入提交），`skill_registry.count()` 恢复 73。
- **`smoke_test.py --gate/--affected` 结构性超时**：desktop.py 消费面 136 文件，串行门禁 900s 上限内不可能跑完；本轮以 `run_selftests.py -k <同口径筛选词>` 并行跑为准（等价覆盖、非串行）。
