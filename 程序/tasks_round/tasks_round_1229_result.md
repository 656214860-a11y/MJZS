## 真因与修复

模型与供应商下拉回调原先立即保存阶段配置，入口按钮却只在确认时更新，造成显示 DeepSeek、配置已变为另一模型。SKILL 勾选复用 save，也会间接提交尚未确认的模型。现在下拉只更新弹窗待选值，SKILL 勾选/全选及既有编程运行入口保存时保留已确认模型，点击确认才提交待选模型并更新按钮；关闭丢弃待选模型。保留既有显式 save 编程接口和预设/恢复默认的独立语义。

Enter 与发送按钮调用同一发送方法，并非 Enter 特有的 API 路由。保存用户消息按实际模型分区，展示却复用旧模型缓存，导致输入已保存但看不见。发送时以实际模型同步展示缓存与按钮，并递增异步解析代次，防止旧解析回调覆盖新分区。确认配置仍只保存关闭，不发消息、不调用 API。
