# L0–L5 制作链路集成任务书

基线为 master 444b6a359。Control agent 负责需求裁决、派工、代码复核和合入；Devin 负责实现与针对性测试。以 Windows 本地项目和现有 13 阶段为交付范围。需求来源为《产品需求规格》§3、§5、§6、§10，以及设计规格 01、02、07、09。实施前核对同类在途改动，以真实调用点裁决过时的待办。

## 工作包与依赖

| 编号与优先级 | 交付职责与接口 | 验收证据 |
| --- | --- | --- |
| A · P0 任务恢复 | L0 复用 project/run/task/attempt、远端号和费用请求号；L1 按实际供应商能力查单；L2 给任务中心接入实际配音进度和历史格式；L4 从正常任务入口定位到句、版本、状态、可执行操作。保留现有资产与视频视图。 | 重启临时项目，成功句保持，408 未知句可定位，有查单能力时取回原请求，无能力时转核实；核对新增付费提交次数为零。验证旧记录、损坏记录和账号切换隔离。 |
| B · P0 商用追溯 | L2 从交付版本及已登记的来源边递归枚举实际采用文件；L3 复用商用资料生成和审核门禁；L4 展示遗漏、变更及人工补录。覆盖剧本、参考、图、视频、音乐、字体、声音。 | 实际导入待填资料并核验；替换已采用音乐、添加字体、修改授权凭据、遇到未登记外部精修时均能区分。未知项由人工登记并签认，保留原资料。 |
| C · P1 执行接口 | 以 L0 定义工具结果或调用协议；L3 注入工具执行器；L4 适配输入、打开页面、确认结果；L5 在现有装配点绑定。迁移所有既有调用者并保留模板执行及已完成步骤复用。 | 无界面执行与桌面执行得到相同业务结果；等待人工处理后接回原任务；重复确认不重复调用；架构检查保护 L3 与 UI 的边界。 |

A、B、C 可独立实施。D 依赖 A 的既有请求字段，E 的规格核对和环境盘点可先行，最终验收使用集成版本。只在有现成实现与适用许可时复用 GitHub 成熟框架、模块或代码，先评估本仓库的适配器、测试与兼容入口。参考 Autodesk Flow Production Tracking 的发布依赖与审阅版本，以及 AWS Deadline Cloud 的作业、步骤、任务下钻。

## 合入与交付标准

1. 维护原项目格式及回读能力；以现有台账为写入权威。重试、取消、改稿、换号、恢复后的重复操作纳入回归。外部精修内容由审核人说明来源。
2. 每卡提供入口、涉及文件、测试命令、执行结果及边界。Control agent 复核变更，运行针对性回归与仓库合并门禁，同一缺陷不重复跑全量。
3. 生产费用须有对应授权与额度，商用许可和独立评审须有真实凭据。离线模拟、隐藏桌面、真实供应商和剪辑软件实机结果分开登记。
4. 软件实现、授权样片、生产账单及外部实机分别判定；完成记录逐项链接证据，尚缺的资料和执行条件保留为未完成。
