# R1600 O3 可恢复桌面任务队列

类型：可靠性/数据迁移轮。来源：R1596 O3；中央工具已认领1600，无对应队列ID。

## 实现
在既有BackgroundTaskQueue上扩展持久描述符，复用core文件读写和publication事务串行领取。仅可序列化参数落盘；优先级加等待老化排序，支持取消与过期，终态历史有界。领取先落盘再执行，重启仅恢复未领取项；未知在途记录展示在运行状况，失败不自动重复提交。

实际桌面入口“项目存储盘点”改用storage_inspect描述符，冻结项目绝对路径，在首次绘制后恢复待办。连接探测因依赖临时设置窗口仍用内存回调。运行状况新增取消全部待执行按钮；该操作保留已领取未知项。生产注册仅只读存储盘点，不宣称已迁移付费生成台账；原资产/视频恢复入口继续使用自身记录。
