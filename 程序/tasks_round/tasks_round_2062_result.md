# R2062 验证码登录：点「用验证码登录」直接发码（功能轮）

轮次类型：功能轮。日期：2026-10-25。

- 密码登录页点「用验证码登录」，原来是先跳到验证码页，再手点「发送验证码」；现在直接发送验证码，发出成功后才切到验证码页并放开「登录」键。
  - 邮箱没填或格式不对：留在密码页，在邮箱框报错，不发送、不跳转。发送失败：留在原页显示原因。
  - 验证码页的「发送验证码」保留，用于重发。
  - 入口：`desktop_account_page.py` `_build_login_form` 里 `use_code` 按钮，复用已有的 `send('login', …, after=…)`；账号页与启动登录闸共用。
- 契约有意变更：`test_account_page`（4 处）、`test_login_gate`（2 处）把“切视图→填邮箱→点发送”改成“填邮箱→点用验证码登录”，断言未动。
- 验证：`run_selftests -k test_account_page test_login_gate` 共 32 条全绿。
