## 原因与修复

原输出契约只进入编剧请求，导演规划、编辑、演员及审核缺少同一阶段交付边界，容易把后续分镜、字幕排版当作自然剧本通过条件。实际失败链为编剧通过、编辑审核要求返工、一次返工后仍未通过；属于审核拒绝，不是 API 断线。

将既有 output_contract 放入各角色、审核和返工共享约束，明确当前只交付自然剧本，保留故事、人物、可表演性和单集时长要求。镜号、逐镜时间码、字幕逐行排版不作为当前阶段放行条件。导演与审核各自的输出格式保持不变。

审核失败异常携带 review_failed_role，经 API 结果传到 UI；编辑未通过时显示导演审核未通过、编剧已通过、编辑未通过、演员未开始。新请求正常重置；未通过稿件仍不保存为正式 script_raw.md。
