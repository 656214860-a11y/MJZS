# 文档导航

这份导航一句话说明每份文档的用途，帮你在「漫剧助手」仓库里快速找到该读的东西。它只做索引，不改写任何文档；文档内容冲突时，以「权威源」列的那份为准。

## 先读这些（入口与状态）

| 文档 | 用途 | 权威源 |
| --- | --- | --- |
| `AGENTS.md` | 代理开工入口：必读顺序、硬约束、轮次类型、自检规则 | 是 |
| `project_status.md` | 项目当前轮次、待办、验证基线、已知阻塞 | 是 |
| `architecture.md` | 目录树、L0–L5 分层表、模块职责、权威源表 | 是 |
| `PROJECT_MAP.md` | 核心模块地图、阶段目录、门禁关系、数据边界 | 是 |

阅读顺序：先 `AGENTS.md` 定规则 → `project_status.md` 看现状 → `architecture.md`／`PROJECT_MAP.md` 查结构。

## 阶段文档（按制作阶段拆分）

- `docs/README.md`：阶段需求/设计索引（13 阶段编号、条数一览）。
- `docs/specs/`：**实现设计规格**（七册）——01 架构与技术选型、02 接口与详细设计、03 安装签名与分发、04 数据与本地存储、05 UIUX 与交互规范、06 安全设计、07 业务域规格；`README.md` 是索引、SRS 覆盖映射与规模基线。
- `docs/adr/`：架构决策记录（MADR 精简格式），`README.md` 是状态枚举／编号规则／索引，`TEMPLATE.md` 是新 ADR 模板。
- `docs/stages/S01…S13_*.md`：每个制作阶段一份，`## 需求`（去向）＋`## 设计`（实现）。
- `docs/review/`：高危路径评审说明（时序＋失败模式），给人审阅用。

## 说明库（`说明/` 目录，面向特定主题）

产品需求规格（PRD）、发布检查单、商用交付、存储盘点、模型金额预算、每分钟成本、账户会员云端设计等，按文件名取用。[已并入设计规格.md](说明/已并入设计规格.md) 是 R3785 删除的旧文件的指针页，只做重定向、不含独立结论。
