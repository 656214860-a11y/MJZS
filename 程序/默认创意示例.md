【short-drama-director 技能】把一个创意做成爆款短剧和漫剧的剧本、分镜和视频提示词
  动手前它要先确认五把前置锁（素材来源、视频模型、画幅、交付形态、段缝衔接）和画风，缺哪把都会停下来问你
  本页发送前必须写明三项 → 素材来源、赛道、交付形态，行首带星号的行必填
  素材来源可选 → 原创 / 改编（有原著） / 对标爆款（现场采风） / 热点速成（给方向先找选题）
  赛道可选 → 国内剧 / 海外剧 / 解说叙事类 / 其他
  交付形态可选 → 两者都交付 / 只要离线看板 / 只要 markdown 文档
  视频模型可选 → Seedance 2.5 / Seedance 2.0
  故事画幅可选 → 9:16 / 16:9 / 21:9
  段缝衔接方式可选 → 末帧定格承接 / 换机位硬切 / 空镜过渡 / 技巧型转场
  故事画风可选 → 直接描述想要的画风，或写「按你的推荐走」让它给候选
