漫剧助手 V0.7 · 2026.09.21 更新版（Windows 64 位）

安装方法
1. 将整个 ZIP 解压到普通文件夹。不要在压缩包预览中直接运行。
2. 关闭正在运行的漫剧助手。
3. 双击“双击安装.cmd”，确认安装位置，点击“一键安装 / 升级”。
4. 安装完成后点击“打开助手”，或使用桌面的“漫剧助手”快捷方式。

已包含
助手完整程序、Python/Tkinter 运行环境、本地 Skill 文件与工作流示例、
Qwen Code 0.24.0 官方 Windows 安装组件（可选安装）。无需另外安装 Python。
同一目录升级会保留项目列表、设置和用户数据；被替换的程序文件自动备份到“升级备份”。
首次安装不会带入现有剧本、资产图片或任何 API Key。

首次使用
ChatGPT / Codex 需要本机安装对应软件并登录。
Qwen Code 在“阶段配置”中选择，打开“阿里云 API 设置”填写自己的 Key。
自动批量制作使用百炼按量付费通用 API；Token Plan 个人版和 Coding Plan 不适用于非交互式批量调用。
新安装的项目默认保存在用户 Documents 下的“漫剧下载”；旧安装保留原项目位置。
ComfyUI、Blender、FFmpeg、剪辑软件及其模型不包含在本包中，需要按制作环节另行配置。
Qwen API 尚未通过本机真实调用验证；图片制作继续使用 ComfyUI。
